## 1、国家局权限申请

国家局密钥权限分为测试环境和正式环境，需先申请测试环境的使用，测试环境验收通过后，再申请正式环境。

目前各地主要由各省医保局通过需求平台进行申请，而后得到反馈，各省第一家机构由国家局验收，国家局验收通过后，可以下发正式权限。各省非第一家机构由各省自行验收，并根据[国家局一码付批量申请表格](https://docs.qq.com/document/DV3V4dUtYenp0V2xJ)统一向国家局申请接入机构的密钥，下发给各家机构。

注意

国家局一码付批量申请表格，一个表最多支持1000条数据，如果数量过多，可以按照每个表1000条数据的方式，拆分为多张表提交。

## 2、微信医保码一码付立项

需以邮件方式申请，模版如下：

- 邮件主题：XX机构+微信医保码一码付立项申请

- 发送人：机构所在区域对应的腾讯商务

- 邮件申请模版如下(以下供参考，请复制到邮件中使用）：

| 城市 | 机构所在城市 |

| 机构类型（仅保留正确的选项） | - 医院<br>  <br>- 基层卫生机构/社康<br>  <br>- 药店 |

| 机构联系人 | - 姓名：<br>  <br>- 职位：<br>  <br>- 邮箱：<br>  <br>- 电话： |
| 服务商信息 | - 公司名称（写公司全称）：<br>  <br>- 服务商类型：<br>  <br>his厂商<br>公众号/小程序厂商<br>其他厂商<br>自研<br>- 姓名：<br>  <br>- 职位：<br>  <br>- 邮箱：<br>  <br>- 电话： |

注意

目前仅支持公立医院的微信商户号开通免密白名单，私立医院和药店暂不支持，仍然需要输密。
