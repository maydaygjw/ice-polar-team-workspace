## 1、接口对接说明

### 1.1 省中台相关接口说明

| 接口名称 | 说明 |
| --- | --- |
| 查询用户一码付状态 | - 使用医保电子凭证二维码解码后的ectoken进行接口调用。 |
| 获取一码付付款凭据 | - 获取到对应的自费付款凭据和支付渠道名称后，需要使用对应的自费支付渠道进行自费下单。<br>  <br>- 接口调用的现金支付金额应和自费支付渠道下单的支付金额一致。 |

### 1.2 微信自费下单接口说明

| 商户号性质 | 说明 |
| --- | --- |
| 微信直连商户号 | - 使用微信的[付款码支付接口](https://pay.weixin.qq.com/doc/v2/partner/4011941052.md)，进行自费下单。<br>  <br>- 微信支付的自费扣款是真实扣款，如果测试环境进行一码付测试，也会进行真实自费扣款，医保扣款则是测试环境模拟。 |
| 微信间连商户号 | - 对应收单机构（银行/其余第三方支付机构）支持微信付款码支付的接口。 |

## 3、测试环境切正式环境

测试环境联调完成后，需整理相关材料提交至省级医保部门，再由省局提交国家医保局审核，具体流程与材料要求可参考[测试信息准备和验收注意事项](https://pay.weixin.qq.com/doc/v3/partner/4027117108.md)。
