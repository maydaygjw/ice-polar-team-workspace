>更新时间：2024.11.04

提交垫付退款回补后，通过调用该接口查询垫付回补结果。

1. 垫付回补结果为处理中，微信支付会在90天内定期重试，重试结果需要查单确认。此状态下商户可以重试。

2. 若处理中状态重试90天后出款方账户仍然余额不足，回补结果将置为回补失败，系统不再重试，商户也无法重试，后续不能再发起此退款单的回补。回补处理期间请确保出款账户余额足够。

3. 垫付退款能力需先开通，才能使用。若需要开通，请联系微信支付客服。





## 接口说明

支持商户：【平台商户】

请求方式：【GET】 `/v3/ecommerce/refunds/{refund_id}/return-advance`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点

　　　　　【备域名】https://api2.mch.weixin.qq.com 使用该域名将访问异地的接入点，指引[点击查看](https://pay.weixin.qq.com/doc/v3/partner/4012082567.md)

## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| refund_id | string(32) | true | **【微信退款单号】** 必须是垫付退款的微信退款单 |
| advance_return_id | string(32) | true | **【微信回补单号】** 微信支付生成的垫付回补操作单号 |
| return_amount | integer | true | **【垫付回补金额】** 退款单对应的垫付退款的金额 |
| payer_mchid | string(32) | true | **【出款方商户号】** 微信支付分配给出款方的商户号 |
| payer_account | string(32) | true | **【出款方账户】** BASIC 基本账户<br>OPERATION 运营账户 |
| payee_mchid | string(32) | true | **【入账方商户号】** 微信支付分配给入账方的商户号 |
| payee_account | string(32) | true | **【入账方账户】** BASIC 基本账户<br>OPERATION 运营账户 |
| result | string(32) | true | **【垫付回补结果】** SUCCESS 回补成功<br>FAILED 回补失败，出款方账户余额不足时发生<br>PROCESSING 处理中 |
| success_time | string(64) | false | **【垫付回补完成时间】** 垫付回补完成的时间，遵循rfc3339标准格式，格式为YYYY-MM-DDTHH:mm:ss+TIMEZONE，YYYY-MM-DD表示年月日，T出现在字符串中，表示time元素的开头，HH:mm:ss表示时分秒，TIMEZONE表示时区（+08:00表示东八区时间，领先UTC 8小时，即北京时间）。例如：2015-05-20T13:29:35+08:00表示，北京时间2015年5月20日13点29分35秒。 |
