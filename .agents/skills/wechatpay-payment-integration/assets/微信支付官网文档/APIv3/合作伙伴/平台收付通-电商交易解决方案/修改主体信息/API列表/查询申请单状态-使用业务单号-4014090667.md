>更新时间：2025.03.31

使用业务单号查询申请单状态




## 接口说明

支持商户：【普通服务商】　【平台商户】

请求方式：【GET】 `/v3/mchalterapply/mchsubjectalterapplyment/merchant/{merchant_code}/out-request-no/{out_request_no}`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点

　　　　　【备域名】https://api2.mch.weixin.qq.com 使用该域名将访问异地的接入点，指引[点击查看](https://pay.weixin.qq.com/doc/v3/merchant/4012075113.md)

## 请求参数

### Header 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| Authorization | string | true | 请参考 [签名认证](https://pay.weixin.qq.com/doc/v3/merchant/4012365342.md#%E8%AF%B7%E6%B1%82%E6%8E%A5%E5%8F%A3%E5%90%8E%E7%AB%AF%E7%AD%BE%E5%90%8D) 生成认证信息 |
| Accept | string | true | 请设置为 `application/json` |
### Path 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| merchant_code | string(32) | true | 【微信支付商户号】 本服务商进件、已签约的特约商户/二级商户号。 |
| out_request_no | string(64) | true | 【业务申请编号】 1、只能由数字、字母或下划线组成，建议前缀为服务商商户号。<br>2、服务商自定义的唯一编号。 |
## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| merchant_code | string(32) | true | 【微信支付商户号】 本服务商进件、已签约的特约商户/二级商户号。 |
| apply_id | string(64) | true | 【申请单号】 微信支付分配的申请单号 |
| out_request_no | string(64) | true | 【业务申请编号】 1、只能由数字、字母或下划线组成，建议前缀为服务商商户号。<br>2、服务商自定义的唯一编号。 |
| state | string | true | 【申请单状态】<br>可选取值<br><ul><li>`APPLYMENT_STATE_AUDITING`:  审核中，申请单正在审核中。</li><li>`APPLYMENT_STATE_REJECTED`:  已驳回，请按照驳回原因修改申请资料。</li><li>`APPLYMENT_STATE_MODIFING`:  资料修改中，系统修改资料中，请耐心等待。</li><li>`APPLYMENT_STATE_FINISHED`:  已完成，商户资料修改申请已完成。</li><li>`APPLYMENT_STATE_CANCELED`:  已作废，申请单已被撤销。</li><li>`APPLYMENT_STATE_EDITTING`:  编辑中，提交申请发生错误导致，请尝试重新提交。</li></ul> |
| audit_reject_reason | string(1024) | false | 【总体驳回原因】 总体驳回原因，当申请状态为 `APPLYMENT_STATE_REJECTED` 时才返回。 |
| audit_reject_detail | array[object] | false | 【驳回原因详情】 各项资料的审核情况，当申请状态为 `APPLYMENT_STATE_REJECTED` 时才返回。 |
| audit_reject_detail.param_name | string(128) | false | 【参数名称】 提交申请单的资料项字段名称。 |
| audit_reject_detail.reject_reason | string(1024) | false | 【驳回原因】 提交资料项被驳回的原因。 |
