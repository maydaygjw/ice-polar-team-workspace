>更新时间：2026.08.19

接口适用场景：收付通（平台）服务商可通过本接口，查询其名下指定主体的子商户列表。

1、通过 `organization_type` 与 `cert_number` 定位主体。

2、仅返回属于指定主体、与当前服务商存在有效父子绑定关系且未注销的子商户。

3、支持 `limit`/ `offset` 分页查询。




## 接口说明

支持商户：【平台商户】

请求方式：【GET】 `/v3/ecommerce/subject-sub-merchants`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点

　　　　　【备域名】https://api2.mch.weixin.qq.com 使用该域名将访问异地的接入点，指引[点击查看](https://pay.weixin.qq.com/doc/v3/merchant/4012075113.md)

### Header 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| Authorization | string | true | 请参考 [签名认证](https://pay.weixin.qq.com/doc/v3/merchant/4012365342.md#%E8%AF%B7%E6%B1%82%E6%8E%A5%E5%8F%A3%E5%90%8E%E7%AB%AF%E7%AD%BE%E5%90%8D) 生成认证信息 |
| Accept | string | true | 请设置为 `application/json` |
| Wechatpay-Serial | string | true | 【微信支付公钥ID】或【微信支付平台证书序列号】  请求参数中的敏感字段，需要使用微信支付公钥加密（推荐），请参考 [获取微信支付公钥ID说明](https://pay.weixin.qq.com/doc/v3/merchant/4013038816.md#Q:-%E5%A6%82%E4%BD%95%E8%8E%B7%E5%8F%96%E5%BE%AE%E4%BF%A1%E6%94%AF%E4%BB%98%E5%85%AC%E9%92%A5ID?) 以及 [微信支付公钥加密敏感信息指引](https://pay.weixin.qq.com/doc/v3/merchant/4013053257.md)；也可以使用微信支付平台证书公钥加密，参考 [获取平台证书序列号](https://pay.weixin.qq.com/doc/v3/merchant/4013053294.md)、 [平台证书加密敏感信息指引](https://pay.weixin.qq.com/doc/v3/merchant/4013053264.md) |
### Query 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| organization_type | string | true | 【主体类型】 主体类型需与营业执照/登记证书上一致，可参考选择 [主体指引](https://kf.qq.com/faq/180910IBZVnQ180910naQ77b.html)。<br>可选取值<br><ul><li>`SUBJECT_TYPE_ENTERPRISE`:  企业，营业执照上的主体类型一般为有限公司、有限责任公司</li><li>`SUBJECT_TYPE_INSTITUTIONS_CLONED`:  事业单位，包括国内各类事业单位，如：医疗、教育、学校等单位</li><li>`SUBJECT_TYPE_INDIVIDUAL`:  个体工商户，营业执照上的主体类型一般为个体户、个体工商户、个体经营</li><li>`SUBJECT_TYPE_OTHERS`:  社会组织，包括社会团体、民办非企业、基金会、基层群众性自治组织、农村集体经济组织等组织</li><li>`SUBJECT_TYPE_GOVERNMENT`:  政府机关，包括各级、各类政府机关，如机关党委、税务、民政、人社、工商、商务、市监等</li><li>`SUBJECT_TYPE_MICRO`:  小微商户或个人卖家，无营业执照、免办理工商注册登记的实体商户</li></ul> |
| cert_number | string(512) | true | 【证件号码】 与主体类型对应的证件号码。<br>1、企业/个体工商户：营业执照上的注册号/统一社会信用代码。<br>2、小微/个人卖家：经营者身份证号码。<br>3、事业单位/政府机关/社会组织：登记证书上的编号。<br>该字段需要使用微信支付公钥加密（推荐），请参考 [获取微信支付公钥ID说明](https://pay.weixin.qq.com/doc/v3/partner/4013038589.md#Q%3A-%E5%A6%82%E4%BD%95%E8%8E%B7%E5%8F%96%E5%BE%AE%E4%BF%A1%E6%94%AF%E4%BB%98%E5%85%AC%E9%92%A5ID%3F) 以及 [微信支付公钥加密敏感信息指引](https://pay.weixin.qq.com/doc/v3/partner/4013059044.md)，也可以使用微信支付平台证书公钥加密，参考 [获取平台证书序列号](https://pay.weixin.qq.com/doc/v3/partner/4013059181.md)、 [平台证书加密敏感信息指引](https://pay.weixin.qq.com/doc/v3/partner/4013059053.md)。 |
| limit | integer | false | 【分页大小】 分页大小，最大不超过200。不传则默认值为20。该值需大于0。 |
| offset | integer | false | 【分页偏移】 该次请求的分页起始位置，从0开始计数。不传则默认值为0。 |
## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| data | array[object] | true | 【子商户列表】 子商户列表。若查询结果为空，则返回空数组。 |
| data.sub_mchid | string(32) | true | 【子商户号】 属于指定主体、与当前服务商存在有效父子绑定关系且未注销的特约商户/二级商户号。 |
| data.merchant_shortname | string(64) | true | 【商户简称】 子商户简称。 |
| data.sign_time | string(32) | true | 【签约时间】 子商户签约完成时间，遵循 [rfc3339](https://datatracker.ietf.org/doc/html/rfc3339) 标准格式，如 `2018-06-08T10:34:56+08:00`。若暂无签约时间则返回空字符串。 |
| offset | integer | true | 【分页偏移】 该次请求的分页起始位置，与请求参数一致。 |
| limit | integer | true | 【分页大小】 该次请求的分页大小，与请求参数一致（未传请求参数时为默认值）。 |
| total_count | integer | true | 【总条数】 符合条件的子商户总条数。 |
