## curl


> POST

```
curl -X POST \
  https://api.mch.weixin.qq.com/v3/pay/partner/transactions/out-trade-no/1217752501201407033233368018/close \
  -H "Authorization: WECHATPAY2-SHA256-RSA2048 mchid=\"1900000001\",..." \

  -H "Content-Type: application/json" \
  -d '{
    "sp_mchid" : "1230000109",
    "sub_mchid" : "1900000109"
  }'
```
