## curl


> POST

```

  https://api.mch.weixin.qq.com/v3/marketing/favor/stocks/9856000/start \
  -H "Authorization: WECHATPAY2-SHA256-RSA2048 mchid=\"1900000001\",..." \

  -H "Content-Type: application/json" \
  -d '{
    "stock_creator_mchid" : "8956000"
  }'
```
