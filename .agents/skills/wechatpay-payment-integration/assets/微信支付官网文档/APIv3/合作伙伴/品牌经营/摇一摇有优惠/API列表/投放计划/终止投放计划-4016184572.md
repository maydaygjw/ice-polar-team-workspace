## 接口说明

支持商户：【普通服务商】

请求方式：【POST】 `/v3/marketing/partner/delivery-plan/delivery-plans/{plan_id}/terminate`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点
