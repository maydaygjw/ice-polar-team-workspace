>更新时间：2025.11.13

接口适用场景：服务商提交配置商家名片配置申请后，可调用此接口查询申请状态。




## 接口说明

支持商户：【普通服务商】

请求方式：【GET】 `/v3/brand/card/card-configs`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点

　　　　　【备域名】https://api2.mch.weixin.qq.com 使用该域名将访问异地的接入点，指引[点击查看](https://pay.weixin.qq.com/doc/v3/merchant/4012075113.md)

接口限频：30/秒（商户号维度）

### Query 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| business_code | string(128) | false | 【业务申请编号】 1、只能由数字、字母或下划线组成，和微信支付申请单号二选一作为请求参数；<br>2、服务商自定义的商户唯一编号，每个编号对应一个申请单；<br>3、填写调用 [提交商家名片配置申请](https://pay.weixin.qq.com/doc/v3/partner/4016468440.md) 时传递的业务申请编号。 |
| applyment_id | string(25) | false | 【微信支付申请单号】 1、申请单的唯一标识，由微信支付生成，和业务申请编号二选一作为请求参数。<br>2、填写调用 [提交商家名片配置申请](https://pay.weixin.qq.com/doc/v3/partner/4016468440.md) 时返回的微信支付申请单号。 |
| brand_id | string(20) | true | 【品牌ID】 商家进驻微信支付品牌商家后获得的品牌ID，作为品牌唯一标识符。 |
## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| business_code | string(128) | true | 【业务申请编号】 1、只能由数字、字母或下划线组成；<br>2、服务商自定义的商户唯一编号，每个编号对应一个申请单。 |
| applyment_id | string(25) | true | 【微信支付申请单号】 申请单的唯一标识，由微信支付生成。 |
| brand_id | string(20) | true | 【品牌ID】 商家进驻微信支付品牌商家后获得的品牌ID，作为品牌唯一标识符。 |
| applyment_state | string | true | 【申请单状态】 商家名片配置的申请状态。<br>可选取值<br><ul><li>`STATE_UNKNOWN`:  「状态未知，非终态」发布配置流程的中间状态，请稍后重试</li><li>`DRAFTING`:  「配置中，非终态」调用提交申请接口后，返回了预览二维码，尚未调用发布接口，即流转到该状态</li><li>`AUDITING`:  「审核中，非终态」调用发布接口后，平台将进行审核，即流转到该状态</li><li>`AUDIT_REJECTED`:  「审核驳回，非终态」审核阶段被驳回，会附带具体的驳回原因，请根据驳回原因修改调整，如仍需添加请使用原业务申请编号重新调用 [提交商家名片配置申请](https://pay.weixin.qq.com/doc/v3/partner/4016468440.md) 接口</li><li>`PENDING_PUBLISH`:  「待发布，非终态」审核通过后，未到达发布时间，即流转到该状态</li><li>`PUBLISHED`:  「已发布，终态」商家名片配置已顺利更新到线上，即流转到该状态</li><li>`CANCELED`:  「已撤销，终态」商家名片配置请求被撤销，如仍需配置请更换业务申请编号重新调用 [提交商家名片配置申请](https://pay.weixin.qq.com/doc/v3/partner/4016468440.md) 接口</li></ul> |
| scheduled_publish_time | string(64) | false | 【定时发布时间】 1、定义：提交商家名片配置审核通过后，平台发布配置上线的计划时间。<br>2、返回条件：当且仅当发布配置时设置了计划发布时间，本字段才会返回值。<br>3、格式：遵循 [rfc3339](https://datatracker.ietf.org/doc/html/rfc3339) 标准格式： `yyyy-MM-DDTHH:mm:ss+TIMEZONE`。 `yyyy-MM-DD` 表示年月日； `T` 字符用于分隔日期和时间部分； `HH:mm:ss` 表示具体的时分秒； `TIMEZONE` 表示时区（例如， `+08:00` 对应东八区时间，即北京时间）。<br>示例： `2025-05-20T13:29:35+08:00` 表示北京时间2025年5月20日13点29分35秒。 |
| reject_reason | string(512) | false | 【驳回原因】 1、商家名片配置申请审核驳回的具体原因；<br>2、当申请单状态为「审核驳回」时有值。 |
| actual_publish_time | string(64) | false | 【实际发布时间】 1、定义：提交商家名片配置审核通过后，平台发布配置上线的实际时间。<br>2、返回条件：当且仅当申请单状态为「已发布」时，该字段才返回值。<br>3、格式：遵循 [rfc3339](https://datatracker.ietf.org/doc/html/rfc3339) 标准格式： `yyyy-MM-DDTHH:mm:ss+TIMEZONE`。 `yyyy-MM-DD` 表示年月日； `T` 字符用于分隔日期和时间部分； `HH:mm:ss` 表示具体的时分秒； `TIMEZONE` 表示时区（例如， `+08:00` 对应东八区时间，即北京时间）。<br>示例： `2025-05-20T13:29:35+08:00` 表示北京时间2025年5月20日13点29分35秒。 |
