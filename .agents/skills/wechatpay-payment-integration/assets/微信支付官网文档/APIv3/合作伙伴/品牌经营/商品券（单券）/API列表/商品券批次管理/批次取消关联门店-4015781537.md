>更新时间：2025.10.21

服务商可以通过该接口取消品牌的门店列表与商品券批次的关联关系

前置条件：

1. 已创建 `usage_mode` 不为 `PROGRESSIVE_BUNDLE` 的商品券对应的批次

2. 批次的 `store_scope` 为 `SPECIFIC`

3. 批次未失效或过期

4. `usage_mode` 为 `PROGRESSIVE_BUNDLE` 的批次在批次组内，不可使用本接口，请使用【[批次组批量取消关联门店API](https://pay.weixin.qq.com/doc/v3/partner/4016280629.md)\]





## 接口说明

支持商户：【普通服务商】

请求方式：【POST】 `/v3/marketing/partner/product-coupon/product-coupons/{product_coupon_id}/stocks/{stock_id}/disassociate-stores`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点

　　　　　【备域名】https://api2.mch.weixin.qq.com 使用该域名将访问异地的接入点，指引[点击查看](https://pay.weixin.qq.com/doc/v3/merchant/4012075113.md)

接口限频：20/秒（商户号维度）

## 请求参数

### Header 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| Authorization | string | true | 请参考 [签名认证](https://pay.weixin.qq.com/doc/v3/merchant/4012365342.md#%E8%AF%B7%E6%B1%82%E6%8E%A5%E5%8F%A3%E5%90%8E%E7%AB%AF%E7%AD%BE%E5%90%8D) 生成认证信息 |
| Accept | string | true | 请设置为 `application/json` |
| Content-Type | string | true | 请设置为 `application/json` |
### Path 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| product_coupon_id | string | true | 【商品券ID】 商品券的唯一标识， [创建商品券](https://pay.weixin.qq.com/doc/v3/partner/4015781289.md) 时由微信支付生成 |
| stock_id | string | true | 【批次ID】 商品券批次的唯一标识，商品券批次创建时由微信支付生成（可使用【 [创建商品券API](https://pay.weixin.qq.com/doc/v3/partner/4015781289.md)】或【 [添加商品券批次API](https://pay.weixin.qq.com/doc/v3/partner/4015781304.md)】创建），请确保该批次属于 `product_coupon_id` 对应的商品券，且 `store_scope` 为 `SPECIFIC`，否则无法取消关联门店 |
### Body 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| store_list | array[object] | true | 【门店列表】 商户欲取消关联的门店列表，<br>单次最多可批量取消200个门店 |
| store_list.store_id | string | true | 【门店ID】 门店的唯一标识，调用【 [创建品牌门店API](https://pay.weixin.qq.com/doc/v3/partner/4015783183.md)】时由微信支付生成 |
| brand_id | string | true | 【品牌ID】 微信支付为品牌方分配的唯一标识，该品牌应与服务商存在授权关系 |
## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| total_count | integer | true | 【去重后门店总数】 系统会自动对请求中的门店去重，这里是去重后的门店总数 |
| success_store_list | array[object] | false | 【取消关联成功的门店列表】 取消关联成功的门店列表 |
| success_store_list.store_id | string | true | 【门店ID】 门店的唯一标识，调用【 [创建品牌门店API](https://pay.weixin.qq.com/doc/v3/partner/4015783183.md)】时由微信支付生成 |
| failed_store_list | array[object] | false | 【取消关联失败的门店列表】 每个取消关联失败门店的详细错误信息 |
| failed_store_list.store_id | string | true | 【门店ID】 取消关联失败的门店ID |
| failed_store_list.code | string(40) | true | 【失败错误码】 门店取消关联失败的错误码 |
| failed_store_list.message | string(200) | true | 【失败错误信息】 门店取消关联失败的错误描述 |
