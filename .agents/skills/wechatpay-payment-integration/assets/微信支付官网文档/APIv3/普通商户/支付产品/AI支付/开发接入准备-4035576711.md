>更新时间：2026.08.27

推荐商家把接入AI专属卡的服务，以Skill形式发布到SkillHub平台。



## 1、整体流程

| 阶段 | 说明 |
| --- | --- |
| ① 支付资质准备 | 申请微信支付商户号（已有可跳过） |
| ② SkillHub 入驻 | 注册开发者 → 认证企业主体 → 开通 SkillPay 并绑定商户号 |
| ③ 商户 Skill 开发 | 开发 Skill（声明 AI 支付插件 + 实现业务逻辑） |
| ④ 支付接入 | 接入传统微信支付下单（Native / JSAPI） |
| ④ 支付接入 | 接入 x402 协议下单（使用 SkillHub 入驻密钥鉴权） |
| ⑤ 上架分发 | 在 SkillHub 上架 Skill，由平台代为分发到各智能体平台 |

## 2、详细说明

### 2.1、申请微信支付商户号

已有商户号可跳过此步。如未入驻，前往 [微信支付商户平台](https://pay.weixin.qq.com/) 完成入驻。

- 商户号类型需为普通直连商户（从商户平台直接入驻），或通过合作伙伴接入的子商户。

- 不支持无营业执照的小微商户、部分银行子商户。

- 自行判断是否支持的标准：商户号必须拥有微信支付商户平台网页端的登录与操作权限。


### 2.2、SkillHub 入驻与密钥获取

详细指引见：[SkillHub Pay Skill 接入文档](https://skillhub.cn/tutorials#agent-pay-onboard)，流程如下：

1、注册开发者 — 前往 [SkillHub 官网](https://skillhub.cn/) 注册并完成开发者入驻。

2、认证企业主体 — 完成企业主体认证，确保商户资质与企业身份绑定。

3、开通 SkillPay 并绑定商户号 — 开通 SkillPay 功能模块，绑定微信支付商户号。完成后将获得用于 x402 下单鉴权的开发者密钥。

### 2.3、开发商户 Skill

开发 Skill 时需声明 AI 支付插件能力，并实现对应的业务逻辑。

### 2.4、支付接入

- 传统支付：对接微信支付 Native / JSAPI 下单接口。

- x402 协议：使用 Step 2 获取的开发者密钥进行鉴权，完成 x402 协议下单。


### 2.5、上架与分发

在 SkillHub 完成上架，由 SkillHub 代为分发到各智能体平台。
