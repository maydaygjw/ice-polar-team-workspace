>更新时间：2026.09.01

Agent 触发 x402 支付的场景下，服务开发者需调用该接口在微信支付侧完成预下单，生成用于触发支付的一次性支付凭证(payment\_code)。




## 接口说明

支持调用方：【SKILLHUB 服务开发者】

请求方式：【POST】/aipay/preorder

请求域名：【主域名】https://aipay.wxpapp.weixin.qq.com

## 请求参数

### Header 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| Authorization | string | true | 请参考本文「 [签名指引](https://pay.weixin.qq.com/doc/v3/merchant/4035576740.md#%E7%AD%BE%E5%90%8D%E6%8C%87%E5%BC%95)」章节生成认证信息，认证类型固定填 `SKILLHUB-SHA256-RSA2048`。 |
| Accept | string | true | 请设置为 `application/json` |
| Content-Type | string | true | 请设置为 `application/json` |
### Body 参数
| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| payment_required | object | true | 【预下单信息】x402 预下单的业务信息主体，所有业务字段均包含在该对象内。 |
| payment_required.skill_info | object | true | 【Skill 信息】Skill 信息对象。SKILLHUB 平台必填。 |
| payment_required.skill_info.skill_id | string(64) | true | 【Skill 标识】Skill 标识，对应 Skill 定义中的 name。SKILLHUB 平台必填。 |
| payment_required.skill_info.skill_version | string(64) | true | 【Skill 版本号】Skill 的版本号。SKILLHUB 平台必填。示例：1.0.0 |
| payment_required.pay_type | string | true | 【支付类型】当前支持的取值：<br><ul><li>`GOODS_PAY`：商品付费，即按商业支付订单付费。</li></ul> |
| payment_required.pay_mode | string | true | 【付费方式】当前支持的取值：<br><ul><li>`AUTH_AND_PAY`：授权即支付，当前仅支持该方式。</li></ul> |
| payment_required.expires_at | string | true | 【授权超时时间】Unix 秒级时间戳字符串，用户须在该时间之前完成授权，最长 15 分钟。该时间同时作为应答返回的 payment\_code 的有效期（仅为请求字段，应答不回显）。示例：1747901100 |
| payment_required.pay_items | array[object] | true | 【支付信息列表】支付信息列表，至少传入 1 条。 |
| payment_required.pay_items.product_id | string(64) | true | 【产品标识】产品标识。SKILLHUB 平台必填。 |
| payment_required.pay_items.pay_data | object | true | 【支付信息】支付信息对象。 |
| payment_required.pay_items.pay_data.type | string | true | 【支付信息类型】支持的取值： `code_url` / `prepay_id` / `h5_url`。 |
| payment_required.pay_items.pay_data.value | string(64) | true | 【支付信息内容】按 type 填入对应下单接口的返回值。 |
## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| payment_code | string(64) | true | 【一次性支付凭证】用于触发支付的一次性凭证。有效期对应请求传入的 expires\_at（最长 15 分钟）；凭证过期或已被使用后，需重新调用本接口获取新的 payment\_code。 |
## 签名指引

本接口使用密钥提供方（developer\_platform）分配的密钥签名，签名方式与微信支付 v3 API 一致。

### 构造待签名串

签名串由 5 行组成，每行以 `\n` 结尾（包括最后一行）：

```
HTTP请求方法\n
URL\n
请求时间戳\n
请求随机串\n
请求报文主体\n
```

具体到预下单接口：

| 行 | 内容 | 说明 |
| --- | --- | --- |
| 第 1 行 | POST | HTTP 请求方法 |
| 第 2 行 | /aipay/preorder | 接口 URL 路径 |
| 第 3 行 | timestamp | 时间戳字符串原值 |
| 第 4 行 | nonce\_str | 随机串原值 |
| 第 5 行 | 请求报文主体 | 请求报文主体 |

### 计算签名

示例（伪代码）：

```
signature = Base64( RSA_Sign( developer_private_key, SHA256(sign_string_bytes) ) )
```

- 算法：使用密钥提供方（developer\_platform）分配的密钥做非对称签名；具体算法标识填入 signature\_type。

- 密钥：密钥提供方为该开发者分配的密钥（与 pub\_key\_id 公钥 ID 配对）。

- 输出：Base64 编码字符串。


### 构造 Authorization 头

```
Authorization: <认证类型> <签名值>
```

认证类型目前只支持 `SKILLHUB-SHA256-RSA2048`，签名值为多个 key="value" 以英文逗号拼接的字符串。

| Key | 说明 |
| --- | --- |
| developer\_platform | 支持 SKILLHUB，按实际的密钥提供方填写 |
| developer\_id | 根据 developer\_platform 填入对应平台颁发的 Id |
| pub\_key\_id | 按 developer\_platform 对应填写：其分配的公钥 ID，对应其签名所用的密钥（无证书，使用公钥 ID 标识） |
| nonce\_str | 随机串，参与签名，每次请求须唯一，建议长度 16~32 字符 |
| timestamp | Unix 时间戳秒级字符串，参与签名，表示签名生成时刻。示例："1747900200" |
| signature | 用 developer\_platform 对应分配的密钥对上述签名串做非对称签名，Base64 编码 |

示例值：

```
Authorization: SKILLHUB-SHA256-RSA2048 developer_platform="SKILLHUB",developer_id="dev_1234567890",pub_key_id="PUBKEY_ABC001",nonce_str="a1b2c3d4e5f60718",timestamp="1747900200",signature="MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA..."
```

## 错误码

出错时 HTTP 状态码也会相应变化：4xx 代表逻辑错误（如参数校验失败、签名错误、鉴权失败等），5xx 代表系统错误（如后台服务异常）。

| 状态码 | 错误码 | 描述 | 解决方案 |
| --- | --- | --- | --- |
| 4xx | 逻辑错误类错误码 | 参数校验失败、签名错误、鉴权失败等 | 请根据应答中的 code 与 message 检查请求参数与签名 |
| 5xx | SYSTEM\_ERROR | 系统异常，请稍后重试 | 请稍后使用相同参数重新调用 |

请求示例

> POST

```
curl -X POST \
  https://aipay.wxpapp.weixin.qq.com/aipay/preorder \
  -H "Authorization: SKILLHUB-SHA256-RSA2048 developer_platform=\"SKILLHUB\",developer_id=\"dev_1234567890\",pub_key_id=\"PUBKEY_ABC001\",nonce_str=\"a1b2c3d4e5f60718\",timestamp=\"1747900200\",signature=\"MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...\"" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
    "payment_required" : {
      "skill_info" : {
        "skill_id" : "skill_id",
        "skill_version" : "1.0.0"
      },
      "pay_type" : "GOODS_PAY",
      "pay_mode" : "AUTH_AND_PAY",
      "expires_at" : "1754208460",
      "pay_items" : [
        {
          "product_id" : "product_id",
          "pay_data" : {
            "type" : "prepay_id",
            "value" : "wx201410272009395522657a690389285100"
          }
        }
      ]
    }
  }'
```

应答示例

> 200 OK

```
{
  "payment_code" : "xY9zAbc123def456"
}
```

接口执行出错时，返回如下结构的错误应答：

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| code | string(32) | true | 【错误码】标识错误类型的错误码。 |
| message | string(256) | true | 【错误描述】错误的详细描述信息。 |

错误应答示例

```
{
  "code" : "SYSTEM_ERROR",
  "message" : "系统异常，请稍后重试"
}
```
