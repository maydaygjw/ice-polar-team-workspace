### 调起支付步骤：

1、通过[Native下单](https://pay.weixin.qq.com/doc/v3/merchant/4012791877.md)接口获取到发起支付的必要参数 `code_url`。

2、将 `code_url` 链接转换为二维码图片后，展示给用户。

示例：将 weixin://pay.weixin.qq.com/bizpayurl/up?pr=NwY5Mz9&groupid=00 生成二维码见下图

![](https://gtimg.wechatpay.cn/resource/xres/mmpaydoc/static/img/e85efb403e73a5f9556837967f789f28.png)

3、用户打开微信“扫一扫”功能，扫描二维码，进行Native支付。
