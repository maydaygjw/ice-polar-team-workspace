>更新时间：2025.03.31

用户在商户前端选择微信支付后，商户需要调用该接口在微信支付下单，生成用于[调起支付](https://pay.weixin.qq.com/doc/v3/merchant/4012791878.md)的二维码链接 `code_url`。




## 接口说明

支持商户：【普通商户】

请求方式：【POST】 `/v3/pay/transactions/native`

请求域名：【主域名】https://api.mch.weixin.qq.com 使用该域名将访问就近的接入点

　　　　　【备域名】https://api2.mch.weixin.qq.com 使用该域名将访问异地的接入点，指引[点击查看](https://pay.weixin.qq.com/doc/v3/merchant/4012075113.md)

## 应答参数

200 OK

| 参数名 | 类型 | 必填 | 描述 |
| --- |  --- | --- | --- |
| code_url | string(64) | true | 【二维码链接】 此URL用于生成支付二维码，然后提供给用户扫码支付。code\_url有效期为2小时，失效后需要重新请求该接口以获取新的code\_url。<br>注意：code\_url并非固定值，使用时按照URL格式转成二维码即可。 |
