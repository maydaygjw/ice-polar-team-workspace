>更新时间：2025.03.26

1、请确认prepay\_id的格式是否正确

app调起支付的为

```
wx201410272009395522657a690389285100
```

而jsapi调起支付和小程序的为

```
prepay_id=wx201410272009395522657a690389285100
```

2、调起支付与下单计算签名使用的商户API证书不一致

请确保调起支付与下单计算签名使用的商户API证书是同一份
