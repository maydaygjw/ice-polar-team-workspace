## curl


> POST

失效商品券

```
curl -X POST \
  https://api.mch.weixin.qq.com/brand/marketing/product-coupon/product-coupons/1000000013/deactivate \
  -H "Authorization: WECHATPAY-BRAND-SHA256-RSA2048 brand_id=\"XXXX\",..." \
  -H "Accept: application/json" \
  -H "Wechatpay-Serial: PUB_KEY_ID_XXXX"  \
  -H "Content-Type: application/json" \
  -d '{
    "out_request_no" : "34657_20250101_123456",
    "deactivate_reason" : "商品券信息有误，重新创建"
  }'

```
