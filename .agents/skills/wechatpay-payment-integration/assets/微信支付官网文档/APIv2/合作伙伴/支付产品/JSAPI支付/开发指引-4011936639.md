业务流程时序图

```mermaid
sequenceDiagram
  autonumber
  actor p0 as 用户
  participant p1 as 微信支付客户端
  participant p2 as 商户系统后台
  participant p3 as 微信支付系统
  p0->>p2: 平台下单，发起支付
  p2->>p2: 生成平台订单
  p2->>p3: 请求下单接口，创建订单
  p3->>p3: 生成预付单
  p3-->>p2: 预付单标识
  p2->>p2: 生成带签名支付信息
  p0->>p2: 发起支付
  p2->>p1: 调起微信支付
  p1->>p3: 发起支付请求
  p3->>p3: 验证支付授权权限
  p3-->>p1: 支付授权
  p0->>p1: 确认自己付，输入密码
  p1->>p3: 提交授权限
  p3->>p3: 验证授权
  alt 获取订单支付状态
    p3->>p2: 异步通知平台支付结果
    p2->>p2: 保存支付通知
    p2-->>p3: 告知成功接收处理
    p3-->>p1: 支付结果，并发微信消息提醒
  end
  p1->>p2: 支付状态查询
  alt 判断支付状态：未收到支付回调通知
    p2->>p3: 调用查单接口，查询支付结果
    p3-->>p2: 支付结果
  end
  p2-->>p0: 展示支付消息
```

图7.9 微信内网页支付时序图

商户系统和微信支付系统主要交互：

1.商户server调用统一下单接口请求订单，api参见公共api【[统一下单API](https://pay.weixin.qq.com/doc/v2/partner/4011936644.md)】

2.商户前端可通过【[JSAPI调起支付API](https://pay.weixin.qq.com/doc/v2/partner/4011936643.md)】调起微信支付，发起支付请求。

3.商户server接收支付通知，api参见公共api【[支付结果通知API](https://pay.weixin.qq.com/doc/v2/partner/4011936650.md)】

4.商户server查询支付结果，api参见公共api【[查询订单API](https://pay.weixin.qq.com/doc/v2/partner/4011936645.md)】（查单实现可参考：[支付回调和查单实现指引](https://pay.weixin.qq.com/doc/v2/partner/4011984698.md)）
