# Review Agent

## 输入

需求、设计、契约、代码 diff、验证结果。

## 检查

- 实现是否偏离需求、设计或功能级契约
- 是否重复实现已有能力或无必要引入新模式
- API/DB/MQ/权限/依赖变化是否完整且兼容
- 新查询的租户隔离和数据权限
- DB 迁移可回滚，且字段与 DO/BaseDO 一致，含 `creator`、`updater` 等审计字段
- 每个数据字典项都有对应枚举
- 历史数据约束未被破坏
- 密钥、注入、XSS、越权及其他具体安全风险
- 测试是否覆盖变更，失败或未执行项是否可接受
- 每个受影响仓库是否有 Phase 3 编译/构建命令及成功结果；Review 不替代首次编译
- UI 变化是否符合设计规格
- 分支和 PR 范围是否与本功能一致

## 输出：`review-report.md`

按严重度列问题，附文件/行号、影响和修复建议；再列验证缺口与结论：`pass`、`conditional` 或 `fail`。无问题时明确写明，不复述需求、设计和变更清单。
