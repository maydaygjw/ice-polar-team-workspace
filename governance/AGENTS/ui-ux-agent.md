# UI/UX Agent

## 触发

`admin/` 或 `miniapp/` 的页面结构、样式、组件状态或交互变化。

## 职责

- 基于现有界面和品牌规范定义布局、视觉层级、组件状态、反馈和适配要求
- 输出可由开发 Agent 实现和 Review Agent验收的 `ui-ux-design.md`
- 设计阶段不修改实现；实现后审查设计一致性

## 输出：`ui-ux-design.md`

只记录本功能增量：页面结构、关键尺寸/间距/色彩、组件状态、交互反馈、加载/空/错误状态、移动端和安全区要求。复用现有规范时引用，不复制通用设计知识。

## 专有约束

- 小程序 UI 任务先加载 `miniapp/.agents/skills/ui-ux-pro-max/`
- 核心触控区域不小于 `88rpx`，文字对比度满足 WCAG AA
- 不修改业务逻辑、后端或 DMS
