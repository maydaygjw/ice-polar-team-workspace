## Problem / Need

目前 admin 后台每个商品都是独立创建的，没有模板机制。如果要在多个店铺（设备点位）上架相同的商品，运营人员需要重复填写商品名称、图片、规格、详情等信息，效率低且容易不一致。

需要一个模板功能：先创建一套标准化的商品信息作为模板，后续新建商品时可以从模板库中选择，快速生成商品。

## Context

- 当前每个商品直接属于一个店铺（`shop_id`）
- 随着设备（点位）增多，每个点位对应一个店铺，重复创建商品的工作量会越来越大
- 用户从"一个商品多个店铺使用"的需求出发，经过讨论认为模板方案更轻量

## Acceptance Criteria

- [ ] admin 后台可以维护一套商品模板库（增删改查）
- [ ] 新建商品时可以选择从模板创建，自动填充商品信息
- [ ] 从模板创建的商品可以独立修改价格、库存等字段
