## Problem / Need

平台当前默认假设每个微信小程序身份只对应一个会员账号，但不同租户的会员认证规则并不相同：

- 有些租户以手机号作为会员账号，同一个微信身份可能需要关联多个不同手机号账号；
- 有些租户没有手机号，会员需要直接使用微信小程序身份完成认证；
- 同一微信身份关联多个账号时，用户重新进入小程序不应因账号关联数量增加而登录失败；
- 不同租户应能够按照自身业务选择合适的会员认证方式。

需要建立适用于多租户平台的会员认证规则，使手机号账号、微信小程序身份和自动登录行为能够符合各租户的实际业务，同时避免用户被错误登录到其他账号。

## Context

- 租户 153 已出现同一个微信小程序身份关联两个不同手机号会员账号的实际场景。
- 手机号登录和微信小程序启动后的自动恢复登录属于不同场景，账号选择依据也应不同。
- 部分租户可能只使用微信小程序身份，不具备手机号登录条件。

## Acceptance Criteria

- [ ] 租户可以使用适合自身业务的会员认证方式，包括手机号认证或微信小程序身份认证。
- [ ] 支持同一微信小程序身份关联多个手机号会员账号的租户场景。
- [ ] 同一微信身份关联多个账号时，小程序重新进入不会因账号数量产生登录异常。
- [ ] 用户使用手机号认证时，能够稳定进入对应手机号账号。
- [ ] 不使用手机号的租户能够仅凭微信小程序身份完成会员认证。
- [ ] 不同租户之间的会员身份和认证规则相互隔离。
