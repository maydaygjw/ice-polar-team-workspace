# 优惠券小程序码

## Scope

在管理后台优惠券列表的每条记录增加“生成二维码”入口。后端基于当前管理租户读取已关联的主小程序，生成进入 `/home/index/index` 并携带 `couponId` 的真实微信小程序码，同时返回可复制的页面链接。

## Use Cases

- 管理员在优惠券列表点击“生成二维码”。
- 系统为当前租户的主小程序生成优惠券码，并在弹窗中展示链接和二维码。
- 管理员复制链接或下载二维码图片，用于线下投放。

## Business Rules

- 链接不携带 `tenantId`；租户仅用于服务端选择主小程序和隔离优惠券数据。
- 小程序页面固定为 `/home/index/index`，场景值为 `couponId={优惠券ID}`。
- 只能为当前租户可访问的优惠券生成二维码。
- 当前租户未配置主小程序时，返回明确错误，不生成二维码。
- 生成的是微信真实小程序码，不使用浏览器二维码替代。

## Frontend Requirements

- 在列表“操作”列增加“生成二维码”按钮，并沿用权限指令。
- 弹窗展示优惠券名称、完整链接和二维码。
- 提供复制链接和下载二维码操作；接口加载和失败状态可见。

## Edge Cases

- 优惠券不存在、已删除或不属于当前租户：按现有业务异常处理。
- 微信接口失败：提示生成失败原因，不展示旧数据。
- 链接较长时允许换行或横向滚动，不能截断复制内容。

## Acceptance Criteria

1. 点击任意可访问优惠券的“生成二维码”后，弹窗显示 `/home/index/index?couponId={id}` 链接。
2. 返回的二维码由当前租户主小程序生成，扫码可进入指定页面并携带优惠券 ID。
3. 未配置主小程序时，管理员收到明确错误提示。
4. 可复制完整链接并成功下载 PNG/JPG 二维码文件。
5. 后端和前端校验命令通过，且不引入密钥或数据库结构变更。

## Assumptions

- 当前登录管理请求已携带租户上下文，接口不额外接收 `tenantId`。
- 后端现有小程序账号服务和二维码文件服务可复用；二维码文件地址使用现有管理端可访问路径。
