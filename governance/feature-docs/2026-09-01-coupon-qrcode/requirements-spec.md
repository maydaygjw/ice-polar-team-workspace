# 优惠券小程序码

## Scope

在管理后台增加优惠券二维码入口。后端基于当前管理租户读取已关联的主小程序和租户参数 `coupon_mini_app_page`，根据优惠券兑换类型选择页面参数：无码券携带 `couponId`，通用码和一卡一码携带 `cdkey`，生成真实微信小程序码，同时返回可复制的页面链接。

## Use Cases

- 管理员在优惠券列表点击“生成二维码”。
- 无码券：系统为当前租户的主小程序生成携带 `couponId` 的小程序码，并在弹窗中展示链接和二维码。
- 通用码：系统使用该券已配置的通用 `cdkey` 生成小程序码。
- 一卡一码：管理员在兑换码记录中选择具体未兑换的 `cdkey` 生成小程序码；每个二维码只对应这一张兑换码。
- 管理员复制链接或下载二维码图片，用于线下投放。

## Business Rules

- 链接不携带 `tenantId`；租户仅用于服务端选择主小程序和隔离优惠券数据。
- 小程序页面路径从当前租户参数 `coupon_mini_app_page` 读取；未配置时禁止生成并提示配置。
- `getType=0`（无码/页面领取）时，场景值和页面查询参数为 `couponId={优惠券ID}`。
- `getType=1`（通用码）时，场景值和页面查询参数为 `cdkey={通用兑换码}`；服务端只能使用属于当前优惠券的通用码。
- `getType=2`（一卡一码）时，场景值和页面查询参数为 `cdkey={具体兑换码}`；请求必须指定属于当前优惠券且状态为未兑换的兑换码，不得自动挑选其他兑换码，也不得回退为 `couponId`。
- 只能为当前租户可访问的优惠券生成二维码。
- 当前租户未配置主小程序时，返回明确错误，不生成二维码。
- 生成的是微信真实小程序码，不使用浏览器二维码替代。

## Frontend Requirements

- 在列表“操作”列增加“生成二维码”按钮，并沿用权限指令。
- 无码券和通用码从优惠券列表生成；一卡一码不在券模板列表生成，改为在“查看兑换码”的具体记录行生成。
- 弹窗展示优惠券名称、完整链接和二维码。
- 提供复制链接和下载二维码操作；接口加载和失败状态可见。

## Edge Cases

- 优惠券不存在、已删除或不属于当前租户：按现有业务异常处理。
- 通用码未配置、指定的一卡一码不存在、已删除或已兑换：提示兑换码无效，不生成二维码。
- 微信接口失败：提示生成失败原因，不展示旧数据。
- 链接较长时允许换行或横向滚动，不能截断复制内容。

## Acceptance Criteria

1. `getType=0` 的优惠券生成 `{coupon_mini_app_page}?couponId={id}` 链接，扫码进入指定页面并携带优惠券 ID。
2. `getType=1` 的优惠券生成 `{coupon_mini_app_page}?cdkey={code}` 链接，扫码进入指定页面并按通用兑换码领取。
3. `getType=2` 的兑换码记录生成 `{coupon_mini_app_page}?cdkey={code}` 链接；已兑换、已删除或不属于该券的兑换码不能生成。
4. 返回的二维码由当前租户主小程序生成，且链接参数与二维码场景参数一致。
5. 未配置主小程序或优惠券页面路径时，管理员收到明确错误提示。
6. 可复制完整链接并成功下载 PNG/JPG 二维码文件。
7. 后端和前端校验命令通过，且不引入密钥或数据库结构变更。

## Assumptions

- 当前登录管理请求已携带租户上下文，接口不额外接收 `tenantId`。
- 后端现有小程序账号服务和二维码文件服务可复用；二维码文件地址使用现有管理端可访问路径。
