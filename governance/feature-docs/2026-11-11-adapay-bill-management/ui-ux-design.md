# UI/UX 设计 — AdaPay 对账单管理

## 页面结构

管理后台新增页面 `对账单管理`，与“日终对账记录”同级。页面为宽表格工作台，首屏直接提供月份日历、日期下载操作和账单明细。

```text
标题：对账单管理
├─ 左侧 320px：月份日历 + 下载状态图例
└─ 主区域
   ├─ 工具栏：账单日期、下载/重新拉取按钮、当前状态、ZIP 版本入口
   ├─ 版本摘要：Charge / Confirm / Div 行数、ZIP 版本、完成时间、文件摘要
   ├─ 明细页签：Charge、PaymentConfirm、Div
   └─ 当前页签对应的分页表格
```

## 布局与组件

- 日历最大宽度 320px，与主区域间距 16px；页面整体保持 Element Plus 后台默认内容边距。
- 日历日期使用 40px 高单元格；非当前月日期弱化，今天仅描边，不使用大色块。
- 日期状态使用可见且语义明确的图标：成功显示绿色下载完成图标并带“已下载”状态文字；失败显示红色错误图标；下载中显示蓝色加载图标；未下载显示灰色状态。图标需确保在浅色背景下可辨认，并提供可访问名称/Tooltip。
- 工具栏中的日期选择器宽 160px；下载和重新拉取使用主要按钮，ZIP 版本使用普通按钮。
- 版本摘要采用一行四段的紧凑统计区，不使用嵌套卡片；每项包含标签和值。
- 明细页签固定在摘要下方。Charge 表格列多，容器允许横向滚动，首列行号和支付 ID 保持可见。
- 每个页签在表格上方提供筛选区：Charge 为支付ID、商户订单号；PaymentConfirm 为商户支付ID；Div 为商户支付ID、MemberId。筛选控件与表格分页使用 `vuex-table` 的查询表单和分页能力，筛选后回到第一页。
- 三类表格均增加商家名称列；未关联到商家时显示 `—`。
- ZIP 版本入口打开右侧抽屉，宽 520px；版本列表包含版本号、文件名、大小、完成时间和下载按钮。

## 日历折叠交互

- 日历卡片支持折叠/展开，默认展开。
- 折叠后保留月份标题、月份切换、本月按钮和已选日期摘要，隐藏月历网格与状态图例；主区域自动扩展使用释放的空间。
- 展开/折叠不改变当前账单日期和筛选条件。

## 交互状态

- 页面加载：日历和日详情分别显示局部加载，不阻塞整个页面。
- 选择日期：更新工具栏日期，加载该日期最新成功版本；无数据时明细显示空状态，并保留下载按钮。
- 点击“下载”：立即禁用按钮并创建任务，每 2 秒轮询任务状态；轮询期间日历日期显示下载中。
- 下载成功：提示成功，刷新日历、日详情、当前页签和 ZIP 版本列表。
- 下载失败：显示后端返回的失败原因，按钮恢复可用；旧明细不清空。
- 对已成功日期点击“重新拉取”：弹出确认框，明确提示“解析明细将替换为最新 ZIP，历史 ZIP 仍保留”。
- 切换明细页签：保留当前日期，加载对应分页，不重新请求日历。
- 表格分页：使用 `vuex-table` 展示服务端分页数据，仅当前页签请求数据；筛选条件变化后回到第一页，清空条件恢复全部结果。
- ZIP 下载：按钮进入 loading，成功保存为 `bill_YYYY-MM-DD_vN.zip`；失败时提示“ZIP 下载失败”。

## 空态、错误与文案

- 未选择日期：主区域显示“请选择账单日期”。
- 日期未下载：版本摘要显示 `—`，三类明细显示“暂无账单数据”。
- 下载中：状态标签为“下载中”，禁止重复提交。
- 最近任务失败：工具栏状态标签为“下载失败”，下方展示 `errorSummary`。
- 权限不足：不显示下载按钮；查询接口失败时展示统一错误提示。
- 表格列值为空时显示 `—`，不得显示 `null`。
- 金额和状态只展示账单原文，不追加“成功”“失败”等业务解释。

## 视觉规范

- 复用现有管理后台 Element Plus 色彩、字体、按钮和表格规范。
- 成功 `#67C23A`，失败 `#F56C6C`，下载中 `#409EFF`，未下载 `#909399`。
- 表格字号沿用现有小表格密度；横向滚动条仅在列容器内出现。
- 不使用新的品牌色、营销式图形或装饰性插画；页面重点是日历状态、原始流水和审计入口。
