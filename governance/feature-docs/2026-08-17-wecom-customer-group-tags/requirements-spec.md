# 企业微信客户群标签

## Scope

在企业微信客户群管理页面增加群标签维护和批量打标能力，并在企业群发创建时支持按群标签选择客户群。

## Business rules

- 群标签是系统业务标签，绑定企业微信配置和客户群 `chat_id`，不写入企业微信客户标签。
- 同一企业微信配置下标签名称唯一；标签删除时同步解除全部群关联。
- 多个筛选标签使用并集：客户群命中任一标签即可进入群发范围。
- 群发目标为空时禁止提交；群发任务仍由企业微信成员在客户端确认后执行。
- 所有标签、关联和群发查询遵守租户隔离及现有客户群权限。

## Acceptance criteria

- 客户群页面存在“群标签”按钮，可新增、编辑、删除标签。
- 可勾选多个客户群，批量添加或移除一个或多个标签，并反馈处理结果。
- 客户群列表显示标签，支持按一个或多个标签筛选。
- 群发弹窗可按标签筛选群、展示目标数量并创建企业微信群发任务。
- 企业微信失败的群 ID 和任务 ID 可反馈给管理端；不泄露 Secret。
