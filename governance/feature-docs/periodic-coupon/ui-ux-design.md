# UI/UX 增量 — 普通券与周期券

## 后台优惠券表单

- 在优惠券名称附近增加“券类型”单选：普通券、周期券；默认普通券。
- 周期券显示“发放周期”：发放开始时间、发放截止时间、每 N 天发放一次，N 默认 1。
- 周期券将用券时间固定展示为“领取后立即生效，有效期 X 天”；隐藏固定时间和无限制时间选项。
- 周期券显示说明“每个发放周期每人限领 1 次”，不再让管理员配置跨周期总次数。
- 周期券兑换码类型固定显示为“无码（页面领取）”，隐藏通用码和一卡一码选项。
- 校验错误在对应表单项下方提示，重点覆盖起止时间、周期天数、有效天数。

## 列表

- 增加“券类型”列，显示普通券/周期券。
- 兑换码类型列保留普通券的现有展示，不增加展示开关；周期券显示无码。
