# 企业微信客户标签库管理 UI/UX 设计

- 菜单归属：企业微信；菜单名称：客户标签；页面组件：`WecomCustomerTag`。
- 顶部使用企业微信配置选择器和“刷新”按钮；未选择账号时不请求接口。
- 主体采用左右分栏：左侧标签组列表，右侧当前组的标签列表；选中组有明显高亮。
- 标签组区域提供“新增标签组”、编辑、删除；标签区域提供“新增标签”、编辑、删除。
- 新增标签组弹窗包含组名称、组排序和至少一行标签名称/排序；新增标签弹窗只选择当前组并填写标签名称/排序。
- 编辑弹窗根据对象类型显示名称和排序；名称最多 30 个字符，排序为非负整数。
- 删除弹窗明确显示“删除标签组/删除标签”和对象名称；删除标签组时提示会删除组内标签。
- 加载时显示骨架/加载状态；无账号显示引导选择账号，无标签组显示空状态，标签列表为空显示“该组暂无标签”。
- 实时请求失败时使用错误提示并保留上一次已显示内容；提供刷新重试，不把失败操作标记为成功。
- 操作按钮遵循 `v-hasPermi` 权限控制；按钮最小触控区域沿用现有管理端规范。
