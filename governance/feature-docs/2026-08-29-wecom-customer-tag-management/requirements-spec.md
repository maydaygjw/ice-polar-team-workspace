# 企业微信客户标签库管理需求规格

## Scope

### In

- 租户管理员选择已有企业微信配置，实时查看该企业的客户标签组和标签。
- 创建标签组时同时创建至少一个标签；向已有标签组新增一个或多个标签。
- 修改标签组或标签的名称、排序值。
- 删除标签组或标签，并将企业微信返回的失败原因反馈给管理员。
- 在企业微信目录下提供独立的“客户标签”管理页面，与现有“客户群标签”区分。

### Out

- 不给具体企业微信客户添加、移除或查询客户标签。
- 不在本地保存标签组、标签快照，不新增业务表或同步任务。
- 不修改现有客户群标签、客户联系人、小程序功能。

## Use Cases

- **查看标签库**：租户管理员选择企业微信配置后查看标签组、标签名称、排序和创建时间。
- **维护标签组**：管理员创建标签组并同时创建首批标签，或修改/删除标签组。
- **维护标签**：管理员在指定标签组下新增标签，或修改/删除标签。

## Business Rules

- 所有请求必须绑定当前租户下的已有企业微信配置；不能跨租户或跨配置操作。
- 标签组名称在企业微信企业范围内不可重复；同一标签组内标签名称不可重复。
- 企业微信不支持创建空标签组，因此新标签组必须至少包含一个标签。
- 标签组和标签名称最长 30 个字符；排序值为企业微信允许的非负整数范围。
- 删除标签组会删除该组下的企业微信标签；删除组内全部标签时企业微信可能自动删除标签组。
- 页面数据以实时企业微信响应为准；企业微信后台直接变更后，刷新页面即可看到最新结果。
- Secret、access token 和外部接口原始敏感凭证不得返回管理端或写入日志。

## Frontend Requirements

- 页面提供企业微信配置选择器；未选择配置时不发起标签请求并展示空状态。
- 以左侧标签组、右侧标签明细的方式展示；显示标签组/标签名称、排序和创建时间。
- 提供新增标签组、新增标签、编辑和删除操作，并按权限隐藏或禁用操作按钮。
- 删除前展示对象类型和名称；外部调用失败时保留当前页面数据并展示可理解的错误。
- 页面具备加载中、空数据、无权限、凭证失效和网络异常状态。

## Edge Cases

- 企业微信配置不存在、凭证失效或应用没有客户标签管理权限。
- 企业微信被其他入口同时修改，导致名称重复、对象已删除或对象 ID 失效。
- 新建标签组未填写标签、标签名称重复、名称超过 30 个字符或排序值越界。
- 删除标签组时组内仍有标签；删除单个标签后企业微信自动删除空组。
- 外部接口超时或返回非零 `errcode`；不得把操作显示为成功。

## Acceptance Criteria

- 管理员选择配置后能够实时看到企业微信当前标签组和标签，不依赖本地快照。
- 能创建带首个标签的标签组，并能在已有标签组下新增标签。
- 能修改标签组/标签名称和排序；企业微信重名校验失败时页面显示失败原因。
- 能分别删除标签或标签组；删除失败时不刷新为虚假的成功状态。
- 不同租户无法通过接口使用其他租户的企业微信配置。
- 管理端任何响应、页面和日志均不暴露 Secret 或 access token。
- 后端目标模块编译/测试通过，管理端类型检查和目标构建通过。

## Assumptions

- 复用 `mp_wecom_account` 中的 CorpID、客户联系 Secret 和 AgentId；不新增凭据配置。
- 本期菜单名称使用“客户标签”，页面功能名使用“企业微信客户标签库管理”。
- 实时读取不引入本地审计快照；外部接口失败由统一业务异常返回。
