# 活动管理 UI/UX 增量设计

## 页面结构

菜单位于“营销 → 活动管理”，包含“活动配置、活动期次、报名记录、中奖记录”四个入口。活动配置列表作为默认入口，期次、报名和中奖页面通过活动行操作进入并携带筛选上下文。

## 活动配置列表

- 顶部筛选：活动标题、商圈、启用状态；右侧提供“新建活动”。
- 表格：标题、商圈、周期、下次开奖时间、启用状态、操作。
- 行操作：编辑、启停、生成期次、查看期次；删除仅在无期次时展示或可用。
- 空状态提供“暂无活动，点击新建”；加载中使用现有列表 skeleton/加载状态。

## 活动编辑

- 使用现有 `Dialog`/`el-form` 表单模式，按“基础信息、时间规则、活动内容、企微/社群条件、奖品配置”分组。
- 时间字段分开展示日期与时间；报名结束时间与开奖时间相同的场景需给出明确提示。
- 富文本编辑器沿用项目现有 `Editor`；图片上传分别标注“活动图、活动背景图、渠道宣传素材”，避免误用。
- 活动管理员和社群标签使用已有选择组件，并分别与对应企微校验开关联动；未启用对应校验时，相关选择项隐藏。活动社群只选择群标签，不选择具体活动群。
- 奖品使用可增删的子表单；每行显示名称、图片、数量、领取说明，底部实时显示计划中奖人数。

## 期次与结果

- 期次列表展示活动标题、期次时间、报名区间、开奖时间、报名人数、计划/实际中奖人数和状态。
- 期次详情提供“报名记录、中奖记录、生成小程序码”操作；生成小程序码时允许输入可选渠道码；开奖前允许手动开奖时显示二次确认。
- 小程序码生成成功后在弹窗中展示预览图、复制地址、下载按钮和“临时地址，预计 48 小时有效”提示；失败保留重试入口。
- 报名/中奖列表使用现有分页表格，提供用户、状态、奖品筛选；无数据时展示明确空状态。

## 反馈与安全

- 创建、更新、启停、生成期次、开奖和二维码生成均使用 `useMessage()` 提示成功/失败。
- 禁止操作时展示后端业务原因，不仅显示通用“操作失败”。
- 已生成期次的模板编辑页显示历史快照保护提示；涉及期次的数据只读。
- 操作按钮遵循权限指令；二维码 URL 不在列表中长期持久化展示，避免误认为永久链接。
