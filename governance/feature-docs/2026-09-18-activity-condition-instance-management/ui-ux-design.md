# 活动报名条件实例管理 UI 设计

## 条件实例管理页

### 页面结构

- 页面标题：报名条件管理。
- 顶部筛选：实例名称/类型关键词、条件类型、启用状态；提供查询、重置、新增按钮。
- 主表：实例名称、条件类型、类别、参数摘要、说明、启用状态、模板引用数、更新时间、操作。
- 操作列：编辑、启用/停用、删除。

### 新增/编辑弹窗

- 使用现有 `Dialog` + `el-form`，沿用活动管理页面的表单布局和消息反馈。
- 条件类型：新增时可选，编辑时禁用；选项显示“实例类型名称 + 类型标识”。
- 实例名称：必填，最多 128 字符。
- 说明：必填，最多 500 字符。
- 参数区：根据 `configSchema` 渲染；订单条件使用通用 Key/Value 编辑器配置 `days`，当前管理端只填写 `1`。
- 排序：非负整数输入。
- 启用：开关；保存时服务端再次校验。
- 加载 schema、保存和校验失败时保留用户输入，不关闭弹窗。

### 状态与反馈

- 空列表：显示“暂无报名条件实例”，保留新增入口。
- 不可用类型：使用警告标签“类型未注册”，禁止新建模板引用；编辑可查看原配置。
- 停用实例：灰色标签“已停用”，允许编辑和删除（删除仍受引用校验）。
- 引用数大于 0：删除按钮可点击，但确认提示明确说明可能被模板引用；删除失败展示“请先从活动模板移除该条件”。
- 删除使用二次确认，成功后刷新列表，失败不移除当前行。

## 活动模板条件选择

- 内置条件区域改为内置条件实例复选框；标签显示实例名称，悬浮/辅助文本显示类型和参数摘要。
- 扩展条件区域使用“实例下拉 + 添加”模式，允许添加同一类型的多个实例。
- 已选择条件使用可排序列表展示，每行显示实例名称、类型、参数摘要和删除按钮。
- 停用但已被模板引用的实例显示为灰色“已停用”，可回显但不能新增选择；保存时展示服务端阻断信息。
- 保存成功、参数校验失败、条件实例已删除/停用等状态均使用现有 `useMessage()` 反馈。

## 适配与可访问性

- 管理端桌面布局沿用现有 `ContentWrap`、Element Plus 表格和弹窗，不新增移动端专用页面。
- 参数输入、删除和启停按钮保持现有后台可点击区域和键盘焦点顺序。
- 长说明、类型标识和 JSON 参数摘要使用省略号，悬浮展示完整内容。
