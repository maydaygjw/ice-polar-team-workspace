# 语音播报功能 API 合同变更

## 变更接口

### `POST /app-api/device/command/{imei}/{commandType}`

**Path 参数变更**:

| 参数 | 变更前 | 变更后 |
|------|--------|--------|
| `commandType` | 1-11 | 1-11, 51-56 |

**新增有效指令值**:

| 值 | 含义 |
|----|------|
| 51 | 广告播报 |
| 52 | 扫码未下单 |
| 53 | 下单未支付 |
| 54 | 支付成功未确认-买杯子 |
| 55 | 支付成功未确认-自带杯 |
| 56 | 出冰完成 |

**请求/响应格式**: 不变，复用现有 `DeviceCommandRespVO`

### `POST /api/v1/commands/{device_imei}/{command}` (DMS)

**Path 参数变更**:

| 参数 | 变更前 | 变更后 |
|------|--------|--------|
| `command` | 1-16 | 1-16, 51-56 |

**请求/响应格式**: 不变，复用现有 `CommandResponse`

## 兼容性

- 向后兼容：1-11 指令值行为不变
- 新增 51-56 指令值仅影响校验范围，接口契约结构无变化
