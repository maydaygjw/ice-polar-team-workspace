# 语音播报管理功能需求规格

## 背景

设备协议新增 51-56 语音播报指令（详见 `icepolar-dms/docs/yinerda_dtu.md`），需要在小程序设备管理端提供对应的操作入口。

## 需求范围

### In-Scope

1. 小程序设备详情页（`device-detail`）新增「语音播报」管理操作
2. 用户点击后弹出选择器，可选择 6 种播报内容之一触发
3. 后端代理 API 支持 51-56 指令值透传至 DMS
4. DMS 指令接口支持 51-56 指令值下发至设备

### Out-of-Scope

- 广告播报的自定义文案编辑（51 号指令的「广告语」内容暂由设备固件决定）
- 语音播报的历史记录查询
- 批量设备语音播报
- Admin 后台的语音播报管理

## 语音播报指令定义

| 指令值 | 业务含义 | 播报内容 |
|--------|----------|----------|
| 51 | 广告播报 | 广告语 |
| 52 | 扫码未下单 | 设备已连接，请尽快选择商品 |
| 53 | 下单未支付 | 购买成功，请尽快完成支付 |
| 54 | 支付成功未确认-买杯子 | 请取杯并正确放置到取冰口 |
| 55 | 支付成功未确认-自带杯 | 请将杯子正确放置到取冰口 |
| 56 | 出冰完成 | 制冰完成，请尽快取走您的冰块 |

## 验收标准

- [ ] 小程序设备详情页显示「语音播报」按钮
- [ ] 点击后弹出选择器，展示 6 种播报场景
- [ ] 选择后调用 `/app-api/device/command/{imei}/{commandType}` 下发指令
- [ ] 指令值 51-56 可正常透传至设备
- [ ] 现有的 1-11 通用指令不受影响
- [ ] 设备离线时下发失败，提示用户
