# 企业微信素材管理测试计划

## 环境前置

- 测试租户已配置企业微信账号，并具备客户联系和企业群发权限。
- 测试租户配置默认小程序主账户，包含可访问的测试 AppID。
- 测试环境文件服务可保存并读取图片，准备 JPG/PNG 测试图片。
- 企业微信 API 使用测试账号或 mock，能够返回图片上传、临时素材上传、群发任务创建和部分失败结果。
- 测试用户已分配素材组、素材和客户群群发权限；无权限用户用于验证按钮隐藏和接口拒绝。
- 测试客户群已同步，并配置至少两个可通过不同标签匹配的客户群。

## API 场景

1. 创建素材组时同时提交首个文字素材，能够返回素材组和素材信息。
2. 创建图片、小程序、链接素材，逐项校验类型字段和响应内容。
3. 拒绝空字段、非法 URL、非法小程序路径、超过 2000 字符文本和不支持的类型。
4. 拒绝第二个文字素材和第十个非文字素材。
5. 素材顺序更新只接受完整且属于目标组的素材 ID 列表。
6. 删除素材组级联删除素材；删除组内最后一个素材被拒绝。
7. 跨租户、跨企业微信配置读取和写入均被拒绝。
8. 群发请求必须使用 `materialGroupId`；旧 `content` 请求被拒绝。
9. 群发请求正确组装文字、图片、链接、小程序附件，并保持排序。
10. 小程序封面上传失败时不创建群发任务；企业微信部分群失败时返回任务 ID和失败群 ID。
11. 外部接口失败和网络异常不泄露 Secret、access token 或图片二进制内容。

## E2E 场景

1. 管理员选择企业微信配置，创建包含首个文字素材的素材组。
2. 在素材组内新增图片、链接和小程序素材，完成预览并调整顺序。
3. 编辑素材组名称和素材内容，确认列表摘要及预览同步更新。
4. 从客户群页面按标签筛选目标群，选择素材组，确认预览内容和附件数量，创建群发任务。
5. 验证页面展示任务 ID、目标数量、成员确认提示以及部分失败反馈。
6. 删除素材组并确认级联删除；确认该组不再出现在群发选择器中。
7. 使用无权限用户验证素材管理和群发操作不可见且接口拒绝。

## 回归与清理

- 执行后端 MP 模块定向单元/集成测试和管理端类型检查、构建。
- 执行素材管理 API 测试及相关客户群群发回归测试。
- 在测试环境执行 `governance/e2e/specs/features/wecom-material-management/` 下的 Playwright 用例。
- 测试结束后通过业务 API 删除本次创建的素材组、素材和测试群发数据；外部 mock 数据按测试运行 ID清理。
- 真实企业微信环境验证属于部署前测试，不在本地默认测试中执行。
