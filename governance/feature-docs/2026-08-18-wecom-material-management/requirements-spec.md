# 企业微信素材管理需求规格

## Scope

### In Scope

- 在企业微信模块增加素材管理入口。
- 按企业微信配置维护素材组；一个素材组包含多个有序素材。
- 支持文字、图片、小程序和链接四种素材类型。
- 在企业微信群发时选择一个素材组，替代当前直接输入文字的群发方式。
- 群发目标继续使用现有企业微信配置和客户群标签筛选能力。

### Out of Scope

- 不保留直接输入 `content` 的群发方式，也不兼容旧的 `content` 请求。
- 不支持视频、文件、语音、富文本、营销追踪参数等素材类型。
- 不修改小程序端、DMS 或企业微信客户群同步逻辑。
- 不新增定时群发、群发历史和群发统计功能。

### Deferred

- 一个素材组包含多个文字素材。
- 素材版本历史、草稿和发布状态。
- 跨企业微信配置共享素材。

## Use Cases

### UC-1 维护素材组

管理员进入企业微信素材管理，选择企业微信配置，填写素材组名称和首个素材后新增素材组；之后可以编辑、查看或删除素材组。素材组列表展示名称、素材数量和更新时间。

### UC-2 维护组内素材

管理员进入素材组，新增或编辑素材，选择素材类型并填写该类型所需内容；管理员可以调整素材顺序。系统展示各类型素材的预览。

### UC-3 创建企业微信群发任务

管理员在客户群页面按现有群标签筛选目标群，选择一个素材组，预览最终消息后创建群发任务。企业微信仍由群成员确认后实际发送。

### UC-4 处理群发结果

管理员看到群发任务编号、目标群数量和企业微信返回的失败群列表；部分群失败时，已创建的任务结果仍需明确反馈。

## Business Rules

- 素材组归属于一个企业微信配置，只能被同一配置下的群发使用。
- 所有素材组、素材及群发关联查询遵守当前租户隔离和企业微信配置归属校验。
- 素材组名称必填；同一企业微信配置下未删除的素材组名称不得重复。
- 素材组至少包含一个素材，且至少有一个素材内容有效后才可用于群发。
- 新增素材组时必须同时提交一个有效的首个素材，不能产生空素材组。
- 一个素材组最多包含一个文字素材；除文字外最多包含九个素材。
- 素材顺序由管理员维护，群发预览和发送请求均按该顺序处理。
- 文字素材必填，支持多行内容，换行必须保留；长度沿用现有群发文本的 2000 字符上限。
- 图片素材必须选择有效图片，并保存可供管理端预览的图片内容。
- 小程序素材必须维护消息标题、页面路径和封面图片；AppID取当前租户默认小程序主账户，管理员不可自由修改。页面路径必须以 `/` 开头。
- 链接素材必须维护标题、封面 URL、描述和链接 URL；两个 URL 必须使用 `http` 或 `https` 协议。
- 群发请求必须选择一个未删除且属于当前企业微信配置的素材组；不能再通过文字输入直接创建群发。
- 外部企业微信群发任务创建成功不代表消息已经发送，系统必须向管理员明确提示仍需成员确认。
- 素材组或素材后续编辑、删除不改变已经创建的企业微信群发任务；后续群发使用最新内容。
- 小程序封面产生的企业微信临时素材只用于创建当前群发任务，不作为长期素材状态展示。
- 删除素材组时级联删除其组内素材；删除后的素材组不能继续被选择或群发。
- 不允许单独删除素材组内最后一个素材；如需清空内容，应删除整个素材组。

## Frontend Requirements

- 企业微信目录下新增“素材管理”入口，并提供企业微信配置筛选。
- 素材组列表支持新增、编辑、删除和进入组内素材维护。
- 素材维护表单根据类型动态展示字段：
  - 文字：多行文本框和字数提示。
  - 图片：图片选择或上传、预览。
  - 小程序：只读 AppID、页面路径、消息标题、封面图片和卡片预览。
  - 链接：标题、封面 URL、描述、链接 URL 和卡片预览。
- 素材组内支持展示素材类型、摘要或缩略图、更新时间，并支持调整顺序。
- 群发对话框移除“消息内容”输入框，改为选择素材组并展示素材组内容预览。
- 群发对话框保留现有目标群标签、发送成员和目标范围提示。
- 素材组为空、素材字段不完整、目标群为空或素材数量超过限制时，禁止保存或提交。
- 群发提交期间禁止重复提交；创建成功、部分失败和失败均显示明确反馈。
- 删除素材组或素材必须二次确认。

## Edge Cases

- 企业微信配置不存在、已删除或缺少有效凭据：禁止读取、保存或群发，并提示配置问题。
- 默认小程序主账户不存在：无法创建或保存小程序素材。
- 素材组在打开群发弹窗后被删除或停用：提交时重新校验并拒绝使用。
- 素材在编辑期间被其他操作删除：保存或群发时重新校验组内容和顺序。
- 图片上传成功但企业微信群发素材准备失败：不得创建不完整的群发任务，并保留原素材管理记录。
- 小程序封面临时上传失败：不得创建群发任务，并反馈可诊断的外部错误，不泄露凭据。
- 企业微信只接受部分目标群：保留任务编号并展示失败群 ID。
- 企业微信成员确认发送前素材组被修改：已创建任务仍使用创建时的消息内容。

## Acceptance Criteria

- [ ] 企业微信目录下存在“素材管理”入口。
- [ ] 管理员可以按企业微信配置创建、编辑、查看和删除素材组。
- [ ] 一个素材组可以维护多个有序素材，且最多一个文字素材、最多九个非文字素材。
- [ ] 文字素材支持多行内容，保存和预览时保留换行。
- [ ] 图片素材可以选择图片并完成管理端预览。
- [ ] 小程序素材展示默认小程序 AppID，并支持保存标题、页面路径和封面图片。
- [ ] 链接素材支持保存标题、封面 URL、描述和链接 URL，并校验 URL 协议。
- [ ] 客户群群发只能选择素材组，前端和后端均不再接受直接 `content` 群发。
- [ ] 群发消息按素材组顺序转换为文字和图片、链接、小程序附件。
- [ ] 无效素材组、空目标群、超出素材数量限制或字段不完整时不能创建群发任务。
- [ ] 群发结果可以展示任务编号、目标群数量和失败群列表。
- [ ] 企业微信配置和租户隔离校验有效，管理端响应不泄露 CorpID Secret、access token 或其他凭据。
- [ ] 已创建的群发任务不受后续素材编辑或删除影响。

## Assumptions

- 素材组是企业微信配置级资源，不与商圈、部门或门店绑定。
- 小程序 AppID来自当前租户默认小程序主账户；页面路径、标题和封面属于素材内容。
- 图片和小程序封面使用现有文件服务保存管理端可访问的内容。
- 企业微信群发的九个附件上限由后端和管理端共同校验。
- 本期不保存本地群发历史；企业微信返回的任务编号和失败群列表作为本次操作结果。
