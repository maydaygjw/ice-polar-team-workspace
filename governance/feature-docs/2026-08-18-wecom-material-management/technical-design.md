# 企业微信素材管理技术设计

## 模块影响

- `backend`：`yshop-module-mp` 增加素材组/素材领域、管理端接口、企业微信素材编排、权限和数据库迁移；改造客户群群发请求。
- `admin`：企业微信素材管理页面、素材编辑表单、群发素材组选择和预览。
- `miniapp`：N/A。
- `icepolar-dms`：N/A。

## 关键决策

### 1. 使用企业微信专属素材模型

不复用 `yshop_material` 和 `yshop_material_group`。现有素材库主要服务商品/后台图片，类型只有图片和视频，且没有企业微信配置归属及小程序/链接字段。新模型放在 `yshop-module-mp`，素材组以 `tenant_id + account_id` 作为业务边界。

### 2. 使用一对多关系和显式类型字段

素材组与素材为一对多关系；素材保存 `sort` 作为展示和发送顺序。素材类型使用 `TEXT`、`IMAGE`、`MINI_PROGRAM`、`LINK`。类型专属字段采用显式 nullable 字段，服务层校验字段互斥和完整性，不使用不可查询的自由 JSON 作为主模型。

素材表不重复保存 `account_id`，通过素材组取得企业微信配置归属，避免组移动或删除后出现两个归属来源。

素材组创建接口同时接收名称和首个素材，在一个本地事务中创建组与素材，禁止产生空组。后续素材通过独立接口维护；删除最后一个素材时拒绝操作，避免违反素材组最小内容规则。

### 3. 图片和小程序封面采用不同的外部素材生命周期

- 图片素材保存系统图片地址，并在创建/替换图片时通过企业微信 `media/uploadimg` 取得可用于群发的 `pic_url`；原图片未变化时复用已保存的企业微信 URL。
- 小程序封面保存系统图片地址，不保存临时 `media_id`。创建群发任务前读取封面内容，调用 `media/upload?type=image`，将新 `media_id` 只放入本次群发请求。
- 外部素材上传成功但本地数据库保存失败时可能产生外部孤儿素材；记录可诊断日志，不把未完成记录返回为可用素材。

### 4. 群发内容由素材组一次性快照化

创建群发任务时读取素材组及其当前排序，转换成企业微信的 `text` 和 `attachments` 请求。之后素材组的编辑或删除不影响已提交任务，因为企业微信已接收本次请求内容。

一个素材组最多一个文字素材和九个非文字素材。文字映射到唯一 `text` 节点；非文字素材按顺序映射到 `attachments`。没有文字时省略 `text` 节点，只发送附件。

### 5. 群发接口破坏性收敛

客户群群发请求改为必须提供 `materialGroupId`，删除 `content` 字段和旧的直接文字分支。前后端同时切换，不保留兼容路径，避免新旧两套消息来源长期并存。

### 6. 事务、幂等和失败处理

- 素材组删除与组内素材软删除在同一事务中完成。
- 素材顺序更新在事务内校验素材全部属于目标组，并按请求顺序重新编号。
- 图片素材外部上传成功后才写入或更新可用记录；更新失败保留原记录。
- 群发外部请求出现响应明确的失败时直接返回错误；网络超时不能自动重试同一个群发请求，避免企业微信已创建任务而本地重复提交。
- 本期不持久化群发任务，因此不新增本地幂等键；管理端需在请求期间禁用重复提交。

### 7. 权限和数据范围

素材管理使用独立菜单权限。每次读写均校验当前租户、素材组所属企业微信配置和软删除状态。群发继续使用现有 `mp:wecom-customer-group:send` 权限，并额外校验素材组归属。

## 处理流程

```text
素材管理表单
  → 校验企业微信配置和类型字段
  → 图片按需同步企业微信 pic_url
  → 保存素材组/素材

客户群群发
  → 群标签匹配客户群
  → 读取素材组当前内容和顺序
  → 小程序封面上传临时 media_id
  → 组装 text + attachments
  → externalcontact/add_msg_template
  → 返回 msgid、目标群数和失败群 ID
```

## 迁移与回滚

- 新增 `backend/sql/upgrade-2026-08-18-wecom-material-management.sql`，创建素材组表、素材表、菜单和权限。
- 迁移必须可重复执行，不能修改 `yixiang-drink.sql`。
- 回滚只在人工确认后执行：先解除租户角色与新增菜单权限，再删除新增菜单，最后删除两张素材表。
- 回滚前必须确认没有继续使用本功能；回滚不删除文件服务中的历史图片或企业微信已上传素材。

## 风险

- 企业微信临时小程序封面可能在成员确认发送前过期，需要测试任务确认时效；本期不持久化临时 ID。
- 图片同步和本地保存不是跨系统原子事务，可能留下企业微信孤儿图片素材。
- 外部群发请求网络异常时无法判断任务是否已创建，本期不自动重试，需在管理端明确提示人工核查。
- 真实企业微信环境的图片 URL、封面大小、群发额度和成员确认权限需要在测试环境验证。
