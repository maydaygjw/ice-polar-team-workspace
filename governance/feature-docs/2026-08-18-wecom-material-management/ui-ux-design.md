# 企业微信素材管理 UI/UX 设计

## 页面入口

- 父菜单：企业微信。
- 子菜单：素材管理。
- 页面：企业微信配置筛选 + 素材组/素材双栏管理工作区。

## 页面结构

### 顶部筛选栏

- 企业微信配置下拉框，必选；切换配置时清空当前素材组和素材列表。
- 右侧提供“新增素材组”按钮。
- 未选择企业微信配置时，列表区域显示引导空状态，不请求素材数据。

### 左侧素材组区域

- 宽度约 240px，展示素材组名称、素材数量和更新时间。
- 当前素材组高亮；列表支持按名称搜索。
- 每个组提供编辑名称和删除操作。
- 删除前展示级联删除组内素材的确认信息。
- 无素材组时展示“新建素材组”操作。

### 右侧素材区域

- 顶部显示当前素材组名称、素材数量和“新增素材”按钮。
- 表格列：顺序、类型、内容摘要/缩略图、更新时间、操作。
- 支持拖拽调整顺序，保存排序时展示加载状态。
- 新增素材组时使用包含“组名称 + 首个素材”的表单，提交成功后进入该组的素材维护区域。
- 正常情况下不会出现空组；若历史脏数据导致空组，显示“暂无素材，请新增”提示，但不能用于群发。

## 素材表单

使用现有 `Dialog`、`el-form` 和 `formRef.validate()` 模式；表单宽度建议 680–760px。

固定字段：素材类型。根据类型展示以下字段：

- 文字：多行输入框，最多 2000 字符，保留换行并显示字数。
- 图片：复用现有 `Materials` 图片选择组件，单选并展示预览。
- 小程序：只读 AppID、消息标题、页面路径、封面图片；显示小程序卡片预览。
- 链接：标题、封面 URL、描述、链接 URL；显示链接卡片预览。

切换素材类型时清空不适用字段，并要求用户确认已填写内容会被清空。

## 群发弹窗改造

- 保留现有群标签筛选、发送成员和目标提示。
- 删除“消息内容”文本框，增加必选“素材组”选择器。
- 素材组选择器只展示当前企业微信配置下可用的非空素材组。
- 选择后展示按顺序排列的消息预览：文字、图片、链接、小程序卡片。
- 显示附件数量和超限提示；提交按钮在素材组或目标范围无效时禁用。
- 提交前确认文案明确：“任务创建后仍需企业微信成员确认发送”。

## 状态和反馈

- 页面、素材组和素材分别显示加载状态，避免整个页面无差别遮罩。
- 保存、删除和排序期间禁用重复操作。
- 外部图片同步或小程序封面处理失败时，保留用户表单内容，不关闭弹窗。
- 群发成功显示任务编号和目标群数量；部分失败显示失败群数量及可复制的失败群 ID。
- 权限不足时隐藏对应操作按钮；无查询权限时显示无权限空状态。
- 删除和级联删除均使用二次确认。
- 删除组内最后一个素材时提示“素材组至少需要保留一个素材”，引导用户删除整个素材组。

## 视觉与适配

- 沿用管理端 `ContentWrap`、Element Plus 表格、Dialog、Tag 和统一间距规范。
- 素材类型使用稳定的文字标签：文字、图片、小程序、链接，不仅依赖颜色区分。
- 图片缩略图使用固定容器并保持 `contain`；小程序和链接使用卡片式预览。
- 双栏布局在窄屏降级为“素材组选择器 + 素材列表”上下结构；不改变数据操作顺序。
- 不在前端展示 CorpID Secret、access token 或企业微信内部认证信息。
