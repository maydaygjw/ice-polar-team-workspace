# 企业微信客户联系回调接入需求规格

## Scope

### In

- 提供可配置到企业微信「客户联系」的公开回调地址。
- 支持企业微信保存回调地址时的 URL 有效性验证。
- 支持接收企业微信推送的加密客户联系事件，完成来源校验和消息解密。
- 记录请求元数据及解密后的事件内容，用于后续联调和业务设计。
- 正确、及时确认已收到合法事件。

### Out

- 不更新客户、客户群、标签或其他业务数据。
- 不调用企业微信查询接口，不发送欢迎语、应用消息或被动回复。
- 不发布 MQ，不持久化事件，不实现幂等、补偿或重放。
- 不新增管理端页面。

### Deferred

- 按事件类型同步客户、客户群和标签数据。
- 事件幂等、乱序处理、失败补偿和主动对账。
- 回调日志持久化、查询和审计页面。

## Use Cases

### 验证回调地址

企业微信携带 `msg_signature`、`timestamp`、`nonce`、`echostr` 发起 GET 请求。系统定位企业微信账户，验证签名并解密，在 1 秒内原样返回明文。

### 接收客户联系事件

企业微信携带签名参数和加密 XML 发起 POST 请求。系统定位账户、验签、解密并记录事件，不执行业务处理，立即确认成功。

### 拒绝非法回调

参数缺失、配置不存在、签名错误、密文非法或解密失败时，不把请求记录为合法事件，不返回成功确认。

## Business Rules

- 回调无需登录态，但必须通过 Token 签名校验和 EncodingAESKey 解密校验。
- 回调地址必须唯一关联企业微信账户，不依赖企业微信不会提供的租户请求头。
- GET 返回解密后的 `echostr` 裸文本，不使用通用 JSON 包装，不附加引号、BOM 或换行。
- POST 仅在验签和解密成功后记录合法事件，并在 5 秒内返回成功。
- 文档列出的客户、客户群、标签事件以及未来新增的合法未知事件均可接收和记录。
- 日志不得包含客户联系 Secret、回调 Token、EncodingAESKey 或加密请求体。
- 本期允许企业微信重试导致同一合法事件重复记录。
- 通过企业微信 API 发起且官方不产生回调的操作，本功能不补发事件。

## Frontend Requirements

- 企业微信配置表单增加回调 Token 和 EncodingAESKey 密码输入框。
- 两项均为可选，但必须同时填写；编辑时同时留空表示保留原值。
- 不回显已保存凭据，使用 `callbackConfigured` 提示当前配置状态。
- 企业微信配置列表显示事件回调“已配置/未配置”。

## Edge Cases

- 必要参数缺失、签名不匹配、密文为空、XML 非法或解密失败。
- 账户不存在、已删除或缺少完整回调凭据。
- 解密消息中的 CorpID 与 URL 关联账户不一致。
- 企业微信重复推送；未知 `Event`、`ChangeType` 或可选字段缺失。
- XML 含换行或特殊字符时不得造成日志注入或改变响应。

## Acceptance Criteria

- 有效 GET 请求在 1 秒内返回解密后的 `echostr` 原文，企业微信可保存 URL。
- 非法 GET 不返回 `echostr` 明文。
- 有效 POST 可解密并记录账户、租户、请求元数据和解密事件内容。
- 有效 POST 在 5 秒内返回 HTTP 200 与裸文本 `success`，不产生业务副作用。
- 非法 POST 不记录为合法事件并返回非成功响应。
- 合法未知事件同样记录并确认成功。
- 自动化测试覆盖有效 GET、有效 POST、错误签名、配置缺失、CorpID 不匹配和未知事件。
- 管理后台可成对录入回调凭据，能区分已配置和未配置状态，且不回显敏感值。

## Assumptions

- 接入现有自建应用的客户联系回调，不含第三方应用、代开发应用或普通应用消息。
- 一账户一个回调 URL，URL 中使用非敏感账户 ID 定位租户和配置。
- 回调 Token 与 EncodingAESKey 归属现有企业微信账户并加密保存。
- 按用户要求记录解密后的请求 XML；清理换行避免日志注入，不记录服务端凭据和加密体。
