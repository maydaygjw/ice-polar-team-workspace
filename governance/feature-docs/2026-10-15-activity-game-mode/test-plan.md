# 活动游戏模式 E2E 测试计划

## 环境前置

- 使用本地或测试环境和专用测试租户、管理员及会员账号；配置游戏管理和活动模板对应权限。
- 测试租户有后端注册的内置游戏类型和至少 3 个启用的活动奖品。
- 使用隔离期次及固定可重放的游戏关卡凭据；测试数据在用例结束后通过业务 API 清理。

## 场景

1. 管理员创建/启用一个内置游戏，创建游戏模式模板并为三关配置奖品，生成期次；断言详情回显游戏和逐关奖品快照。
2. H5 用已报名会员开始游戏并通过第 1 关；断言进入第 2 关且未生成最终中奖记录。
3. 通过第 1 关后在第 2 关失败；断言游戏终止，生成的唯一中奖记录对应第 1 关奖品。
4. 第 1 关失败；断言会话终止且无中奖记录。
5. 连续通过 3 关；断言终局中奖记录只对应第 3 关奖品。
6. 重复提交同一 `requestId`、并发开始会话、终局后重复开始；断言状态和中奖记录幂等，不重复消耗库存或生成记录。
7. 验证未报名、期次未开放、非游戏模式、错误关卡顺序、无效凭据及他租户会话访问均失败且无业务副作用。
8. 验证停用游戏不改变已有期次游戏快照；开奖/抽奖模式模板和旧期次回归正常。
9. 库存耗尽或单人限中时结束游戏但无第二条中奖记录；H5 展示无奖终局结果。
