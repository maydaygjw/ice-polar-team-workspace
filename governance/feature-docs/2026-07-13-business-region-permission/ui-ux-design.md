# 界面与体验设计说明：business-region 管理

## 设计概述

界面需要清晰区分内部管理概念和后续 C 端业务概念：

- 管理后台展示部门、`business-region`、门店和门店管理员分配。
- 小程序端本期暂不实现；后续只展示 `business-region` 和门店，不展示部门。

管理后台应保持高效、克制、适合运营人员批量管理。

## 管理后台

### 新页面：business-region 管理

建议路由：

```text
mall/store/business-region
```

页面结构：

- 筛选区：区域名称、部门树选择器、状态。
- 表格列：ID、名称、部门、状态、排序、地址、创建时间、操作。
- 操作：新增、编辑、删除、启停、设为默认。
- 表单弹窗：
  - 区域名称
  - 部门选择器
  - 是否默认商圈
  - 状态
  - 排序
  - 省/市/区
  - 地址
  - 经度/纬度

交互规则：

- 部门选择器复用现有部门树样式。
- 状态字段复用现有启用/停用字典展示。
- 默认商圈在列表中用标签标识。
- 默认商圈不允许直接删除；删除按钮置灰或由后端返回错误后展示提示。
- 如果区域下存在门店，删除操作由后端阻止，前端展示错误提示。

### 门店管理调整

门店表单：

- 在门店名称和地址附近增加 `business-region` 选择器。
- 选择 `business-region` 后，只读展示对应部门。
- 现有门店管理员选择改为基于新关系表的多用户分配。

门店列表：

- 增加 `business-region` 列。
- 增加部门列。
- 增加 `business-region` 筛选项。

### 用户/门店分配

用户维度：

- 用户详情或授权弹窗展示“可管理门店”。
- 使用可搜索的选择器或穿梭框，支持按 `business-region` 和门店名称过滤。

门店维度：

- 门店表单或门店详情支持分配多个管理员。

## 小程序

本期暂不实现小程序端。以下内容仅作为后续阶段占位，不进入第一版开发范围。

### business-region 选择器

入口位置：

- 在首页或扫码页顶部展示当前 `business-region`。
- 展示为紧凑选择器：

```text
[当前商圈：城西商圈 v]
```

点击后打开选择页面或底部弹层。

### 区域选择视图

内容：

- 按区域名称搜索。
- 区域列表按排序或距离展示。
- 区域卡片字段：
  - 区域名称
  - 区/地址
  - 当前选中标记

状态：

- 加载中
- 空状态
- 网络失败
- 已选区域被停用

### 切换后行为

- 本地保存 `businessRegionId`。
- 刷新门店列表和后续业务上下文。
- 如果当前门店或设备不属于新区域，则清空旧选择。
- 切换成功后展示简短提示。

### 小程序文案

面向用户使用：

- “商圈”
- “附近门店”
- “切换商圈”

不展示：

- “部门”
- “数据权限”
- “租户”

## 可用性与交互

- 可点击区域不小于 `88rpx`。
- 区域名称过长时单行省略。
- 空状态提供刷新或重新选择入口。
- 已选区域有效时，不阻断扫码和下单主流程。
