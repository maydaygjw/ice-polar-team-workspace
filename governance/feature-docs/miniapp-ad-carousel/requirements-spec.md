# Requirements Spec: MiniApp Ad Carousel Banner

## 1. Feature Overview

在小程序扫码页（`pages/scan/scan`）接入广告轮播图，并同步构建金刚区（快捷入口网格）。后端复用现有的 `yshop_shop_ads` 广告管理功能，不新建独立模块；如现有字段或接口不满足，通过扩展字段和修复查询逻辑来支持。

## 2. Scope

### In Scope
- 小程序扫码页新增广告轮播图（金刚区上方）
- 金刚区快捷入口网格（5 个入口：我的订单、优惠券、附近设备、设备管理、合作加盟）
- 后端 `yshop_shop_ads` 表扩展 `link` 字段（支持广告点击跳转）
- 后端 App API `GET /ad/list` 修复：仅返回 `is_switch=1` 且按 `weigh` 降序排序
- Admin 后台广告表单增加 `link` 输入项
- 广告图支持点击跳转（外部链接通过 webview 打开）

### Out of Scope
- 不新建独立的广告模块或广告服务
- 不涉及积分商城广告 (`yshop_score_ads`)
- 不修改现有广告 Admin 的权限体系
- 不新增小程序页面（除 webview 页外）
- 广告统计/曝光/点击数据追踪（后续迭代考虑）

## 3. Functional Requirements

### FR-1 广告轮播展示
- 小程序扫码页在设备状态卡下方展示广告轮播区域
- 轮播图使用 `<swiper>` 组件，支持自动播放（5s 间隔）和循环
- 单张广告时不显示指示点且不自动播放
- 无广告时隐藏轮播区域

### FR-2 广告数据获取
- 小程序调用现有 `GET /app-api/ad/list?shop_id={shopId}` 获取广告列表
- 后端仅返回 `is_switch = 1` 的广告
- 返回结果按 `weigh DESC, id DESC` 排序
- 响应包含 `id`, `image`, `link` 字段

### FR-3 广告点击跳转
- 广告图支持点击跳转
- 若 `link` 不为空，点击后通过 `wx.navigateTo` 打开 `/pages/webview/webview?url=xxx`
- 若 `link` 为空，广告仅展示不可点击

### FR-4 金刚区快捷入口
- 轮播图下方展示 5 个快捷入口图标网格
- 图标：我的订单、优惠券、附近设备、设备管理、合作加盟
- 点击图标跳转对应页面

### FR-5 后台广告管理
- Admin 后台「店铺广告」管理页面增加「跳转链接」输入框
- 支持创建/编辑广告时填写可选的跳转链接
- 现有图片上传、权重设置、开关控制、店铺选择保持不变

## 4. Non-functional Requirements

### NFR-1 性能
- 广告图使用 `lazy-load` 懒加载
- 轮播区域在图片加载前预留 16:9 空间，避免布局偏移（CLS）
- 单张广告图建议 ≤ 80KB，最多展示 6 张

### NFR-2 兼容性
- 适配 375px ~ 414px 宽度的主流手机屏幕
- 使用 `rpx` 单位确保多设备兼容

### NFR-3 可靠性
- 广告 API 失败时静默处理，可展示默认品牌兜底图
- 不影响扫码核心流程的正常使用

## 5. Edge Cases & Boundary Conditions

| 场景 | 预期行为 |
|------|---------|
| 无广告数据 (`list` 为空) | 隐藏轮播区域，仅显示金刚区 |
| 仅 1 条广告 | 不显示指示点，不自动播放，不可滑动 |
| 广告 `link` 为空 | 展示图片，点击无反应 |
| 广告 `is_switch=0` | 不展示在轮播中 |
| `weigh` 相同的多条广告 | 按 `id DESC` 二次排序 |
| 网络异常获取广告失败 | 静默失败，可展示默认品牌图或隐藏轮播 |
| 管理员修改广告后 | 用户重新进入小程序页面时刷新（`onShow` 拉取） |
| webview 页面不存在 | 点击有 link 的广告时需确保 `pages/webview/webview` 已注册 |

## 6. Acceptance Criteria

- [ ] 小程序扫码页可见广告轮播图，多张时自动轮播
- [ ] 广告图可点击跳转（有 link 时打开 webview，无 link 时不响应）
- [ ] 后台创建广告时可填写跳转链接，保存后生效
- [ ] `is_switch=0` 的广告不在轮播中展示
- [ ] 广告按权重从高到低排序展示
- [ ] 金刚区 5 个快捷入口可正常点击跳转
- [ ] 无广告时轮播区域隐藏，不影响页面布局
- [ ] 租户隔离正常（仅展示当前租户广告）

## 7. Open Questions / Decisions Needed

1. **金刚区页面是否存在？** 设计 spec 中提议的「附近设备」「设备管理」「合作加盟」页面需确认在小程序中是否存在。若不存在，Phase 3 实现时金刚区先接入已有页面（我的订单、优惠券），其余入口可后续补充。
2. **webview 页面**：小程序是否已有 `pages/webview/webview`？若没有，需在本次实现中创建。
