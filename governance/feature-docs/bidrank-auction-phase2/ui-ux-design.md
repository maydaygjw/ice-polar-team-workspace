# 商圈排名竞价（二期）— UI/UX Design

本期只设计 admin 的出价单与周期结算结果查询；商家竞价页面和实时竞争展示列入 Phase3。
沿用现有 Vue3 + Element Plus 管理端列表页范式，页面由后端菜单动态路由加载。

## 导航与权限

- 在一期“商圈竞价”目录下新增“出价单”和“结算结果”两个菜单。
- 查询权限统一使用 `bidrank:order:query`。
- 无权限时不显示菜单；接口仍由后端权限注解拦截。

## 出价单页面

路径：`/bidrank/order`

筛选项：周期、商圈、门店、出价单状态；结果表展示出价单号、周期、门店、档位、当前出价、预付/尾款状态、是否中标、最终支付时间。

状态要求：

- 加载态使用表格骨架/现有列表 loading。
- 无数据显示统一空态。
- 查询失败使用 `useMessage().error`，保留筛选条件。
- 金额统一显示两位小数，时间按后台现有日期格式展示。

## 结算结果页面

路径：`/bidrank/order/result`

筛选项：周期、商圈；结果表展示档位范围、门店、最终出价、最终支付时间、中标状态和排序生效日期。

页面只读，不提供人工改价、人工改中标、退款重试或结算重跑操作；这些能力列入 Phase3。
