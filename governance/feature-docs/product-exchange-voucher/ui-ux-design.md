## UI/UX Design: 商品兑换券

### 现状分析

现有小程序已具备优惠券页面 (`pages/coupons/`)，采用双层级 tab（一级：我的/领券中心，二级：可使用/已使用/已过期）+ 卡片列表布局。优惠券卡片为左右分栏设计：左侧蓝色渐变展示金额/条件，右侧白色区域展示详情与操作按钮。空状态、模态弹窗、底部操作栏等组件均已成熟。

商品兑换券与现有优惠券在业务形态上高度相似（券码、有效期、状态流转、核销动作），因此大量复用既有视觉模式和组件结构，同时针对"兑换实物商品+设备提货"的场景做差异化设计。

### 用户流程

```
入口 A: 个人中心 → 点击"我的兑换券" → 列表页
入口 B: 首页/扫码页 → 点击"兑换券核销" → 核销页
入口 C: 扫码页 → 扫描兑换券 QR → 自动跳转核销页

列表页:
  顶部 Tab: 未使用 / 已使用 / 已过期
  点击卡片 → 详情页

详情页:
  商品信息 + 券码 + 有效期 + 使用说明
  点击"去使用" → 核销页

核销页:
  方式1: 手动输入券码 → 校验 → 选择设备 → 确认核销
  方式2: 扫描券码 QR → 自动校验 → 选择设备 → 确认核销
  核销成功 → 成功页（展示取货码/设备号）
  核销失败 → 错误提示页（具体原因 + 重试/返回）
```

### 页面清单

| 页面 | 路径 | 说明 |
|------|------|------|
| 兑换券列表 | `pages/voucher-list/` | 三 tab 卡片列表，入口自 profile |
| 兑换券详情 | `pages/voucher-detail/` | 商品信息、券码、有效期、使用说明、QR 大图 |
| 兑换券核销 | `pages/voucher-redeem/` | 输入/扫描券码、校验中、设备选择、确认核销 |
| 核销成功 | `pages/voucher-success/` | 取货指引、设备信息、返回按钮 |
| 核销失败 | `pages/voucher-error/` | 错误原因、重试/返回按钮 |

### 配色方案

沿用现有设计系统，兑换券以**紫色渐变**作为主题色，与优惠券（蓝色）形成区分，强化"商品兑换"心智。

| Token | 值 | 用途 |
|-------|-----|------|
| `--voucher-primary` | `#7C3AED` | 兑换券主题色 |
| `--voucher-primary-light` | `#A78BFA` | 渐变终点、hover 态 |
| `--voucher-primary-dark` | `#6D28D9` | 渐变起点、press 态 |
| `--voucher-gradient` | `linear-gradient(135deg, #6D28D9 0%, #7C3AED 50%, #A78BFA 100%)` | 卡片左侧、主按钮 |
| `--voucher-bg` | `#F5F3FF` | 兑换券页面背景替代色 |
| `--brand-success` | `#10B981` | 核销成功、设备在线 |
| `--brand-error` | `#EF4444` | 已过期、核销失败、设备离线 |
| `--brand-warning` | `#F59E0B` | 即将过期（< 7 天） |
| `--brand-text-primary` | `#111827` | 主标题、商品名 |
| `--brand-text-secondary` | `#374151` | 副标题、设备名 |

### 组件规范

#### 1. 兑换券卡片 (VoucherCard)

```
┌─────────────────────────────────────┐
│ ┌────────┐  商品名称                │
│ │  图片   │  规格: 500ml            │
│ │ 占位   │  ─────────────────────   │
│ │  120rpx│  有效期: 2026.06.01-07.01│
│ └────────┘  [去使用] 或 [已使用]    │
└─────────────────────────────────────┘
```

- 尺寸：宽度 `100% - 64rpx`（左右 32rpx 边距），高度自适应
- 圆角：`24rpx`
- 阴影：`0 4rpx 16rpx var(--brand-shadow-blue-soft)`
- 左侧商品图：正方形 `120rpx × 120rpx`，圆角 `16rpx`，紫色渐变背景兜底
- 右侧内容区：垂直排列，商品名（`--text-xl`，单行截断）、规格（`--text-sm`， muted）、有效期（`--text-sm`，muted）、操作按钮（底部右对齐）
- 状态 pill：未使用=紫色渐变，已使用=灰色，已过期=红色，即将过期=橙色
- 触摸反馈：active 时 `scale(0.98)`，`transition: transform 150ms ease`

#### 2. 券码展示组件 (VoucherCode)

```
┌─────────────────────────────────────┐
│ 券码: 8位字母数字混合               │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │  A B C D  -  E F G H            │ │
│ │  大字号等宽字体，4-4分组          │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [复制券码]  [查看 QR 大图]           │
└─────────────────────────────────────┘
```

- 券码容器：背景 `--brand-gray-50`，边框 `1rpx solid --brand-gray-200`，圆角 `16rpx`，内边距 `32rpx`
- 券码文字：`--text-3xl`，`font-family: var(--font-mono)`，字间距 `0.1em`，颜色 `--brand-text-primary`
- 分隔符：每 4 位一组，中间 `-` 分隔，颜色 `--brand-text-muted`
- 按钮区：两个 `text` 类型按钮，高度 `72rpx`，主按钮紫色，次按钮灰色边框

#### 3. QR 大图弹窗 (QRModal)

- 全屏遮罩：背景 `var(--brand-overlay)`，`backdrop-filter: blur(8rpx)`
- 内容卡片：白色背景，圆角 `32rpx`，居中，宽度 `80%`
- QR 码区域：最小 `400rpx × 400rpx`，白色背景，内边距 `24rpx`
- 关闭按钮：顶部右侧，圆形 `64rpx`，灰色背景
- 底部提示："请向设备管理员出示此码"

#### 4. 核销输入区 (RedeemInput)

```
┌─────────────────────────────────────┐
│ [扫描图标]  或  [输入框]             │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │  请输入 8 位兑换券码            │ │
│ └─────────────────────────────────┘ │
│                                     │
│      [确认核销]  主按钮            │
└─────────────────────────────────────┘
```

- 扫描按钮：圆形 `120rpx`，紫色渐变背景，白色扫描图标，底部文字 "扫码核销"
- 输入框：高度 `96rpx`，背景 `--brand-gray-50`，圆角 `16rpx`，边框 `1rpx solid --brand-gray-200`，focus 态边框变紫色
- 确认按钮：高度 `96rpx`，紫色渐变，圆角 `24rpx`，阴影 `0 8rpx 24rpx rgba(124, 58, 237, 0.3)`
- 禁用态：背景 `--brand-gray-300`，无阴影

#### 5. 设备选择卡片 (DeviceSelector)

```
┌─────────────────────────────────────┐
│  选择取货设备                        │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ ● 在线  设备名称                  │ │
│ │    距离 1.2km  地址...           │ │
│ │    [radio] 选中态                │ │
│ └─────────────────────────────────┘ │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ ○ 离线  设备名称                  │ │
│ │    [禁用，置灰]                   │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

- 设备卡片：白色背景，圆角 `16rpx`，边框 `1rpx solid --brand-gray-200`
- 选中态：边框变紫色 `2rpx solid --voucher-primary`，背景 `--voucher-bg`
- 在线状态：绿色圆点 `16rpx` + "在线"文字
- 离线状态：灰色圆点 + "离线"文字，整卡透明度 `0.5`，不可点击
- 单选按钮：右侧 `48rpx` 圆形，选中为紫色填充+白色勾，未选中为灰色边框

#### 6. 状态结果页 (ResultPage)

成功态：
- 顶部：大图标 `120rpx`，绿色圆形背景+白色勾，动画 `scale(0.5) → scale(1)` + `opacity 0 → 1`，持续 `400ms`，`cubic-bezier(0.175, 0.885, 0.32, 1.275)`（弹性效果）
- 标题："核销成功"，`--text-2xl`，居中
- 信息区：设备名称、取货码（大字号等宽）、地址
- 按钮："返回首页"（主按钮）、"查看订单"（次按钮）

失败态：
- 顶部：红色错误图标，动画同成功态
- 标题：错误摘要（如"券码无效"）
- 详情：具体原因说明
- 按钮："重新输入"（主按钮）、"返回"（次按钮）

### 交互优化

1. **列表加载**：下拉刷新（`onPullDownRefresh`），上拉加载更多（`onReachBottom`），骨架屏占位（3 条灰色脉冲卡片）
2. **券码输入**：自动大写、自动过滤非字母数字、输入满 8 位自动触发校验（防抖 300ms）
3. **扫描 fallback**：扫码失败或用户拒绝授权时，自动聚焦输入框并弹出软键盘
4. **设备选择**：默认选中最近/距离最近的在线设备，减少用户操作步骤
5. **核销确认**：二次确认弹窗（`wx.showModal`），防止误触，展示商品名+设备名
6. **网络异常**：全局错误提示 toast，"网络开小差了，请重试"，3 秒后自动消失
7. **页面转场**：列表→详情用 `wx.navigateTo`，核销成功→首页用 `wx.reLaunch` 清空栈

### 影响范围

- `app.json`：新增 5 个页面路由
- `app.wxss`：新增兑换券主题色 CSS 变量（或独立引入 `brand-assets/colors/voucher-colors.wxss`）
- `pages/profile/profile.wxml`：个人中心菜单新增"我的兑换券"入口（图标+角标数字）
- `pages/scan/scan.wxml`：扫码页新增"兑换券核销"快捷入口按钮
- `pages/coupons/`：样式复用，不修改现有优惠券逻辑

### 异常/空状态

| 场景 | 视觉表现 | 交互 |
|------|----------|------|
| 无兑换券 | 居中插图（空礼盒）+ "暂无兑换券" + "去首页看看" 按钮 | 点击跳转 scan 页 |
| 券码无效 | 输入框边框变红 + 下方红色提示文字 "券码不存在或已失效" | 清空按钮出现，点击清空 |
| 券码已使用 | 错误页：红色图标 + "该券码已核销" + 核销时间 | 返回列表页 |
| 券码已过期 | 错误页：红色图标 + "券码已过期" + 过期时间 | 返回列表页 |
| 设备全部离线 | 设备列表区显示 "附近暂无可用设备" + 刷新按钮 | 点击刷新重新拉取 |
| 网络错误 | 全局 toast "网络异常" + 页面内重试按钮 | 点击重试 |
| 核销超时 | 加载态转错误态，提示 "核销超时，请确认设备状态后重试" | 重试或返回 |

### 设计决策待确认

1. **兑换券主题色**：采用紫色（`#7C3AED`）与优惠券蓝色区分，是否确认？
2. **QR 码生成**：券码 QR 由前端生成（纯文本 QR）还是后端返回图片？影响 QR 大图弹窗实现方式。
3. **设备选择**：是否允许用户选择非最近设备？当前设计支持列表自选，但默认选中最近在线设备。
4. **核销成功后的取货码**：是显示设备生成的取货码，还是直接用券码作为取货凭证？影响成功页信息展示。
