# 活动邀请报名增加抽奖机会

## 规则

- 活动模板新增 `inviteRegistrationChance` 开关，默认关闭。
- 开启后，新用户报名成功且请求带有推荐人时，若推荐人已报名同一期活动，推荐人的报名记录自动增加 1 次抽奖机会。
- 推荐人不能是被推荐用户本人；推荐人未报名、报名无效或已开奖时，不增加抽奖机会。
- 奖励使用期次生成时的模板快照，模板配置不会影响已生成期次。

## 接口字段

- 管理端活动模板创建、更新请求和详情/分页响应增加 `inviteRegistrationChance`。
- 用户端报名接口行为保持原路径和参数不变；符合条件时自动更新推荐人的 `drawChances`。

## 权限与兼容性

- 复用现有活动模板权限，不新增权限点。
- 数据库升级历史模板默认关闭，未开启的活动行为保持不变。
