# 管理端界面设计

## 目标用户

企业微信配置维护人员，需要在同一租户内区分系统配置名称与企业微信应用身份，并核对共享应用的 AgentId。

## 页面变更

### 企业微信配置表单

- 在“配置名称”后增加“应用名称”，新建时必填。
- 增加“AgentId”数字输入框，允许为空；说明该字段用于识别应用，不参与客户联系欢迎语发送请求。
- 继续隐藏 Secret、回调 Token、EncodingAESKey 的已保存值；编辑时留空保持原值。

### 企业微信配置列表

- 在配置名称后展示应用名称和 AgentId。
- 保留 CorpID、回调配置状态、同步时间和备注，方便核对同一共享应用的多租户配置。

### 联系我表单

- 商圈选择下方提示改为“系统会将租户和商圈路由标识写入企业微信回调 State”。
- 不让用户手填 State，避免产生无法路由到目标租户的二维码。

## 非目标

- N/A：本期不新增后台筛选条件、不改变权限、不新增页面和交互流程。
