# 店铺导入 UI/UX 设计

## 页面结构

- 菜单挂在“门店中心”下，名称为“店铺导入”；页面沿用后台列表页的筛选区、表格、分页和操作栏。
- 顶部提供“新建导入”和“模板管理”按钮；导入弹窗使用三步步骤条：选择参数并上传、预览确认、导入结果。
- 参数页固定为“新建店铺”，不显示已有店铺选择控件。

## 模板管理

- 模板管理弹窗先展示模板名称、编码、版本、原文件名和下载操作。
- 上传表单要求填写模板编码、名称、版本、解析器和说明，并选择 `.xlsx`/`.xls` 文件。
- 模板文件保存到主 OSS；下载按钮打开已保存的 OSS 文件，不重新生成字段模板。
- 未上传文件的内置解析器仍可用于导入，但下载按钮置灰。
- 新增平台格式时，解析器编码必须由后端先提供；前端不做任意列名映射。

## 关键交互

- 上传成功后显示模板、Sheet、行数和识别结果；解析失败显示可读错误。
- 商圈选择后在预览页展示默认店铺参数摘要；商圈模板缺少创建必填参数时由后端拒绝创建。
- 预览表展示错误和警告信息；错误行不会导入，批次完成后显示部分成功统计。
- 预览表的有效商品行使用数字输入框编辑售价，确认导入时提交修改后的价格。
- 导入记录为“预览中”时，操作栏显示“继续编辑”，重新打开已保存预览并继续确认导入；已进入导入或完成状态的批次不显示该操作。
- 确认前展示新店铺、商品和配送等关键参数，并明确确认会创建新店铺。
- 记录页操作区提供“查看明细”“删除商品数据”“删除店铺及商品”，危险操作使用二次确认。

## 状态

- 上传中、解析中、导入中：按钮禁用并显示进度。
- 无数据：显示模板下载和新建导入引导。
- 无可下载文件：提示先进入模板管理上传模板文件。
- 部分失败：显示成功/跳过/失败统计，并突出错误明细入口。
- 删除中：锁定当前批次操作，完成后刷新记录。
