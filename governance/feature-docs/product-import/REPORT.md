# 店铺导入实现报告

状态：功能实现和 Maven 模块化拆分完成，等待部署环境联调。

本期已交付：

- 门店中心下的“店铺导入”菜单和权限迁移。
- 美团外卖用户端模板解析、模板文件 OSS 上传/直链下载、预览和确认导入。
- 导入模板管理：模板编码、名称、版本、解析器绑定、OSS 文件元数据和多模板选择。
- 商圈店铺模板默认值继承；首期始终创建新店铺，不支持已有店铺。
- 批次、明细、目标店铺/商品/分类 ID 关联、分页查询和安全删除；未改动核心店铺、商品、分类表结构。
- 管理端导入向导、导入记录、明细和危险操作二次确认。

验证结果：店铺导入模块编译、Server 聚合编译、店铺导入页面/API client ESLint、真实 Excel 解析均通过；前端 `ts:check` 受仓库现有 TypeScript 类型入口缺失影响，未能执行到页面类型诊断。

部署说明：升级 `backend/sql/upgrade-2026-07-15-product-import.sql` 后，在“门店中心 → 店铺导入 → 模板管理”上传 `美团外卖商品导入模板.xlsx`。当前工作区不内置该二进制文件，因此首次部署需要由管理员完成上传；后续下载直接使用 OSS 中的静态文件。

边界说明：上传多个文件不等于自动支持多个未知平台格式。每个模板必须绑定已有 `ProductImportTemplateParser`；新增平台格式需要先增加后端解析器，再在后台上传对应模板文件。

模块化说明：导入流程已从 `yshop-module-product-biz` 移至独立的 `yshop-module-store-import-biz`。商品模块只通过 `ProductImportWriteApi` 提供商品写入/清理能力，门店导入模块负责解析、预览、批次和模板管理；拆分后保持现有 API、权限和数据库命名不变。
