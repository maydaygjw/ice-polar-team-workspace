# 客户联系人同步测试计划

## 前置条件

- test 环境已执行联系人表和菜单权限升级脚本。
- 使用具备客户联系权限的企业微信配置；企业微信已绑定与小程序同主体的微信开发者账号。
- 准备至少三类联系人：可返回 UnionID 且能匹配会员、可返回 UnionID 但无会员匹配、无法返回 UnionID。
- 准备至少一名跟进多个客户的企业微信员工，以及一个由多个员工跟进的客户。

## 核心场景

| 编号 | 场景 | 预期 |
|---|---|---|
| E2E-01 | 首次同步联系人 | 分页获取授权范围内联系人，新增记录并返回汇总 |
| E2E-02 | UnionID 匹配会员 | 唯一匹配的联系人显示对应会员，会员手机号脱敏 |
| E2E-03 | UnionID 为空或无匹配 | 联系人保留，状态为未关联，不创建会员 |
| E2E-04 | 多员工跟进 | 同一联系人详情保留全部可见跟进关系 |
| E2E-05 | 重复同步 | 不产生重复联系人或重复跟进关系，已有记录更新 |
| E2E-06 | 局部详情失败 | 成功联系人写入，失败数量和摘要正确，旧数据不被清空 |
| E2E-07 | 凭证/权限错误 | 同步失败并提示原因，不泄露 Secret 或 access token |
| E2E-08 | 租户隔离 | 其他租户无法查询、同步或看到联系人与会员匹配结果 |
| E2E-09 | 管理端状态 | 同步按钮加载/禁用、成功汇总、部分失败、空数据和详情抽屉状态正确 |
| E2E-10 | 发送文本消息 | 详情选择已同步跟进成员并提交文本后，后端创建企业微信群发任务并返回任务 ID |
| E2E-11 | 发送权限与关系校验 | 无发送权限、非当前联系人跟进成员、无跟进成员或空消息均不能创建任务 |

## 回归检查

- 企业微信配置新增、编辑、删除和客户群同步行为不受影响。
- 企业微信群发任务创建成功后，确认企业微信客户端收到待发送任务；不把任务创建误判为客户已收达。
- 会员小程序登录、公众号登录和已有 UnionID 回填行为不受影响。
- 后端目标模块测试、管理端类型检查和目标构建结果记录在 `test-notes.md`。
