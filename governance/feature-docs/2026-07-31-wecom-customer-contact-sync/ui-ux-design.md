# UI/UX 设计

## 页面入口与布局

- 在现有“微信管理 → 企业微信”下新增“客户联系人”页面，与“企业微信配置”“客户群”同级。
- 页面沿用现有 `ContentWrap`、查询表单、表格、分页和详情抽屉布局，不新增独立视觉主题。
- 顶部查询区包含企业微信配置、联系人名称、外部联系人 ID、UnionID、关联状态和查询/重置操作。
- 第二个内容区显示联系人表格；移动或窄屏宽度下允许横向滚动，固定操作列。

## 列表字段

- 联系人头像与名称。
- 外部联系人 ID。
- UnionID 脱敏值。
- 跟进员工数。
- 会员关联状态：已关联、未关联、存在多个候选。
- 关联会员摘要：会员编号、昵称、脱敏手机号。
- 最近同步时间。
- 操作：查看详情。

## 同步交互

- 企业微信配置列表新增“同步客户联系人”按钮，沿用客户群同步权限。
- 点击后弹出确认提示，说明会刷新当前配置的联系人快照，不删除历史联系人。
- 同步期间按钮禁用并显示加载状态；完成后用成功提示展示新增、更新、匹配、未匹配和失败数量。
- 部分失败使用警告提示，并允许用户进入列表查看成功数据和失败摘要；不显示 Secret、access token 或原始请求内容。

## 详情抽屉

- 抽屉顶部展示头像、联系人名称、联系人类型、关联状态和最近同步时间。
- 基本信息区展示外部联系人 ID、脱敏 UnionID、企业信息和当前会员摘要。
- 跟进员工区以表格展示员工 ID、备注、描述、添加来源和首次跟进时间。
- 详情抽屉提供“发送消息”按钮；有多个跟进成员时先选择发送成员，再输入文本内容。
- 发送确认提示明确说明：这会创建企业微信群发任务，跟进成员仍需在企业微信客户端确认发送。
- UnionID 为空时展示“企业微信未返回 UnionID”；无会员匹配时展示“当前租户未找到对应会员”；多匹配时展示“存在多个候选，暂不自动关联”。

## 状态与安全

- 初始无配置时提示先维护企业微信配置；无联系人时区分“尚未同步”和“同步后暂无联系人”。
- 列表加载、同步中、详情加载和接口失败均使用现有 Loading/Message/Error 组件模式。
- UnionID 和手机号默认脱敏显示；Secret 与 access token 永不出现在页面、详情或错误提示中。
- 无查询权限时不渲染联系人数据；无同步权限时隐藏同步入口。
- 无发送权限时隐藏“发送消息”入口；没有跟进成员时按钮禁用并提示“暂无可用发送成员”。

## 兼容性

- 桌面端优先，沿用现有后台表格密度和间距；不新增小程序页面。
- 表格列过多时保持关键身份字段与操作列可见，其余字段可横向查看。
