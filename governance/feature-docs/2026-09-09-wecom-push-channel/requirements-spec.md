# 企业微信推送通道

## Scope

在企业微信客户群模块增加海豚私域推送通道维护，并允许客户群定时推送选择官方企业微信或指定海豚私域通道。

## Business Rules

- 推送通道按租户隔离；同一商圈允许多个通道，以备注区分。
- 官方通道使用现有企业微信群发 API。
- 海豚私域通道使用维护的 Webhook，支持文本和小程序素材。
- 海豚私域不支持图片、视频、链接素材；任务遇到这些素材时失败并记录原因。
- 既有定时任务兼容为官方通道。

## Acceptance Criteria

- 可对通道进行分页查询、新增、编辑、删除。
- 新建定时推送时可选择官方或已维护的海豚私域通道。
- 定时执行按保存的通道发送，结果可查询。
- Webhook payload 符合海豚私域文档的 text / miniProgram 格式。
