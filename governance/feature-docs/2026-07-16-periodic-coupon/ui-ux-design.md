# UI/UX 增量 — 普通券与周期券（重新实现）

## 后台优惠券表单

- 在优惠券名称附近增加“券类型”单选：普通券、周期券；默认普通券。
- 增加必填“所属商圈”单选下拉；一张优惠券只能选择一个商圈。
- 店铺适用范围改为三选一：不限制店铺、指定店铺、排除店铺。
- 店铺选择器只加载所属商圈下的店铺；“指定店铺”和“排除店铺”均支持多选；“不限制店铺”不显示店铺选择器且提交空店铺列表。
- 店铺范围与“适用商品”分开配置，反选模式明确提示“所选店铺不可用，其他店铺可用”。
- 周期券显示“发放时间”：发放开始时间、发放结束时间、每 N 天可领取一次；`N` 默认 1，周期起点为发放开始时间。
- 周期券的用券时间只显示并选中“领取后立即生效，有效期 X 天”，有效天数必须大于 0；隐藏或禁用“固定时间”和“无限制时间”。
- 周期券的领取后有效起止时间按每次领取时间计算，并在发放后固化到用户券；不将发放开始/结束时间填入 `takingEffectTime`/`expirationTime`。
- 周期券显示说明“每个周期限领 1 次，进入下一周期可再次领取，每次领取生成一张独立券”。
- 如配置了每人领取上限，页面说明该上限按整个发放窗口累计计算，不随时间窗口分段重置。
- 周期券兑换码类型固定显示为“无码（页面领取）”，隐藏通用码和一卡一码选项。
- 校验错误在对应表单项下方提示，重点覆盖发放起止时间、领取后有效期和每人领取上限。

## 列表

- 增加“券类型”列，显示普通券/周期券。
- 增加“店铺范围”列，显示不限制、指定店铺或排除店铺。
- 兑换码类型列保留普通券的现有展示，不增加展示开关；周期券显示无码。
