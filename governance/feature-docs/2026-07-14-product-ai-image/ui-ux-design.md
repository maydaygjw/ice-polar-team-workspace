# UI/UX 增量设计

## 布局

- 商品编辑“基本信息”页的封面图素材组件右侧增加 `AI 生成图片` 次按钮；保留现有素材库入口。
- 按钮下方或右侧显示候选图预览卡片，建议宽度 180px、高度 180px，使用 `contain`，不挤压原封面上传区域。
- 预览卡片包含状态文本和操作按钮：生成中显示加载态，成功显示“采用此图片”，失败显示原因和“重新生成”。

## 交互状态

- 初始：只显示生成按钮，不显示候选图。
- 生成中：按钮禁用，预览区显示 loading；禁止对当前任务重复发起请求。
- 成功：显示临时预览图和提示“图片仅用于预览，采用后保存到 OSS”；采用按钮可用。
- 采用中：采用按钮禁用并显示 loading；原封面保持可见。
- 采用成功：关闭候选操作，更新封面图组件值并提示成功。
- 失败/过期：保留原封面，显示简短错误提示，允许重新生成。

## 适配与安全

- 复用 Element Plus 按钮、图片预览和消息提示样式；不引入新的全局色彩或组件库。
- 预览图使用服务端返回 URL，不向浏览器暴露 API Key。
- 关闭编辑弹窗时清理轮询定时器，避免结果回写到后续打开的商品。
