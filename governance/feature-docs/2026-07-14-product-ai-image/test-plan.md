# E2E 测试计划

## 环境前置

- 测试环境配置 `AI_IMAGE_ENABLED=true`、测试用百炼 API Key 和已验证的图像模型；master file client 指向测试 OSS。
- 使用具备 `shop:store-product:update` 的测试管理员和一个已有测试商品；禁止使用生产或个人商品数据。

## 场景

1. 打开商品编辑页，确认封面图旁存在 AI 生成按钮；填写/保留名称、简介、详情并点击生成。
2. 验证生成请求期间按钮禁用；同步返回成功后验证候选图片可预览。
3. 点击采用此图片，验证提示成功、封面图替换，并重新打开商品确认封面仍为 OSS 地址。
4. 模拟百炼失败或关闭配置，验证失败提示且原封面不变。
5. 关闭编辑弹窗后重新打开另一个商品，验证旧任务轮询不会替换新商品封面。

## 断言与副作用

- 仅断言用户可见状态、商品封面和权限行为；不在 E2E 中直接调用后端 API 或数据库。
- 生成会产生外部模型调用和测试 OSS 文件，测试数据可保留并需在 `test-notes.md` 记录清理方式。
