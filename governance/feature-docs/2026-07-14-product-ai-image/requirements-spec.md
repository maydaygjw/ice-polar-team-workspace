# 商品图片 AI 自动生成

## Scope

### In

- 在管理后台商品编辑页的封面图区域提供“AI 生成图片”入口和预览区。
- 使用商品编号对应的商品名称、商品简介和商品详情生成一张候选封面图。
- 展示生成中的、成功、失败和过期状态。
- 用户确认采用候选图后，由后端把图像保存到当前文件存储（生产配置为 OSS），并设置为该商品封面图。

### Out

- 不自动替换现有封面图；必须由用户明确点击采用。
- 不生成轮播图、SKU 图片或商品详情图片。
- 不在小程序端直接调用百炼，也不暴露百炼 API Key。
- 本期不提供提示词编辑、风格选择、多图批量生成和历史生成记录。

## Use Cases

### 商品管理员生成并采用封面图

1. 管理员打开已有商品的编辑页，确认名称、简介和详情内容。
2. 点击封面图旁的“AI 生成图片”。
3. 系统提交商品文本并显示生成中状态；管理员可等待预览。
4. 生成成功后查看候选图，点击“采用此图片”。
5. 系统把候选图上传到文件存储，更新商品封面图并刷新预览。

## Business Rules

- 仅已有商品的编辑场景可生成；商品必须属于当前租户，且操作人需要商品更新权限。
- 生成使用当前编辑表单中的商品名称、商品简介和商品详情；未保存的文本也可用于本次生成。
- 名称不能为空；简介和详情可以为空，但至少应存在可用于描述商品的名称。
- 每个生成任务只允许为创建任务时指定的商品和租户采用，不能跨商品或跨租户复用。
- 候选图采用前必须经过服务端校验和下载，客户端不得直接把任意 URL 写入商品封面字段。
- 采用成功后只更新商品封面图，不修改商品名称、详情、轮播图和 SKU 数据。
- 百炼任务和候选 URL 仅短期有效；过期、失败或找不到任务时，用户需要重新生成。
- API Key 仅从服务端环境配置读取，不进入前端响应、日志或代码仓库。

## Frontend Requirements

- 封面图区域保留现有素材选择能力，并在其旁边增加 AI 生成按钮。
- 生成按钮在生成中禁用，完成或失败后可再次生成。
- 生成前如果名称为空，应在页面内提示；生成按钮不应触发整个商品保存。
- 预览区显示候选图、生成状态、重新生成和采用按钮。
- 采用成功后将候选图作为封面图显示；采用失败保留原封面图并提示原因。
- 关闭编辑弹窗时停止轮询，不因关闭弹窗而保存商品其他字段。

## Edge Cases

- 百炼配置未启用、API Key 缺失、模型不可用或额度/限流：展示可理解的失败提示，不泄露供应商密钥和原始响应。
- 百炼任务超过前端等待窗口仍未完成：停止轮询并提示可稍后重新查看/重新生成。
- 生成 URL 在采用时已过期或下载失败：不更新商品封面。
- OSS 上传成功但商品更新失败：保留原封面，记录服务端错误，允许再次采用或重新生成。
- 管理员在生成期间切换商品或关闭窗口：旧任务结果不得写入新商品。
- 商品已被删除或当前管理员失去数据权限：采用失败且不修改任何商品。

## Acceptance Criteria

- 已有商品编辑页可发起 AI 生成请求，提交名称、简介和详情，且前端不包含 API Key。
- 百炼同步返回后，页面能展示候选图片；失败有明确反馈。
- 点击采用后，后端完成候选图下载、OSS/当前文件存储上传和商品封面更新，页面显示新封面。
- 不能使用其他租户或其他商品的任务采用图片；未授权请求返回统一权限/业务错误。
- 生成或采用失败时现有封面和商品其他字段不被清空或覆盖。
- backend 测试通过，admin 完成 TypeScript 检查和生产构建；核心 UI 链路有 E2E 测试说明。

## Assumptions

- 用户提供的百炼控制台模型对应的模型名称/部署名称通过服务端配置注入；当前默认按北京地域万相 `wan2.6-t2i` HTTP 同步协议配置。
- 本期使用百炼北京地域 HTTP 同步图像接口；默认 endpoint 可由环境变量覆盖。
- 现有 infra FileApi 已将内容写入 master file client，因此部署环境把 master client 配置为 OSS 即满足“上传 OSS”。
