# 活动模板周期频率技术设计

## 模块影响

- `backend/yshop-module-activity`：扩展模板周期类型校验、期次日期计算和数据库字段约束。
- `admin`：扩展模板周期配置、列表展示和提交参数。
- 不影响 `miniapp`、`h5` 和活动用户端 API。

## 关键决策

- 复用现有 `cycle_type` 字段，新增值 `2` 表示每天；`1` 继续表示每周，避免新增字段和期次表冗余。
- `cycle_weekday` 对按天模板允许为空；按周模板仍由业务校验保证为 1-7。
- 期次生成只改变目标日期计算，期次快照和现有幂等唯一约束保持不变。
- 每天模式的结束时间取开奖模式的开奖时间，抽奖模式取报名结束时间；若当天已结束则取下一天。

## 风险与兼容

- 旧表字段 `cycle_weekday` 为非空，需要迁移为可空；旧数据无需回填，继续按周解释。
- 不修改基线 SQL，使用 `backend/sql/upgrade-2026-09-23-activity-cycle-frequency.sql`，并提供回滚语句。
