# 活动模板周期频率需求

## Scope

- In：活动模板支持按周或按天配置，并按模板频率生成活动期次；管理后台可配置和展示周期频率。
- Out：不改变期次报名、开奖、抽奖、奖品快照和历史期次规则；不新增客户端接口。

## Business Rules

- 周期类型 `1` 表示按周，必须选择周一至周日中的一天。
- 周期类型 `2` 表示按天，不需要选择星期。
- 按周模板继续从当前日期计算最近的目标星期；当天已超过本期结束时间时顺延到下一周。
- 按天模板继续从当前日期计算最近期次；当天已超过本期结束时间时顺延到下一天。
- 生成接口的幂等和最多生成未来 3 个期次的约束保持不变。
- 历史模板未迁移配置为按周，已有期次不重新计算。

## Frontend Requirements

- 模板表单提供“按周/按天”选择。
- 选择按周时显示并要求选择星期；选择按天时隐藏星期选择。
- 模板列表周期列显示“每天”或“每周X”。

## Acceptance Criteria

1. 新建按天模板可以保存，生成期次得到当天或下一天的期次。
2. 新建按周模板仍按选定星期生成，且当天结束后顺延一周。
3. 按天模板连续生成第 1、2、3 期时，期次日期逐日递增且不重复。
4. 历史按周模板和已生成期次的日期、时间和业务行为不变。
5. 每天模式不提交无意义的星期值，按周模式缺少星期时保存失败。

## Assumptions

- “创建活动期次”沿用现有生成接口和 `occurrence=1..3` 语义；按天模式仅改变相邻期次的日期间隔。
