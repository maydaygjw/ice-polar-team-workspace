# UI/UX 设计 — Adapay 店铺收入报表

## 页面

- 菜单：门店中心 → 店铺收入报表。
- 路由：`/mall/store/profit-sharing-income`。
- 页面组件：`views/mall/store/profitSharingIncome/index.vue`。
- 页面为只读报表，不提供编辑、重试、提现或调整按钮。

## 汇总区

筛选栏提供结算日期范围、店铺 ID、查询和重置。主表列：结算日期、店铺名称、结算订单数、订单金额合计、店铺结算收入合计、操作。

收入金额使用人民币元格式并保留两位小数；结算日期显示 `YYYY-MM-DD`。金额列右对齐，收入合计使用强调色。

## 明细穿透

点击「查看明细」打开 Dialog，标题包含店铺名称和结算日期。顶部展示该日订单数、订单金额合计、店铺收入合计；下方分页表展示订单号、订单金额、店铺结算金额、结算时间、分账状态。

订单号可点击跳转既有订单详情；订单不存在或已删除时保留文本并显示不可用提示。明细仅展示店铺角色金额，不展示其他角色金额和敏感收款人信息。

## 状态

- 加载：表格显示 loading。
- 空汇总：显示「暂无店铺结算收入数据」。
- 空明细：显示「该店铺当日暂无结算明细」。
- 请求失败：沿用后台统一错误提示，保留当前筛选条件。
- 汇总分页和明细分页互不影响；关闭明细后再次打开重新加载目标日期和店铺。
