# 企业微信素材组外部素材需求规格

## Scope

### In Scope

- 为现有企业微信素材组增加外部素材引用能力。
- 定义统一的外部素材提供方标准：输入为素材组配置的参数，输出为同一种类型的、有序的微信/企业微信可发送标准素材列表。
- 首期支持两种外部素材输出类型：`TEXT`、`MINI_PROGRAM`。
- 将现有私域推送中的“一口价商品文本”接入为首个外部素材提供方。
- 外部素材可与普通素材共同存在于素材组中，并按素材组顺序引用和发送。
- 外部素材支持客户群手动群发、客户群定时推送和企业微信欢迎语。
- 外部素材按租户和企业微信配置遵守现有数据隔离与归属校验。

### Out of Scope

- 不改变现有一口价私域 Webhook 推送任务；旧链路继续保留。
- 不支持跨商圈的外部素材；一次外部素材引用只能服务一个商圈。
- 不支持一个外部素材提供方一次返回多种素材类型；同一次调用可以返回多个同类型素材。
- 不支持首期外部 `IMAGE`、`VIDEO`、`LINK` 类型。
- 不允许管理员填写任意 URL 或任意代码来调用未注册的外部服务；外部数据源必须是系统已注册的提供方。
- 不新增小程序端、DMS 或新的外部业务系统。
- 不在本期实现外部素材历史版本、缓存管理、手动刷新历史结果或跨租户共享。

## Terminology

- **素材组**：现有企业微信素材组，由多个有序素材组成，可用于客户群群发、定时推送和欢迎语。
- **普通素材**：当前已保存到素材组中的静态文字、图片、小程序、链接等素材。
- **外部素材**：素材组中保存的是提供方标识和参数，实际内容在预览或发送时由提供方动态生成的素材。
- **外部素材提供方**：系统内注册的业务适配器。它接收标准化参数和当前租户/企业微信配置上下文，返回同一种类型的有序标准素材结果列表。
- **一口价外部素材**：从外部商城获取当前商圈热门一口价商品，生成一段可发送的文本内容。

## User Goal

管理员可以在不手工复制动态商品文案的情况下，把一口价商品内容作为一个可复用的素材放入素材组；发送时系统自动获取当前商圈的最新内容，并与素材组中的其他素材一起发送。

## Use Cases

### UC-1 配置外部素材

管理员在素材组中新增外部素材，选择系统已配置的提供方并填写该提供方参数定义要求的业务参数。`externalType`、`externalMaxCount` 和参数定义均由系统配置，管理员不能输入或修改；首期一口价提供方至少需要配置一个商圈编码。

一个外部素材引用只绑定一个商圈。需要向多个商圈发送时，必须分别配置对应商圈的外部素材或素材组，不把多个商圈合并成一次外部素材结果。

### UC-2 预览外部素材

管理员在素材组编辑或群发配置中预览外部素材。系统调用提供方获取实时结果，并按标准素材类型展示文本或小程序卡片预览。

预览失败时应明确提示失败原因，不能把未解析的提供方标识或原始异常堆栈作为素材内容展示。

### UC-3 使用素材组发送

管理员使用包含外部素材的素材组创建客户群手动群发、客户群定时推送或企业微信欢迎语。系统在实际发送前重新解析外部素材，并把本次解析结果与普通素材一起转换为企业微信发送内容。

已创建的发送任务使用创建时解析出的内容快照；之后素材组参数或提供方结果变化，不影响已创建任务。

### UC-4 生成一口价文本

一口价提供方复用现有一口价商品查询逻辑：按照素材组中的商圈参数和执行日期获取外部商城商品，生成文本素材结果列表；首期受现有素材组文本数量限制，Provider 配置的 `externalMaxCount` 固定为 1。

一口价外部素材的输出仍为 `TEXT` 素材列表；每个商品按统一规则生成一个文本素材，结果保持提供方返回顺序。商品名称、价格和购买链接组成最终文本内容；当前旧的私域 Webhook 推送仍按原有逻辑独立执行。

### UC-5 生成小程序素材

系统支持后续通过同一标准接入小程序素材提供方。提供方返回图片 URL、标题和页面路径；系统补充当前租户默认小程序 AppID，并在企业微信发送前将图片转换为企业微信要求的临时媒体标识。

### UC-6 生成饭火轮新店素材

饭火轮新店 Provider 调用 `GetNewStoreList` 接口，使用素材参数中的商圈编码获取新店列表，并将有效门店的 `logo`、`name`、`id` 分别组装为小程序素材的封面图片、标题和页面 `storeId` 参数。页面固定为 `hlmall/pages/takeout/takeoutindex?storeId={门店ID}`。

该 Provider 的 `externalMaxCount` 固定为 3、输出类型固定为 `MINI_PROGRAM`。接口返回超过 3 个有效门店时随机抽取 3 个；返回空列表时返回空结果，本次素材项跳过，不影响同素材组其他素材发送。

## Standard External Material Contract

外部素材提供方每次调用返回一个有序标准素材结果列表。列表可以包含一个或多个结果，但所有结果必须对应同一种首期支持的类型：

```text
ExternalMaterialResult[]
└── each item
    ├── type: TEXT | MINI_PROGRAM
    └── payload
        ├── TEXT
        │   └── content
        └── MINI_PROGRAM
            ├── imageUrl
            ├── title
            └── page
```

系统内 Provider 配置表至少包含：

```text
ExternalMaterialProviderConfig
├── provider
├── externalType: TEXT | MINI_PROGRAM
├── externalMaxCount: positive integer
├── paramsDefinition
└── enabled
```

外部素材引用只保存 Provider 标识和按参数定义校验后的业务参数；保存时读取 Provider 配置中的 `externalType` 和 `externalMaxCount`。`externalMaxCount` 是该引用在素材组中预留的最大展开数量。以非文字素材为例，素材组的数量预算为：`普通非文字素材数量 + Σ(各外部素材 externalMaxCount) ≤ 9`。例如已有 2 个普通图片素材时，外部素材引用的 `externalMaxCount` 合计最多为 7；某次实际返回 3 个素材并不会释放未使用的预算。

标准字段要求：

| 类型 | 字段 | 要求 |
|---|---|---|
| `TEXT` | `content` | 必填，保留换行，遵循现有企业微信文本长度限制 |
| `MINI_PROGRAM` | `imageUrl` | 必填，必须是可由后端读取并上传到企业微信的图片地址 |
| `MINI_PROGRAM` | `title` | 必填，遵循现有小程序消息标题长度限制 |
| `MINI_PROGRAM` | `page` | 必填，使用小程序页面路径格式，并遵循现有前导 `/` 规则 |
| `MINI_PROGRAM` | `appId` | 不由提供方返回，由系统注入当前租户默认小程序主账号 AppID |

标准接口的业务约束：

- 输入参数由素材组中的外部素材引用保存，提供方不得依赖管理端直接传入的秘密凭据。
- 提供方返回类型必须与外部素材引用声明类型一致；列表内不得混入其他类型。
- Provider 配置的 `externalMaxCount` 必须为正整数；非空实际返回数量不得超过该配置值。允许 Provider 返回空结果，表示本次跳过该外部素材项。
- 返回列表必须保留顺序；系统不得按名称、ID 或其他字段自动重排。
- 每个 `TEXT` 结果不得为空；每个 `MINI_PROGRAM` 结果的 `imageUrl`、`title`、`page` 任一缺失都视为结果无效。
- 外部素材提供方不得返回混合类型或包含未定义字段语义的自由格式消息。
- 外部素材结果在进入企业微信发送链路前必须逐项转换为现有标准消息模型，不能把提供方专属对象直接传给企业微信客户端。

## Business Rules

- 外部素材是素材组中的一个有序素材项，拥有独立的提供方标识和参数。
- 外部素材引用遵守当前租户和企业微信配置归属；不能引用其他租户或其他企业微信配置下的素材组数据。
- 一个外部素材引用只能指定一个商圈编码；不支持跨商圈查询、跨商圈合并或自动选择多个商圈。
- 一个外部素材提供方一次可以返回一个或多个结果，但只能返回系统配置的 `externalType`，并且实际数量不得超过该 Provider 配置的 `externalMaxCount`。
- 饭火轮新店 Provider 最多输出 3 个小程序素材；超过 3 个时随机抽取 3 个，空列表不视为解析失败并跳过该素材项。
- 首期外部素材类型只有 `TEXT` 和 `MINI_PROGRAM`。
- 外部 `TEXT` 素材只能位于素材组第一个位置，后端和管理端均必须校验；不满足时不能保存或发送。
- 素材组沿用现有数量约束：最多一个 `TEXT` 素材、最多九个非文字素材。
- 外部素材引用对应 Provider 配置的 `externalMaxCount` 作为数量预算参与校验；同一素材组中所有外部素材引用的 `externalMaxCount` 与已有普通非文字素材数量之和必须小于等于 9。保存、复制、排序、预览和发送前均需校验该预算。
- 外部 `TEXT` Provider 的 `externalMaxCount` 必须配置为 1，且一个素材组最多引用一个外部 `TEXT` 素材。
- 外部 `MINI_PROGRAM` 素材可以按返回顺序展开，并与普通素材按素材组顺序混排。
- 普通素材与外部素材可以共同组成一个素材组；素材组排序调整必须保留外部素材引用的位置。
- 外部素材在预览和实际发送时动态获取，不把动态响应内容提前固化为普通素材内容。
- 手动群发、定时推送和欢迎语在发送前都必须重新解析外部素材；发送任务创建后使用当次解析结果快照。
- 外部素材解析失败时，本次预览或发送失败，不得发送部分内容，也不得把旧结果静默当作新结果；Provider 明确返回空结果时仅跳过该素材项。
- 一口价提供方默认使用执行当天日期；商圈编码由素材组参数指定。
- 一口价私域 Webhook 任务与素材组外部素材可以并存，现有任务行为不因本功能改变。
- 外部素材调用、图片读取和企业微信上传不得在日志或管理端响应中暴露 Secret、access token 或其他敏感信息。

## Frontend Requirements

- 素材组新增“外部素材”类型入口，并支持选择系统已注册的提供方。
- 管理端根据 Provider 配置的参数定义展示表单；Provider 的 `externalType` 和 `externalMaxCount` 只读展示。一口价 Provider 至少展示商圈编码，并明确一个素材只能绑定一个商圈。
- 外部素材编辑时展示提供方和参数，不把动态结果伪装成可直接编辑的普通文字或小程序字段。
- 素材组列表和详情需要区分普通素材与外部素材，并展示提供方摘要、输出类型、系统配置的 `externalMaxCount`、商圈参数和当前排序。
- 外部素材可拖拽排序；如果类型为外部 `TEXT` 且不在第一个位置，保存前阻止操作并提示原因。
- 外部 `MINI_PROGRAM` 预览展示图片、标题和页面路径；AppID展示为系统默认小程序账号信息，不允许管理员通过外部素材表单修改。
- 预览需要展示加载中、成功和失败状态；失败时允许管理员修正参数后再次预览。
- 客户群手动群发、定时推送和欢迎语选择素材组时，能够识别并预览包含外部素材的素材组。
- 提交发送期间禁止重复提交；外部素材解析失败时提示“未发送”，不能显示为部分成功。

## Edge Cases

- 外部素材提供方不存在、已禁用或参数缺失：禁止保存或发送，并返回明确的配置错误。
- 商圈编码为空、包含多个商圈或试图跨商圈查询：禁止保存或发送。
- 外部接口超时、返回非成功状态、返回数量超过 Provider 配置的 `externalMaxCount` 或返回格式不符合标准：本次解析失败；Provider 返回空列表时跳过该素材项。
- 素材组中普通非文字素材数量与外部素材引用对应的 `externalMaxCount` 之和超过 9：禁止保存、复制、预览和发送。
- 外部素材返回混合类型、顺序丢失或非空数量超过配置上限：本次解析失败；Provider 返回空结果时按规则跳过。
- 一口价商品数据缺少生成文本所需的关键字段：跳过无效商品；如果最终没有可用商品，整个外部素材解析失败。
- 外部 `TEXT` 被移动到首位以外：保存、预览提交和发送提交均需重新校验并拒绝。
- 外部 `MINI_PROGRAM` 缺少图片 URL、标题或页面路径：拒绝生成标准素材。
- 外部小程序图片无法读取、格式不支持或企业微信临时素材上传失败：本次发送失败，不创建不完整任务。
- 当前租户没有默认小程序主账号：外部 `MINI_PROGRAM` 无法生成，且不能使用其他租户的 AppID 兜底。
- 素材组在打开预览或发送窗口后被删除、修改或外部参数变化：提交时重新读取并校验最新素材组。
- 定时推送每次执行均重新获取动态内容；同一素材组前后两次发送允许产生不同文本。
- 同一一口价内容同时通过旧私域推送和素材组发送时，两个链路独立执行，系统不自动去重。

## Acceptance Criteria

- [ ] 管理员可以在企业微信素材组中新增、编辑和删除外部素材引用。
- [ ] 外部素材必须选择系统已注册的提供方，并保存该提供方要求的参数。
- [ ] 一个外部素材引用只能绑定一个商圈，不支持跨商圈参数。
- [ ] 系统 Provider 配置表维护 `externalType`、`externalMaxCount` 和参数定义；管理员只能选择 Provider 并填写定义中的业务参数。
- [ ] 提供方可返回一个或多个同类型素材，实际数量不超过 Provider 配置的 `externalMaxCount`，且保持返回顺序。
- [ ] 饭火轮新店 Provider 配置为 `MINI_PROGRAM`、最大数量 3；超过 3 个有效门店随机取 3 个，空列表跳过。
- [ ] 外部 `TEXT` 结果包含有效 `content`，并且对应素材只能位于素材组第一个位置。
- [ ] 外部 `MINI_PROGRAM` 结果包含有效 `imageUrl`、`title`、`page`，AppID由当前租户默认小程序账号注入。
- [ ] 外部素材可以与普通素材共同存在；素材组中普通非文字素材数量与各外部素材 Provider 的 `externalMaxCount` 之和不超过 9，外部结果按返回顺序参与发送。
- [ ] 预览、手动群发、定时推送和欢迎语发送均会在执行前解析外部素材。
- [ ] 发送任务使用创建时的素材快照，不受后续素材组修改影响。
- [ ] 首个外部素材提供方可以按商圈和当天日期查询一口价商品，并生成一段可发送的 `TEXT` 内容。
- [ ] 一口价外部素材生成失败时，不发送不完整内容，并向管理端返回可诊断但不泄露敏感信息的错误。
- [ ] 现有一口价私域 Webhook 推送任务行为保持不变。
- [ ] 所有外部素材读写、解析和发送均通过租户及企业微信配置归属校验。

## Assumptions

- 本需求中的“素材组”指现有企业微信素材组，不扩展到商品素材库或其他非企业微信素材组。
- 外部素材提供方是服务端注册能力；管理端只选择提供方和填写业务参数，不配置任意外部 URL、脚本或凭据。
- 首期一口价提供方的商圈编码由素材组保存，执行日期由系统按 Asia/Shanghai 当前日期生成。
- `MINI_PROGRAM` 的企业微信临时媒体上传仍复用现有发送流程，外部提供方只负责提供图片 URL、标题和页面路径。
- 外部素材不保存动态响应的历史版本；已提交任务的快照由发送任务或外部平台请求内容承担。
- 当前实现使用独立 worktree；数据库迁移、OpenAPI 契约快照和完整实现仍按 Phase 3 继续推进。
