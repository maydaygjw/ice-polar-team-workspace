# 企业微信素材组外部素材 UI/UX 增量

## 外部素材表单

- 素材类型新增“外部素材”。选择后显示启用的 Provider、系统配置的输出类型和 `externalMaxCount`（只读），以及参数定义生成的表单。
- 不提供 `externalType` 或 `externalMaxCount` 输入框；界面说明数量上限由系统 Provider 配置决定并会预占素材组预算。
- 一口价提供方展示单个商圈选择器；不允许选择多个商圈。
- 外部素材展示提供方配置，不把动态结果伪装成可编辑的普通文字、图片或小程序字段。
- 保存前显示当前预算：普通非文字素材数 + 各外部引用对应 Provider 的 `externalMaxCount` / 9；超过上限时禁用保存并说明超限项。

## 素材组列表与预览

- 外部素材行显示“外部”、提供方、系统配置的输出类型、`externalMaxCount` 和排序位置。
- 预览按素材组顺序展示动态结果；同一外部引用返回多个结果时，连续展示且保留提供方顺序。
- 预览状态区分加载中、成功、空结果/格式错误和提供方失败；不展示原始异常堆栈或敏感信息。
- 拖拽排序、复制和删除操作继续受现有权限控制，并在提交时重新校验数量预算。

## 群发与反馈

- 群发弹窗继续展示完整素材组预览，并显示展开后的附件数量和预算上限。
- 外部素材解析失败时显示“未发送”和可诊断错误；不显示“部分发送成功”。
- 保存、预览、排序和发送期间禁用重复提交；参数修正后允许再次预览。
