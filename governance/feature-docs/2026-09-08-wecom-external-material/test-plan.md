# 企业微信素材组外部素材测试计划

## 后端/API 场景

1. 创建和更新外部引用，校验只能选择启用 Provider，类型和 `externalMaxCount` 从配置表读取，参数符合 Provider 参数定义。
2. 提供方返回 1 个及多个同类型结果，校验数量、字段和原始顺序均被保留。
3. 提供方返回混合类型、空列表、超过配置的 `externalMaxCount`、字段缺失、超时或非成功状态，确认整体解析失败。
4. 校验普通非文字素材数量与各 Provider `externalMaxCount` 之和等于 9 时成功，超过 9 时创建、更新、复制、排序、预览和发送均拒绝。
5. 校验外部 `TEXT` Provider 的 `externalMaxCount` 只能为 1 且必须位于首位；多个外部 `TEXT` 被拒绝。
6. 校验外部结果按素材组顺序展开，并转换为既有企业微信消息模型。
7. 校验租户、企业微信配置归属、权限和凭据脱敏；确认外部结果不落库为普通素材。
8. 校验发送任务保存完整内容快照，后续提供方结果变化不影响已创建任务。

## E2E 场景

1. 管理员选择系统配置为 `externalMaxCount=3` 的 Provider，预览三个同类型结果并确认顺序；管理员不能修改该数量。
2. 管理员配置多个外部引用，界面实时展示数量预算；超过 9 时阻止保存。
3. 在素材组中混排普通素材与外部素材，确认预览和发送顺序一致。
4. 模拟外部解析失败，确认页面显示“未发送”，没有部分成功状态。
5. 无权限或跨租户用户无法查看、修改或发送外部素材组。

- 按仓库现有 E2E 配置执行素材组管理、预览和群发流程。
