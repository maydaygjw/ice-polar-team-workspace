# 企业微信商圈欢迎语模板需求规格

## Scope

### In Scope

- 在“企业微信”下新增“欢迎语管理”模块。
- 每个企业微信配置、每个启用商圈最多维护一条欢迎语模板。
- 模板固定由一条文字和一个附件组成，附件类型为图片或小程序二选一，业务顺序为文字后附件。
- 图片附件从现有图片空间选择；保存时通过企业微信 `media/uploadimg` 上传并保存企业微信返回的图片 URL。
- 小程序附件使用当前租户默认的小程序主账户，管理端只读展示账户名称和 AppID；管理员可填写小程序页面 path，并上传小程序卡片封面图。
- 模板可创建、编辑、查看、启用/停用和删除。
- 管理员可从现有图片空间选择图片，并预览本地图片和当前模板内容。
- 所有数据按租户隔离，并校验商圈可见性和启用状态。

### Out of Scope

- 不支持链接、文件、视频等消息类型。
- 不支持一个商圈多套模板、按成员/部门分流或发送记录。

### Deferred

- 模板版本历史和灰度发布。

## Use Cases

### UC-1 新建欢迎语模板

管理员选择企业微信配置、商圈，填写模板名称和文字，从图片空间选择图片或小程序附件并保存。系统校验商圈有效后，图片类型按需同步企业微信素材，保存本地图片地址与企业微信素材信息。

### UC-2 编辑欢迎语模板

管理员修改名称、文字、附件类型或附件内容。未更换图片时复用原企业微信图片 URL；小程序封面在客户添加事件发送前重新上传临时素材。

### UC-3 管理模板状态

管理员启用、停用或删除模板。停用模板不可作为未来自动发送的候选模板；删除只影响本地业务关联，并按外部素材归属能力尝试删除远端素材。

## Business Rules

- 唯一范围为 `tenant + wecom account + business region`，同一范围只能存在一条未删除模板。
- 新建和编辑必须选择当前租户可见且启用的商圈。
- 模板文字不能为空；且图片附件字段或小程序附件字段必须完整，不能同时存在两种附件。
- 图片仅支持 JPG/PNG，大小由企业微信图片上传限制校验。
- 小程序页面 path 必须以 `/` 开头；小程序卡片标题复用模板名称，封面图仅支持 JPG/PNG，大小为 5B-2MB。
- 小程序封面管理阶段只保存系统文件；实际发送前根据系统文件地址上传企业微信临时素材并立即发送，不持久化临时 `media_id`。
- 企业微信 `media/uploadimg` 返回的图片 URL 用于后续客户添加欢迎语发送；系统本地文件地址仅用于后台预览和管理。
- 企业微信凭据和 access token 仅由后端使用，不返回给管理端。
- 外部上传失败时不得保存可用模板记录；原有模板编辑失败时保留原模板。
- 企业微信图片素材 URL 只作为后续发送素材，不作为本地业务主键。
- 文本允许企业微信 `%NICKNAME%` 占位符，系统不改写其大小写。

## Frontend Requirements

- 列表支持按企业微信配置、商圈、状态查询。
- 列表显示模板名称、企业微信配置、商圈、文字摘要、附件类型/缩略图、状态和更新时间。
- 表单按“企业微信配置 → 商圈 → 模板名称 → 欢迎文字 → 附件类型 → 附件配置 → 预览”组织。
- 从图片空间选择图片时展示本地预览和企业微信图片 URL 已生成状态；选择小程序时展示默认小程序账户、path、封面图和本地预览。
- 保存、编辑、删除、启用/停用均显示明确的成功或失败反馈。
- 保存期间禁止重复提交；图片上传失败时保留表单内容。

## Edge Cases

- 商圈在编辑期间被停用：拒绝保存并提示重新选择。
- 同一范围已存在模板：创建失败，编辑使用原记录。
- 企业微信账号缺少客户联系权限：附件上传失败并保留可诊断错误。
- 企业微信每日图片上传额度或图片大小超限：图片附件保存时提示外部错误；小程序封面在发送时提示发送失败并记录原因。
- 图片已上传企业微信但本地保存失败：记录失败，不把该 URL 作为有效模板；后续可通过重新保存处理遗留图片素材。
- 历史模板图片的本地 URL 不可访问：列表仍显示模板状态，预览显示占位图。

## Acceptance Criteria

- [ ] 企业微信目录下出现“欢迎语管理”菜单。
- [ ] 管理员可以为一个启用商圈创建一条文字+图片或文字+小程序模板。
- [ ] 同一企业微信配置和商圈不能创建第二条未删除模板。
- [ ] 图片成功上传后保存企业微信返回的 `pic_url`，不是仅保存本地 URL。
- [ ] 小程序模板使用默认小程序账户的 AppID，能够保存 path 和封面，并发送 `miniprogram` 附件。
- [ ] 管理后台可以预览本地图片，并能看到企业微信图片 URL 或小程序素材已生成。
- [ ] 编辑文字、替换图片、启用/停用和删除均可用。
- [ ] 企业微信凭据不出现在任何管理端响应或日志中。
- [ ] 租户隔离、商圈可见性和商圈启用状态校验有效。
- [ ] 外部上传失败时不产生可用模板记录或破坏原有模板。
- [ ] 模板保存不会触发客户消息；收到客户添加事件后，发送链路根据附件类型只发送图片或小程序其中一种。

## Assumptions

- 使用现有企业微信配置中的客户联系 Secret；小程序 AppID 来自当前租户默认小程序主账户。
- 使用现有文件服务保存后台预览图片。
- `uploadimg` 返回的企业微信图片 URL足以支持后续客户欢迎语发送。
- 第一版每个商圈只保留一个当前模板，不保存历史版本。
