# 企业微信商圈欢迎语模板需求规格

## Scope

### In Scope

- 在“企业微信”下新增“欢迎语管理”模块。
- 每个企业微信配置、每个启用商圈最多维护一条欢迎语模板。
- 模板固定由一条文字和一张图片组成，业务顺序为文字后图片。
- 图片上传到系统文件服务，同时通过企业微信 `media/uploadimg` 上传并保存企业微信返回的图片 URL。
- 模板可创建、编辑、查看、启用/停用和删除。
- 管理员可预览本地图片和当前模板内容。
- 所有数据按租户隔离，并校验商圈可见性和启用状态。

### Out of Scope

- 不处理企业微信客户添加回调。
- 不解析或消费 `WelcomeCode`。
- 不调用 `send_welcome_msg`，不自动发送欢迎语。
- 不支持链接、小程序、文件、视频等消息类型。
- 不支持一个商圈多套模板、按成员/部门分流或发送记录。

### Deferred

- 收到 `add_external_contact` 后根据 `State` 找商圈模板并发送。
- 欢迎语发送幂等、20 秒时效处理、失败重试和审计记录。
- 模板版本历史和灰度发布。

## Use Cases

### UC-1 新建欢迎语模板

管理员选择企业微信配置、商圈，填写模板名称和文字，上传图片并保存。系统校验商圈有效后上传图片到企业微信，保存本地图片地址与企业微信图片 URL。

### UC-2 编辑欢迎语模板

管理员修改名称、文字或图片。未更换图片时复用原企业微信图片 URL；更换图片时重新上传并更新远端欢迎语素材（若已建立远端素材关联）。

### UC-3 管理模板状态

管理员启用、停用或删除模板。停用模板不可作为未来自动发送的候选模板；删除只影响本地业务关联，并按外部素材归属能力尝试删除远端素材。

## Business Rules

- 唯一范围为 `tenant + wecom account + business region`，同一范围只能存在一条未删除模板。
- 新建和编辑必须选择当前租户可见且启用的商圈。
- 模板文字不能为空；图片不能为空。
- 图片仅支持 JPG/PNG，大小由企业微信图片上传限制校验。
- 企业微信 `media/uploadimg` 返回的图片 URL 用于后续客户添加欢迎语发送；系统本地文件地址仅用于后台预览和管理。
- 企业微信凭据和 access token 仅由后端使用，不返回给管理端。
- 外部上传失败时不得保存可用模板记录；原有模板编辑失败时保留原模板。
- 企业微信图片素材 URL 只作为后续发送素材，不作为本地业务主键。
- 文本允许企业微信 `%NICKNAME%` 占位符，系统不改写其大小写。

## Frontend Requirements

- 列表支持按企业微信配置、商圈、状态查询。
- 列表显示模板名称、企业微信配置、商圈、文字摘要、图片缩略图、状态和更新时间。
- 表单按“企业微信配置 → 商圈 → 模板名称 → 欢迎文字 → 欢迎图片 → 预览”组织。
- 图片上传后同时展示本地预览和企业微信图片素材 URL 已生成状态。
- 保存、编辑、删除、启用/停用均显示明确的成功或失败反馈。
- 保存期间禁止重复提交；图片上传失败时保留表单内容。

## Edge Cases

- 商圈在编辑期间被停用：拒绝保存并提示重新选择。
- 同一范围已存在模板：创建失败，编辑使用原记录。
- 企业微信账号缺少客户联系权限：图片上传失败并保留可诊断错误。
- 企业微信每日图片上传额度或图片大小超限：拒绝保存并提示外部错误。
- 图片已上传企业微信但本地保存失败：记录失败，不把该 URL 作为有效模板；后续可通过重新保存处理遗留图片素材。
- 历史模板图片的本地 URL 不可访问：列表仍显示模板状态，预览显示占位图。

## Acceptance Criteria

- [ ] 企业微信目录下出现“欢迎语管理”菜单。
- [ ] 管理员可以为一个启用商圈创建一条文字+图片模板。
- [ ] 同一企业微信配置和商圈不能创建第二条未删除模板。
- [ ] 图片成功上传后保存企业微信返回的 `pic_url`，不是仅保存本地 URL。
- [ ] 管理后台可以预览本地图片，并能看到企业微信图片素材 URL 已生成。
- [ ] 编辑文字、替换图片、启用/停用和删除均可用。
- [ ] 企业微信凭据不出现在任何管理端响应或日志中。
- [ ] 租户隔离、商圈可见性和商圈启用状态校验有效。
- [ ] 外部上传失败时不产生可用模板记录或破坏原有模板。
- [ ] 本期不会调用发送欢迎语接口，不会因模板保存触发客户消息。

## Assumptions

- 使用现有企业微信配置中的客户联系 Secret。
- 使用现有文件服务保存后台预览图片。
- `uploadimg` 返回的企业微信图片 URL足以支持后续客户欢迎语发送。
- 第一版每个商圈只保留一个当前模板，不保存历史版本。
