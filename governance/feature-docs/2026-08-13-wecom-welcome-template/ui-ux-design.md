# 企业微信欢迎语管理 UI/UX 设计

## 页面入口

- 父菜单：企业微信
- 子菜单：欢迎语管理
- 页面：后台桌面端列表 + Dialog 编辑表单

## 列表页

查询项：企业微信配置、商圈、状态。

表格列：模板名称、企业微信配置、商圈、文字摘要、附件类型/缩略图、启用状态、更新时间、操作。

操作：新增、编辑、启用/停用、删除。

## 编辑表单

顺序：

1. 企业微信配置
2. 商圈
3. 模板名称
4. 欢迎文字
5. 附件类型（图片/小程序）
6. 附件配置
7. 消息预览

预览固定展示：

```text
文字消息
图片消息
```

图片附件区域同时显示：

- 系统预览图
- 企业微信图片素材 URL 已生成/未生成

小程序附件区域显示：

- 默认小程序账户名称和 AppID（只读）
- 小程序页面 path
- 小程序封面上传和本地预览
- 小程序封面将在客户添加事件发送时上传企业微信临时素材
- 预览中固定按文字后小程序卡片展示

企业微信图片 URL 不直接作为普通图片预览源，优先使用系统文件 URL。

## 状态和反馈

- 保存中禁用重复提交。
- 上传失败时保留文字和图片选择，不关闭 Dialog。
- 删除必须二次确认。
- 停用模板显示灰色状态，启用模板显示绿色状态。
- 无模板时显示空状态和“新增欢迎语”按钮。

## 复用组件

- Element Plus `el-table`、`el-form`、`el-dialog`、`el-upload`。
- 现有企业微信账号简单列表。
- 现有商圈简单列表。
- 现有文件上传能力，仅用于系统预览文件；企业微信上传由后端接口完成。
