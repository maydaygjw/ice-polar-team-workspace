# 商圈排名竞价 — UI/UX Design（本期：admin）

范围为本期 admin 侧：竞价活动配置与竞价周期管理。竞拍监控/入围结果、miniapp 属延后期，本文 `N/A`。
栈：Vue3 + Element Plus + TS，沿用 admin 现有 coupon/card 配置页范式。

## 导航与授权

- 顶级菜单 `竞价` → 子菜单 `竞价活动`（路由 `/bidrank/auction`）、`竞价周期`（路由 `/bidrank/cycle`）。
- 菜单/按钮经租户套餐 `menu_ids` 授权；未授权租户整棵菜单不渲染，直达 URL 被后端 `@PreAuthorize` 拦截。
- 活动按钮权限：`bidrank:auction:create/update/delete/query`；周期查询使用 `bidrank:cycle:query`，周期操作统一使用活动编辑权限 `bidrank:auction:update`。

## 屏 1：竞价活动列表 `/bidrank/auction`

```
[商圈▾] [是否启用▾] [活动主题 search] [查询][重置]            [+ 新建活动]
─────────────────────────────────────────────────────────────
活动主题 | 适用商圈 | 周期 | 生效日期 | 下次生效日期 | 启用 | 操作
xxxxx   | 南通大学主校区 | 每周 | 每周一 | 2026-07-28 | ●启用 | 编辑 停用 删除 生成周期
─────────────────────────────────────────────────────────────
                                                     分页 ◁ 1 2 3 ▷
```

- 商圈下拉受当前用户部门/数据权限约束。
- `是否启用` 为开关列，即时切换 `enabled`；无草稿/发布生命周期（活动是周期模板）。
- `下次生效日期` 由周期规则派生、只读。
- 行操作：编辑 / 启停切换 / 删除 / 生成周期。存在任意周期时，编辑、启停和删除置灰。
- `生成周期`打开选择框，可选择下一次、下 2 次或下 3 次；系统按活动模板派生对应的生效日期、竞价开始/结束时间和尾款截止时间，创建后状态为“待开始”；重复点击时按竞价开始时间幂等，不创建重复周期。
- 活动停用后隐藏或禁用“生成周期”；已生成的周期仍可在周期页面查看和按状态操作。
- 当活动存在任意周期（待开始/竞价中/可付尾款/已结算）时，活动表单不可提交，档位不可增删改；页面提示“竞价活动已生成周期，暂不可变更”。

### 字段校验（前端 + 后端双校验）

| 字段 | 规则 |
|------|------|
| 活动主题 / 适用商圈 | 必填 |
| 活动周期 | 每周/每月，必选 |
| 生效日期 | 必填（周期锚点） |
| 提前天数 | 整数 ≥ 0 |
| 启动时间 | HH:mm，必填 |
| 活动时长 / 支付时间 | 整数分钟 > 0 |
| 预付比例 | 整数 1–100，默认 20 |
| 竞拍内容说明 / 规则 | 富文本，可空（建议填规则） |
| 排名起始/终止位次 | 整数，`起始 ≥ 1` 且 `起始 ≤ 终止` |
| 可拍卖数量 | `1 ≤ 数量 ≤ 终止 − 起始 + 1` |
| 起拍金额 / 最小加价 | > 0，两位小数；**UI 用元、提交转分（bigint）** |
| 档位 | 至少 1 行 |

> 允许档位范围重叠（业务规则）；不做跨档位互斥校验。
> 老系统「显示天数比例」列已移除，改为范围内随机曝光；「最小加价」为本期新增，老系统无。

## 交互与状态

- **提交**：保存活动模板并校验完整性；无草稿/发布生命周期，可反复编辑。提交前校验是否存在任意周期。
- **启用/停用**：列表开关即时切换 `enabled`；存在任意周期时禁用开关；停用后不再派生新周期（不影响已生效周期，退款/下线属延后期）。
- **删除**：二次确认；存在任意周期时禁用删除。

## 屏 3：竞价周期列表 `/bidrank/cycle`

```
[活动▾] [商圈▾] [周期状态▾] [竞价开始时间] [查询][重置]
─────────────────────────────────────────────────────────────
活动 | 商圈 | 生效日期 | 竞价开始 | 竞价结束 | 尾款截止 | 状态 | 操作
xxxxx | 南通大学主校区 | 2026-08-01 | 2026-07-31 22:00 | ... | ... | 待开始 | 开启
xxxxx | 南通大学主校区 | 2026-07-25 | 2026-07-24 22:00 | ... | ... | 竞价中 | 进入尾款 终止
─────────────────────────────────────────────────────────────
                                                     分页 ◁ 1 2 3 ▷
```

- 列表默认按 `bid_start_time` 倒序；活动、商圈和周期状态受当前用户部门/数据权限约束。
- 状态展示：待开始 / 竞价中 / 可付尾款 / 已结算；“可付尾款”表示已停止新出价，只按状态允许支付尾款。
- `开启`仅对待开始周期显示，二次确认后进入“竞价中”；不修改周期派生时间。
- `进入尾款`仅对竞价中周期显示，二次确认后进入“可付尾款”，立即停止新出价/加价。
- `手工结算`仅对可付尾款周期显示，二次确认后立即执行结算，不判断尾款截止时间。
- `删除`仅对待开始周期显示，二次确认后逻辑删除。
- `终止`对竞价中、可付尾款周期显示，二次确认后逻辑删除，停止后续支付且不再结算；待开始使用删除，已结算周期不显示终止操作。

## 空态与权限态

- 无数据：空表 + `暂无竞价活动，点击新建`。
- 无 `create` 权限：隐藏新建按钮；无 `query` 权限：不进入路由。
