# 商品必选字段契约变更

## API

- 管理后台商品创建、更新请求增加 `isRequired`（0/1），未传时按 0 处理。
- 管理后台商品详情、列表和商品编辑详情响应增加 `isRequired`（0=否，1=是）。
- C 端商品详情响应增加 `isRequired`（0=否，1=是）；本次仅透传配置，不改变下单校验。

## DB

- `yshop_store_product` 新增 `is_required` tinyint(1) NOT NULL DEFAULT 0 COMMENT '是否必选 0=否 1=是'。
- 存量商品回填为 0，回滚时删除该列。

## 兼容性

- 仅新增字段，旧客户端不传该字段时保持否；不改变历史订单快照。
- 不与选项分组的 `required` 字段混用，后者仍表示选项分组是否必选。
