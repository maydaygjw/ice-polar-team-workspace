# 管理端订单结算与对账交互设计

## 订单结算管理

- 列表仍按业务订单展示。
- 结算状态显示订单级聚合状态：待分账、处理中、已结算、部分失败、已回退。
- 详情页增加“支付分账明细”折叠区域，每个支付对象独立展示确认金额、确认号、状态和失败原因。
- 重试按钮放在支付分账子记录行，仅对失败且未回退记录可用。
- 部分成功时显示已成功和待处理子记录，禁止显示为整体已结算。

## 日终对账

- 详情筛选增加订单号、支付对象 ID、确认对象 ID和匹配结果。
- 同一订单的多个支付对象按多行展示。
- 金额差异显示账单金额、本地金额和差额，避免只展示订单总额。
- 保持现有敏感支付信息脱敏展示。
