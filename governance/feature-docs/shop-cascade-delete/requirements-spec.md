# 需求规格：店铺删除级联清理

## Scope

- 管理端删除店铺时，后端级联删除该店铺下的业务配置数据。
- 前端在删除前给出明确不可逆警告。

## Business Rules

1. 级联删除范围：
   - 店铺-管理员映射、店铺标签、预约规则/标签。
   - 商品分类、商品、商品规格属性/值/结果、套餐组/明细、商品评价。
   - 桌台、桌台分类。
   - 广告图。
2. 必须保留：
   - 管理员账号本身。
   - 历史订单、购物车分享、营收、提现、银行账户。
   - 租户共享的商品规格规则。
   - 导入批次历史。
3. 删除操作必须在同一个事务中完成。

## Frontend Requirements

- 店铺列表删除按钮点击后，先弹出级联警告确认框，用户确认后再调用删除接口。
- 警告文案需说明：将删除哪些配置数据、不可恢复、保留哪些数据。

## Acceptance Criteria

- [x] 删除店铺后，其商品、分类、桌台、广告等配置数据不可见。
- [x] 删除店铺后，历史订单、营收、管理员数据仍可查询。
- [x] 管理端删除操作前显示级联警告。
- [x] 后端编译通过，相关测试通过，前端生产构建通过。
