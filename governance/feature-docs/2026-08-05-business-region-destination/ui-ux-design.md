# 界面与体验设计：商圈目的地维护

## 商圈管理入口

- 在现有商圈列表操作列增加“商圈目的地”文字按钮，放在“店铺模板”附近。
- 按钮沿用商圈查询权限；点击后使用后台路由打开新的标签页，原商圈列表标签保留。

## 目的地标签页

- 页面顶部展示“商圈目的地”标题和当前商圈名称。
- 筛选区包含目的地名称、代码、搜索、重置和新增按钮。
- 表格列为名称、代码、地址、标签、排序、创建时间、操作。
- 空列表复用现有 Element Plus 表格空状态；查询和保存期间显示 loading。

## 表单交互

- 使用现有 `Dialog` + `el-form` 模式。
- 名称、地址、经度、纬度为必填；地址通过现有地图选择器填写，地图选定后回填地址和坐标。
- 代码、标签使用普通文本输入；排序使用数字输入，默认 0。
- 保存成功提示并关闭弹窗，刷新当前商圈目的地列表。
