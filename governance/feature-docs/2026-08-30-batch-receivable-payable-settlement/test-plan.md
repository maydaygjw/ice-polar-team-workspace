# 测试计划：应收应付批量结算

| 编号 | 场景 | 期望 |
|---|---|---|
| UNIT-01 | 多条记录全部成功 | 每条只执行一次，成功数等于总数。 |
| UNIT-02 | 一条失败、后续成功 | 返回逐条结果，后续记录仍被处理。 |
| UNIT-03 | 重复 ID | ID 只处理一次。 |
| UNIT-04 | 跨租户/不存在 ID | 该项失败且不泄露其他租户数据。 |
| UNIT-05 | 超过 100 条或空列表 | 请求校验失败。 |
| UI-01 | 选择框状态 | 不可结算记录禁用，可结算记录可选择。 |
| UI-02 | 批量确认与刷新 | 确认后调用批量接口，完成后显示汇总并刷新列表。 |
