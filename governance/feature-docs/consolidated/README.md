# 当前活动管理全量文档

本目录整理“活动管理”从 2026-09-13 一期建设到 2026-09-21 相关增量的统一需求与设计基线。

## 文档入口

- [活动管理全量需求与设计](activity-management-full-spec.md)：评审、开发、测试和交付的主文档。

## 覆盖范围

主文档合并以下功能主题：

- 活动模板、活动期次、报名、抽奖、中奖记录和临时小程序码。
- 企业微信客户管理员、社群成员和外部商城订单报名条件。
- 报名条件类型、条件实例和期次快照机制。
- 抽奖次数、单人中奖限制、报名人数上限和邀请报名奖励。
- 中奖兑奖、线下兑奖码、企业微信中奖通知和中奖公示。
- 活动 H5 Ticket 认证与活动页面小程序短链接。
- 管理后台菜单、权限、UI/UX、部署、测试和已知风险。

## 状态口径

文档中的状态分为：

- **已实现/已设计**：原功能目录已有实现记录或契约设计。
- **待环境验证**：代码或本地构建已有记录，但真实数据库、账号、企微数据、微信开发者工具或 E2E 尚未验证。
- **后续范围**：原始需求明确排除，本文只保留边界，不视为当前交付内容。

原始 feature-docs 目录仍保留为变更历史和详细契约来源；本目录是面向当前评审的汇总基线。
