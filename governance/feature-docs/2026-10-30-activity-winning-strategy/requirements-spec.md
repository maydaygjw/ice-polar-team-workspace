# 活动模板中奖策略需求规格

## Scope

活动模板支持四种画像中奖策略，当前期次沿用生成时的策略配置。策略应用于 `drawMode=1` 的统一开奖和 `drawMode=2` 的即时抽奖；游戏模式保持现有规则。由 backend 实施，admin 提供模板配置；本期不修改小程序、H5 或用户端 API 请求结构。

## Use Cases

- 活动运营人员创建或编辑抽奖模式模板时选择公平开奖、偏向新用户、偏向流失/低频用户或留存唤醒分层策略。
- 已生成期次的用户即时抽奖时，系统读取期次策略和会员最新用户画像阶段，计算该阶段对应的中奖概率。
- 统一开奖时，系统读取期次策略和报名会员最新画像阶段，按报名抽奖机会加权抽取中奖者。
- 画像记录或阶段缺失时，用户按公平策略抽奖。

## Business Rules

- 策略编码：`FAIR`、`PREFER_NEW_USERS`、`PREFER_AT_RISK_AND_LOW_FREQUENCY`。
- `FAIR` 下所有画像阶段和无画像用户的中奖权重均为 1.0。
- `PREFER_NEW_USERS` 下 `new` 阶段权重为 2.0，其余阶段及无画像用户权重为 1.0。
- `PREFER_AT_RISK_AND_LOW_FREQUENCY` 下 `low_frequency`、`at_risk`、`churned` 阶段权重为 2.0，其余阶段及无画像用户权重为 1.0。
- `RETENTION_REACTIVATION_TIERS` 下优先级及权重依次为 `at_risk=3.0`、`low_frequency=2.0`、`new=1.2`、`mid_frequency=0.7`、`high_frequency=0.3`；`churned`、无画像和未知阶段权重为 `1.0`。
- 权重用于调整“中奖”相对“未中奖”的赔率；对用户的所有奖品概率使用同一画像权重，并保持奖品间相对概率不变。设原奖品概率合计为 P（百分数）、权重为 W，则新总中奖率为 `P×W / (100−P + P×W)`；各奖品按原概率占比分配新总中奖率。P=0 时仍为 0，P=100 时仍为 100。策略不承诺中奖。
- 统一开奖按报名者的每一张抽奖机会生成加权抽样项，目标阶段每项权重为 2.0、其他项为 1.0；不放回抽取并保持现有奖品顺序、数量及 `singleWinner` 规则。未中奖用户仍参与公平抽样。
- 奖品库存耗尽、单人中奖限制、抽奖次数、请求幂等和奖品兑奖沿用现有行为；抽奖未中奖概率仍包含库存耗尽奖品所占概率。
- 以会员 ID 批量读取当前租户画像阶段；缺失或未知阶段按权重 1.0。不得由客户端提交画像阶段或中奖权重。
- 期次生成时将策略复制到期次快照，模板后续修改不影响已生成期次。历史模板和期次默认 `FAIR`，兼容原有抽样行为。
- 策略仅对统一开奖和即时抽奖模式生效；游戏模式不使用策略并维持旧行为。

## Frontend Requirements

- 仅在活动模式为“开奖”或“抽奖”时展示策略选择，位于活动奖品/中奖规则配置区域。
- 提供四个选项及其目标阶段/权重说明；默认选择公平策略。
- 偏向策略旁说明画像缺失时按公平处理、策略权重仅调整相对赔率且不保证中奖；分层策略展示各阶段权重。
- 编辑旧模板时没有策略字段则显示公平策略；复制模板复制策略。

## Edge Cases

- 画像阶段为空、阶段编码未知、会员没有画像记录：使用 1.0 权重。
- 概率合计为 0 或 100、单个奖品概率为 0：计算结果不产生 NaN、除零或负概率。
- 生成期次后修改模板策略：旧期次仍使用快照策略，新期次使用最新策略。
- 同一用户重复请求命中现有幂等记录，返回首次结果，不因画像后续变化重新抽取。
- 新策略不改变奖品库存校验顺序、抽奖次数消耗和单人中奖约束。

## Acceptance Criteria

1. 模板创建、编辑、详情和复制能够保存并回显四种策略；旧模板无字段时显示公平。
2. 生成期次时策略进入快照，模板更新不会改变已生成期次策略。
3. 公平策略与当前抽奖结果分布算法一致。
4. 偏向新用户策略只提高 `new` 阶段的中奖赔率；偏向流失/低频策略只提高 `low_frequency`、`at_risk`、`churned` 阶段的中奖赔率；其他和无画像阶段使用公平赔率。
5. 留存唤醒分层策略按配置的五级权重排序应用阶段，其余阶段按公平权重。
6. 调整后概率总和不超过 100%，奖品之间相对概率保持一致，且未中奖概率正确。
7. 抽奖请求仍服务端获取画像、保持请求幂等和租户隔离；客户端不能指定阶段或权重。
8. 游戏模式的行为不变，公平策略下统一开奖与即时抽奖都与现有行为兼容。

## Assumptions

- 当前活动画像阶段 `new`、`low_frequency`、`at_risk`、`churned` 是本功能唯一分群依据；不直接使用标签、注册时间或订单字段二次计算。
- “偏向”表示相对机会提高，不提供目标用户中奖名额保证。
- 两个既有偏向策略继续使用 2.0 权重；新增分层策略按单独的五级权重表执行。“偏向流失中和低频用户”按 `low_frequency`、`at_risk` 和 `churned` 三阶段实现。
- 留存唤醒策略的层级权重是更明显的试运行差异，不代表已验证 ROI；`churned` 先按公平处理，因为用户给出的优先级序列未指定已流失阶段。

## ROI 评估与建议

- 这套优先级更贴近留存与唤醒目标：高频用户自然复购可能性高，明显降低其中奖权重可减少补贴流向原本就会复购的人；流失中和低频用户获得更高的激励机会。
- 分层策略将 `new` 放在流失中和低频之后，更贴近留存/唤醒优先级；新用户仍高于中频和高频，但它的增量价值取决于后续复购毛利能否覆盖奖品成本。用户阶段只描述历史行为，不等同于用户对奖品的增量响应。
- 上线后保留随机公平对照组，按阶段比较活动后 30 天增量复购率、增量毛利减奖品成本、唤醒成本；待数据稳定后再调权重。不要只用中奖率或报名率判断 ROI。
