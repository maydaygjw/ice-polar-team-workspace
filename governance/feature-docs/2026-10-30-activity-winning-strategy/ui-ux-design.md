# 活动模板中奖策略 UI 设计

## 布局与交互

- 在模板编辑器的“活动奖品”步骤中，紧邻奖品概率/中奖规则展示“中奖策略”表单项。
- 仅 draw mode 为开奖或抽奖时显示；切换到游戏模式时隐藏并保存为 `FAIR`。
- 使用带说明的单选项，保留现有纵向表单布局和 Element Plus 表单校验/交互。
- 策略文案：
  - **公平开奖**：所有用户按相同中奖权重参与。
  - **偏向新用户**：画像阶段为“新用户”的中奖赔率权重为 2 倍。
  - **偏向流失和低频用户**：画像阶段为“流失中”“已流失”或“低频用户”的中奖赔率权重为 2 倍。
- **留存与唤醒分层**：显示流失中 3.0、低频 2.0、新用户 1.2、中频 0.7、高频 0.3；已流失和未知阶段按公平权重 1.0。
- 表单帮助说明：画像缺失时按公平权重处理；权重提升机会，不保证中奖。
- 新建和旧模板默认公平。编辑、查看详情和复制都回显选择值。

## 可用性

- 使用可见标签和帮助文本表达每项含义，不仅依靠颜色区分策略。
- 单选项可通过键盘选择，当前选择态应清晰可见。
- 复用现有 Element Plus 表单和项目颜色变量，不增加新控件依赖或装饰动效。

## UI 指引来源

采用 UI/UX Pro Max 的 Vue 表单规范结果：使用内建 `v-model` 修饰符（仅在字段类型转换需要时），表单字段须有明确标签和说明。第一次定向检索未命中，改用 `forms --stack vue` 后得到表单组件和 `v-model` 建议；本次为现有管理表单增量，不引入 VeeValidate/FormKit。
