# 技术设计：外卖订单应收应付状态与手工生成

- 订单表增加 `receivable_payable_generated` 冗余标记，订单分页直接转换该字段，不查询应收应付表。
- pay 计费成功后通过 `OrderApi` 按租户和订单号置位；计费失败时清除标记。迁移按租户/订单号回填历史 `SUCCESS` / `SUCCESS_WITH_DIFFERENCE` 记录。
- order 手工入口按当前租户读取订单并检查 `takeout`、已支付、未退款、状态 2/3。已标记成功的订单直接返回成功；其他情况调用 `BillingSettlementApi.calculate`，然后重新读取订单标记作为结果。
- 管理端在外卖订单表格展示状态，并只对状态 2/3 且未生成的外卖订单显示菜单操作。执行前二次确认，完成后刷新列表。
- 失败重试和计费明细重建沿用 pay 模块已有逻辑。
