# 活动奖品与开奖规则管理 UI/UX 设计

## 页面入口

“营销 → 活动管理”下增加“奖品管理”和“开奖规则”两个入口。奖品管理是可编辑页面；开奖规则是只读说明页面。

## 奖品管理

- 筛选：奖品名称、开奖规则、启用状态。
- 列表：图片、奖品名称、开奖规则、参数摘要、规则说明、模板引用数、状态、更新时间、操作。
- 操作：编辑、启用/停用、删除。模板引用数大于 0 时删除按钮仍显示，但点击后展示后端阻断原因。
- 新增/编辑弹窗字段：奖品名称、图片、领取说明、开奖规则、开奖规则参数、启用状态、排序。
- 选择开奖规则后，根据规则元数据渲染通用 Key/Value 编辑器；参数行支持新增、删除、编辑 key/value，并显示类型、必填、范围提示。
- 编辑已被模板使用的奖品时，开奖规则选择器置灰；规则参数允许修改并提示“仅影响后续新建期次”。
- JSON 参数不以原始 JSON 文本作为主要编辑方式；复杂值通过统一 value 输入，保存失败时定位到具体 key。

## 开奖规则

- 表格展示：开奖规则名称、标识、说明、版本、参数说明、启用状态。
- 页面无新增、编辑、删除按钮；禁用规则显示为不可选择。
- 规则不可用但仍被奖品引用时，展示警告和受影响奖品数量。

## 活动模板奖品配置

- 原内嵌奖品编辑区改为“从奖品库添加”选择器。
- 选择器展示图片、名称、开奖规则、启用状态；已停用且已关联的奖品允许回显但禁止新增。
- 模板奖品行只编辑数量和排序，并只读展示奖品名称、图片、领取说明、开奖规则和参数摘要。
- 不展示可编辑的规则参数输入，避免用户误以为模板可以覆盖奖品配置。
- 保存前校验重复奖品、数量和排序；后端返回规则不可用或奖品被删除时，保留已输入数量并标记对应行。
- 页面提示：“开奖规则和参数在奖品管理中维护；修改只影响后续新建期次。”

## 开奖结果展示

- 中奖记录表展示开奖规则名称和参数摘要，明确标注“本期仅记录开奖规则，暂不发放积分/余额”。
- 本期不展示奖励状态、奖励失败原因和重试按钮。

## 状态与反馈

- 保存奖品、模板和删除操作使用统一成功/失败消息。
- 参数错误使用表单字段错误，不仅展示通用错误。
- 删除被引用奖品、停用仍被引用奖品、规则不可用等场景必须显示业务原因。
- 列表加载、空状态、权限不足沿用活动管理现有组件和文案风格。
