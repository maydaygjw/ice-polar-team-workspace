# 美团镜像库店铺导入

## Scope

### In

- 店铺导入页面增加“美团镜像库”导入来源。
- 镜像库模式不上传 Excel、不选择上传模板，必须填写 `poi_id`。
- 按指定 `poi_id` 导入商品、SKU 规格和商品选项。
- 复用现有店铺创建、导入预览、草稿、确认、明细和批次记录流程。
- 仅读取镜像库的商品、分类和属性数据。

### Out

- 不导入评论、评论汇总、接口采集流或活动数据。
- 不修改镜像库数据。
- 不导入已有店铺；每次确认仍创建一个新店铺。
- 不在管理端配置第三方数据库账号。

### Deferred

- 不在本期实现多次镜像数据同步或增量更新已有商品。
- 不在本期导入美团门店基础资料；店铺名称、图片、商圈等仍按现有新店流程填写。

## Use Cases

1. 租户管理员选择“美团镜像库”，填写 `poi_id`、商圈和新店铺信息，查看商品/规格/选项预览并确认导入。
2. 租户管理员在预览中调整商品售价、分类和库存，保存草稿后继续确认。
3. 租户管理员查看批次明细，区分商品、SKU、选项解析错误，并删除导入记录而不删除已创建业务数据。

## Business Rules

- 商品按当前租户、`poi_id`、`spu_id` 聚合；每个 `foods` 行按 `sku_id` 形成一个 SKU。
- `food_attrs.sku_id = ''` 的记录形成商品级选项组；同一 `attr_id` 后续即使带 `sku_id` 被复制到其他 SKU，仍按商品选项处理。
- 未出现过空 `sku_id` 的属性定义，才按 `sku_id` 关联到 SKU 规格组合；同一 SKU 的属性值必须可唯一确定规格组合。
- SKU 价格、原价、库存、图片和规格文本以 `foods` 为准；选项加价和选择规则以 `food_attrs` 为准。
- 缺少分类的商品进入预览异常或“未分类”警告，不能静默丢弃。
- 只读取 `foods`、`food_attrs`、`food_categories`；评论和采集流不参与导入。
- 镜像库连接失败、`poi_id` 不存在、SKU 属性不完整或数据不一致时，预览返回明确错误/警告，不创建店铺。
- 镜像库账号由服务端环境配置提供，管理端只能提交 `poi_id`。

## Frontend Requirements

- 增加导入来源选择；选择“美团镜像库”后隐藏模板、下载模板和文件上传控件。
- 镜像库模式展示 `poi_id` 输入框并做必填、长度和空白校验。
- 保留商圈、店铺名称、店铺图片、管理员和库存等现有店铺参数。
- 预览显示商品、SKU、规格组、选项组数量及分类缺失/属性异常提示。
- 批次列表区分文件导入和镜像库导入，并显示 `poi_id`。

## Edge Cases

- `poi_id` 不存在或没有商品数据。
- 同一 `spu_id` 下出现重复 `sku_id`、重复属性值或缺少 SKU 属性关联。
- SKU 规格属性与 `foods.spec_text` 不一致、SKU 价格与属性价格不一致。
- 商品或 SKU 缺少分类、名称、价格、库存或图片。
- 同一商品存在商品级选项和 SKU 级规格同名属性组。
- 镜像库查询超时、连接中断、返回数据超过单批次上限。
- 重复点击预览/确认，或同一草稿被并发确认。

## Acceptance Criteria

- 选择镜像库并填写有效 `poi_id` 后，无需上传文件即可生成导入预览。
- 以 `spu_id=15402787971` 为例，3 个 SKU 均能关联到对应的“大份/小份/标准份”规格，价格分别保持一致。
- 商品级“加量”“口味”“温馨提示”等选项组及选项价格、必选/多选规则可预览并写入目标店铺。
- 预览和确认过程中不读取、不写入评论数据。
- 仅创建一个新店铺，商品、SKU、分类和选项均归属于该店铺及当前租户。
- 无效 `poi_id`、缺失 SKU 关系、超时和数据不一致不会创建店铺，并在批次/接口中返回可理解的错误。
- 文件导入现有流程保持兼容。

## Assumptions

- 镜像库连接地址、账号和密码由部署环境提供，使用只读账号；本地探索账号不进入代码或文档。
- `food_attrs.selected=1` 表示默认选项，不用于判断 SKU 与属性的类型；属性类型依据同一门店快照中该 `attr_id` 是否出现过空 `sku_id` 的记录推断。
- 商品分类缺失时默认保留为预览警告，并允许管理员在预览阶段补齐；实现可按现有校验策略拒绝确认。
