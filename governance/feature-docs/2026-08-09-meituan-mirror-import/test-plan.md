# 美团镜像库导入 E2E 计划

## 场景

1. 打开店铺导入，切换来源为“美团镜像库”。
2. 确认模板下载、模板选择和文件上传控件隐藏，仅显示 POI ID。
3. 不填写 POI ID 点击预览，页面阻止提交。
4. 填写测试 POI ID，提交预览，确认批次来源和 POI 展示正确。
5. 检查多 SKU 商品的 SKU 行、商品选项组和异常警告。
6. 确认并检查新店铺商品规格与选项；确认评论未被导入。

## 环境与数据

- 后端注入镜像库连接环境变量，不在测试脚本中写入凭据。
- 使用 `poi_id=15402787971` 作为结构回归数据；真实确认需使用部署环境配置的可导入 POI。
- 需要预先执行镜像库批次迁移 SQL。
