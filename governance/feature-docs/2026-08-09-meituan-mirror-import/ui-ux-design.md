# 美团镜像库店铺导入 UI/UX

- 在导入参数区增加“导入来源”：美团外卖文件、美团镜像库。
- 文件模式保持现有模板选择、模板下载和文件上传行为。
- 镜像库模式隐藏文件相关控件，展示 `poi_id` 输入框，提示“请输入美团镜像库中的门店 ID”。
- 镜像库模式的店铺名称不从数据库自动提取，继续由管理员填写；商圈、图片和管理员沿用现有表单。
- 预览顶部增加数据来源和 `poi_id`，并显示商品数、SKU 数、规格组数、选项组数。
- 分类缺失、SKU 属性不一致和源数据不可用使用警告/错误标签，不在确认前静默修正。
- 导入批次表增加“来源”列；镜像库批次文件列显示“—”，来源列显示“美团镜像库 / poi_id”。
