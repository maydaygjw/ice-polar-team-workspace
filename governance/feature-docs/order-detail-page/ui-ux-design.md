## 界面风格优化方案: MiniApp 订单详情页

### 现状分析
- 当前小程序已有订单列表页，但缺少详情承接页
- 订单信息、支付动作、退款动作都集中在列表卡片上，信息层次偏挤
- 用户无法查看完整金额明细和订单备注

### 优化方案

#### 配色方案
- 主色: 沿用品牌蓝渐变
- 背景色: 浅灰蓝背景
- 卡片色: 白色
- 文字色: 深色正文 + 次级灰文字
- 状态色:
  - 处理中: 蓝色
  - 已完成: 绿色
  - 退款中/已退款: 橙色

#### 字体规范
- 页面标题: `36rpx`, `700`
- 状态标题: `32rpx`, `600`
- 模块标题: `28rpx`, `600`
- 正文: `28rpx`, `400`
- 辅助文字: `24rpx`, `400`

#### 组件规范
- 状态卡：顶部大卡片，展示状态、金额、主操作
- 信息卡：白底卡片，圆角与 `orders` 页一致
- 金额行：左右对齐，重点金额使用更强字重
- 底部操作栏：固定底部，主次按钮并列或单按钮展示

#### 交互优化
- 订单列表整卡可点击进入详情
- 详情页复制订单号保留快捷反馈
- 支付操作按钮在未支付状态下固定展示
- 退款入口仅在满足条件时显示
- 接口失败时展示错误文案与返回路径

### 影响范围
- `miniapp/pages/orders/orders.wxml`
- `miniapp/pages/orders/orders.wxss`
- `miniapp/pages/orders/orders.js`
- `miniapp/pages/order-detail/*`
- `miniapp/app.json`
