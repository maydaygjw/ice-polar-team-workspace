# 商圈排名竞价 — UI/UX Design（本期：admin）

范围仅本期 admin 侧：竞价活动配置。竞拍监控/入围结果、miniapp 属延后期，本文 `N/A`。
栈：Vue3 + Element Plus + TS，沿用 admin 现有 coupon/card 配置页范式。

## 导航与授权

- 顶级菜单 `商圈竞价` → 子菜单 `竞价活动`（路由 `/bidrank/auction`）。
- 菜单/按钮经租户套餐 `menu_ids` 授权；未授权租户整棵菜单不渲染，直达 URL 被后端 `@PreAuthorize` 拦截。
- 按钮权限：`bidrank:auction:create/update/delete/query`。

```

─────────────────────────────────────────────────────────────
活动主题 | 适用商圈 | 周期 | 生效日期 | 下次生效日期 | 启用 | 操作
xxxxx   | 南通大学主校区 | 每周 | 每周一 | 2026-07-28 | ●启用 | 编辑 停用 删除
─────────────────────────────────────────────────────────────
                                                     分页 ◁ 1 2 3 ▷
```

- 商圈下拉受当前用户部门/数据权限约束。
- `是否启用` 为开关列，即时切换 `enabled`；无草稿/发布生命周期（活动是周期模板）。
- `下次生效日期` 由周期规则派生、只读。
- 行操作：编辑 / 启停切换 / 删除（均二次确认）。

### 字段校验（前端 + 后端双校验）

| 字段 | 规则 |
|------|------|
| 活动主题 / 适用商圈 | 必填 |
| 活动周期 | 每周/每月，必选 |
| 生效日期 | 必填（周期锚点） |
| 提前天数 | 整数 ≥ 0 |
| 启动时间 | HH:mm，必填 |
| 活动时长 / 支付时间 | 整数分钟 > 0 |
| 预付比例 | 整数 1–100，默认 20 |
| 竞拍内容说明 / 规则 | 富文本，可空（建议填规则） |
| 排名起始/终止位次 | 整数，`起始 ≥ 1` 且 `起始 ≤ 终止` |
| 可拍卖数量 | `1 ≤ 数量 ≤ 终止 − 起始 + 1` |
| 起拍金额 / 最小加价 | > 0，两位小数；**UI 用元、提交转分（bigint）** |
| 档位 | 至少 1 行 |

> 允许档位范围重叠（业务规则）；不做跨档位互斥校验。
> 老系统「显示天数比例」列已移除，改为范围内随机曝光；「最小加价」为本期新增，老系统无。

## 交互与状态

- **提交**：保存活动模板并校验完整性；无草稿/发布生命周期，可反复编辑。
- **启用/停用**：列表开关即时切换 `enabled`；停用后不再派生新周期（不影响已生效周期，退款/下线属延后期）。
- **删除**：二次确认。

## 空态与权限态

- 无数据：空表 + `暂无竞价活动，点击新建`。
- 无 `create` 权限：隐藏新建按钮；无 `query` 权限：不进入路由。
