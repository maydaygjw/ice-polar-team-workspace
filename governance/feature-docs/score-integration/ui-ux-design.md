## UI/UX Design: 小程序积分中心

### 页面清单

| 页面 | 路径 | 说明 |
|------|------|------|
| 积分中心 | `pages/score/center` | 积分余额卡片 + 签到区域 + 功能入口 |
| 积分明细 | `pages/score/bill` | 积分收支列表 |

### 个人中心修改

在现有个人中心页面（`pages/user/index` 或类似）增加积分余额展示：
- 位置：用户信息区域下方
- 展示：`积分: 128` 或带图标形式
- 点击：跳转积分中心

### 积分中心页面布局

```
┌─────────────────────────┐
│  积分余额               │  ← 大字号突出显示
│  ┌─────────────────┐    │
│  │   1,280 积分     │    │  ← 主视觉区域，品牌色背景
│  └─────────────────┘    │
│                         │
│  ┌─────────────────┐    │
│  │  今日签到 +5积分 │    │  ← 签到按钮（已签到变灰色）
│  │  已连续签到 3 天 │    │
│  └─────────────────┘    │
│                         │
│  ┌─────────────────┐    │
│  │  积分明细   >   │    │  ← 入口列表
│  │  积分规则   >   │    │
│  └─────────────────┘    │
└─────────────────────────┘
```

### 签到按钮状态

- **未签到**：品牌色背景，文字"立即签到 +X积分"
- **已签到**：灰色背景，文字"今日已签到"

### 积分明细页面

- 列表形式，每条记录显示：
  - 左侧：标题（如"每日签到"、"消费返积分"）
  - 右侧：+X 或 -X 积分（绿色表示获得，红色表示消耗）
  - 下方：时间

### 交互规范

- 签到成功：toast 提示"签到成功，获得 X 积分"
- 连续签到达成：toast 提示"恭喜！连续签到 N 天，额外获得 X 积分"
- 下拉刷新：支持刷新积分余额和签到状态
