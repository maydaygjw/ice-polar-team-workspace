## Feature: 商品选项加价模式

来源：`governance/BACKLOG/BACKLOG-004-product-option-pricing.md`

### Scope

**In-scope**

- 商品新增「选项加价」能力：基础规格定价 + 选项加价，不再依赖笛卡尔积穷举 SKU。
- 门店选项库（两层主从，shop 维度共享）：
  - 门店选项分组（如「奶茶底」「加料」「甜度」）：必选/可选、单选/多选、min/max、排序。
  - 门店选项（如「鲜奶 +1」「珍珠 +1」「全糖 +0」）：名称、价格、库存、状态、排序。
  - 分组与选项**多对多**：选项为独立门店资源，可跨组复用；价格/库存/状态单一事实源。
- 商品引用门店分组：商品开启 `has_options` 后勾选引用哪些门店分组，选项随门店库实时生效。
- 商品详情接口按 `spec_type` + `has_options` 返回规格 + 引用的选项分组（实时带选项价/库存/状态）。
- 下单价格计算：规格价 + Σ 选中选项价格（选中即加一次，无份数）。
- 库存扣减：规格 SKU 库存 + 选中选项库存（各一次）。
- 订单/购物车记录所选规格、选项分组的快照及加价合计。
- admin 后台维护门店选项库（分组+选项+跨组指派）与商品引用分组。

**Out-of-scope**

- 小程序点单页改造（本期不交付，后续迭代；本期由后端接口保证可对接）。
- 不改动现有单规格（`spec_type=0`）与多规格笛卡尔积（`spec_type=1`）的既有逻辑。
- 不改变已支付历史订单的金额、佣金、快照（历史数据不可变）。
- 不引入新的支付方式或结算/分账规则变化。
- 选项跨门店共享、平台级选项库（本期仅门店维度）。
- 选项不按份数多选（无「2 份珍珠」）；如需多份后续再议。
- 选项级独立打包费（打包费仅规格层 `pack_fee`）。

### Use Cases

- 门店运营：维护门店选项库——建分组（奶茶底/加料/甜度）、建选项（鲜奶/燕麦奶/珍珠），把选项指派到一个或多个分组；统一改价/补库存，引用商品自动生效。
- 门店运营：为奶茶商品开启选项加价并勾选引用「奶茶底」「加料」分组。
- 顾客：在小程序点单页选杯型（规格）、奶茶底、加料，实时看到加价后的价格。
- 系统：下单按选项计算价格、扣减规格与选项库存、写入订单选项快照。
- 管理员：在订单详情查看所选规格/选项快照。

### Business Rules

- 价格：商品单价 = 选中规格 price + Σ 选中选项 price（每个选中选项加一次，无份数乘法）。
- 选项是否加价由选项自身 `price` 决定：`price=0` 即纯选择维度（原"属性"），`price>0` 即加价项（原"小料"）。属性与小料统一为一套模型。
- 分组支持单选/多选；**组级可配是否多选，默认单选（`multiple=0`）**。单选组服务端强制 ≤1 选择。
- 必选组必须满足 `min_select`；多选组受 `max_select` 限制。
- 选项可跨组复用；同一选项在多个分组/多个商品间共享同一份价格与库存。
- 选项在门店维度统一维护；改价/改名后，门店内所有引用（分组/商品）同步生效（订单快照仅作用于下单时点）。
- 库存：只维护规格 SKU 库存与选项库存（选中各扣一次）。
- 历史订单金额、佣金、快照不可变。

### Frontend Requirements

- admin：
  - 门店选项库管理：分组 CRUD + 选项 CRUD + 选项指派到分组（多对多）。
  - 商品编辑：开启 `has_options` 后勾选引用哪些门店分组（展示组内选项实时价/库存）。
- 小程序点单页：本期不改造，仅由后端接口预留对接能力（返回 `specs` + 选项分组、计价与扣库存规则）。

### Edge Cases

- 必选组未选或低于 `min_select` 时禁止下单并提示。
- 单选组提交多个选择时服务端拒绝。
- 选项库存不足时置灰/提示；规格 SKU 缺货整商品不可下单（按规格库存为准）。
- 选项被门店停用/从分组移除：引用商品下单时不可用；历史订单快照不受影响。
- 选项被多个分组引用时删除：需先从所有分组移除。
- 购物车中选项/规格后续被改价：下单时按实时价重新计算，快照仅记录所选内容。

### Acceptance Criteria

- [ ] 商品新增 `has_options`，不影响现有单/多规格逻辑。
- [ ] 新增门店选项分组表与门店选项表，选项支持名称/价格/库存/状态/排序。
- [ ] 分组与选项多对多关联，选项可跨组复用；价格/库存单一事实源。
- [ ] 分组支持单选/多选（默认单选）、必选/可选、min/max、默认选项、排序。
- [ ] 商品可勾选引用门店分组；商品详情按 `spec_type` + `has_options` 返回规格 + 选项分组（实时价/库存/状态）。
- [ ] 下单价格 = 规格价 + Σ 选中选项价格（无份数）。
- [ ] 库存扣减 = 规格 SKU 库存 + 选中选项库存（各一次）。
- [ ] 订单/购物车记录所选规格、选项分组快照及加价合计。
- [ ] admin 支持维护门店选项库（分组+选项+跨组指派）与商品引用分组。
- [ ] 选项门店维度统一维护，修改后引用方同步生效。

### Assumptions

- 选项加价模式与笛卡尔积多规格互斥：同一商品同一时刻只用一种定价模式（`has_options` 与 `is_combo` 互斥）。
- 选项库为门店维度，暂不做平台级共享。
- 选项不按份数；一个选项选中即加一次价、扣一次库存。

### Open Questions
