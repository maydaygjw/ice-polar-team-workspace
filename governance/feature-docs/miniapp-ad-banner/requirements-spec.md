# 需求规格说明书：小程序首页广告轮播

## 功能概述
在小程序首页（`pages/scan/scan`）接入广告轮播图，展示在品牌头部下方、主内容区上方。

## In-Scope
- 首页新增轮播广告区域，调用已有 `/app-api/ad/list` API
- 使用微信小程序原生 `<swiper>` 组件实现轮播
- 轮播指示器（indicator-dots）
- 自动轮播（autoplay）
- 广告图点击支持（预留，当前 API 无跳转链接）
- 无广告时的降级处理（隐藏轮播区域）

## Out-Scope
- 后端 API 开发（已有 `AppAdController`）
- Admin 后台广告管理页面（已有）
- 数据库表变更（已有 `yshop_shop_ads` 表）
- 广告点击跳转链接（当前 API 未返回 url 字段，后续可扩展）

## 验收标准
- [ ] 首页加载时自动请求广告列表
- [ ] 广告图以轮播方式展示，支持自动播放和手动滑动
- [ ] 轮播区域有圆角、阴影等视觉样式，与现有设计系统一致
- [ ] 无广告时不显示轮播区域，不破坏页面布局
- [ ] 使用 `rpx` 单位，适配不同屏幕尺寸
