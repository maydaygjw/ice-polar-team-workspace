# 店铺导入

## Scope

### In

- 管理端在“门店中心”目录下提供“店铺导入”菜单。
- 首期支持“美团外卖用户端”导出文件。
- 支持在后台上传多个导入模板文件；模板文件保存到主 OSS，下载时使用已保存文件，不动态生成 Excel。
- 上传文件时选择商圈，并使用商圈店铺模板补齐新店铺默认信息。
- 每次导入新建一个店铺，不支持导入已有店铺。
- 支持导入预览、错误提示、确认导入、导入记录和导入明细。
- 导入记录处于草稿状态时，管理员可重新打开已保存的预览，继续编辑有效行售价并确认导入。
- 导入记录状态简化为“草稿”和“已导入”，明细保留逐行导入结果。
- 任意状态的导入记录均可删除，但只删除 import 批次和明细，不删除店铺、商品或分类。

### Out

- 不修改已有店铺及其商品。
- 不导入美团活动价、到手价、优惠券和统计汇总数据。
- 将美团商品月售导入为新商品的初始销量；不导入其他统计汇总数据。
- 不在本期实现任意 Excel 字段自动映射；上传模板必须绑定已有解析器。美团以外的平台模板需先增加对应解析器，再上传模板文件。

## Use Cases

1. 租户管理员选择模板、上传文件和商圈，填写新店铺必要信息，查看预览后确认导入；店铺公告和商品数据选项不在导入流程中设置。
2. 租户管理员在导入记录中查询批次状态、成功/失败数量和逐行错误。
3. 租户管理员删除导入记录，确认只清理 import 数据，不影响店铺及商品。
4. 具备模板上传权限的管理员在“模板管理”中登记模板编码、名称、版本、解析器和 Excel 文件，并下载已上传模板。

## Business Rules

- 商圈必须存在且启用；店铺默认地址、地图地址、经纬度、营业时间、抽成、配送和省市区来自所选商圈模板。
- 新建店铺必须补充店铺名称、管理员和店铺图片等系统创建所需信息；店铺公告和手机号不作为导入参数。
- 美团文件优先读取“商品详情-多规格多行显示”，兼容“商品详情”；统计和排行 Sheet 不参与导入。
- 商品以“外部商品 ID + 一级分类”识别；同一分类下的规格作为 SKU 维度去重，重复记录在预览中提示，默认以后出现的记录覆盖先出现的记录。
- 美团用户端模板只取一级分类，忽略二级分类；规格以 `#` 分隔时导入为同一商品的多个 SKU。
- 分类按一级分类创建或复用，归属于新建店铺；美团用户端模板忽略二级分类。
- 导入商品默认下架，商品初始销量取源文件商品月售；多规格商品使用商品分组内首个非空月售值。
- 预览阶段发现错误时，错误行不会写入商品；确认后有效行继续导入，并在批次中标记为部分成功，管理员可从明细查看错误。
- 删除只物理清理当前租户的 import 批次和明细，不调用店铺、商品或分类删除能力。
- 模板编码在当前租户内唯一；同一解析器可以绑定多个不同模板编码和版本。
- 模板文件仅接受 `.xlsx`/`.xls`，单文件不超过 10MB；文件上传后通过 infra 文件 API 保存到主 OSS。
- 模板下载只返回已登记文件的 OSS 访问地址；未上传文件的内置解析器不提供下载文件。

## Frontend Requirements

- 使用步骤式页面：选择参数并上传、预览确认、结果记录。
- 页面提供“模板管理”入口，展示模板编码、版本、文件名和下载操作；上传表单包含模板元数据、解析器和 Excel 文件。
- 参数页只展示“新建店铺”模式，不展示已有店铺选择项。
- 预览表展示源行号、一级分类、商品、商品月售、规格、售价、库存、图片和校验结果；有效行的售价可在表格中编辑，并在确认时生效。
- 记录页支持按批次号、模板、店铺、商圈、状态和时间查询。
- 记录详情支持查看成功、跳过和失败明细，并可下载错误明细。
- 删除操作必须明确提示只删除导入记录、不影响店铺和商品，并二次确认。

## Edge Cases

- 文件缺少目标 Sheet、表头不匹配、文件超过大小限制或超过单批次行数上限。
- 模板编码重复、解析器不存在、模板文件格式不支持或 OSS 上传失败。
- 外部商品 ID 为空、价格非法、库存为负、图片地址非法或规格为空。
- 同一商品跨分类重复，或同一商品的规格行价格/库存不一致。
- 商圈没有完整模板默认值；必填店铺字段仍由页面补充。
- 导入中断、重复确认、删除进行中再次删除。
- 店铺创建成功但商品写入失败时，批次必须可查询，且删除批次不能影响已创建的店铺或商品。

## Acceptance Criteria

- 上传给定美团文件后，系统能识别商品详情 Sheet，并生成可审阅的预览数据。
- 上传模板后，模板元数据和 OSS 文件地址可查询；再次下载得到同一份静态文件，不触发 Excel 动态生成。
- 选择商圈后，预览/确认信息中能看到商圈模板提供的店铺默认值。
- 确认后只新建一个店铺；导入明细记录目标店铺、商品和分类 ID，商品、分类、SKU 均归属于该店铺。
- 重复商品、错误行和导入统计在记录中可追溯。
- 导入批次可查询明细；删除批次不会影响其他店铺或商品。
- 任意状态的导入记录均可删除，且删除后店铺、商品和分类仍可在各自业务页面管理。
- 后端编译、管理端类型检查和构建通过。

## Assumptions

- 首期店铺名称由用户填写，文件名仅作为默认建议值。
- 商品图片首期保存源图片地址，不做图片下载和转存。
- 商品分类只处理一级分类；美团用户端模板忽略二级分类；美团三级类目为空或未分类时忽略。
- 首次部署需在模板管理中上传 `美团外卖商品导入模板.xlsx`，编码建议为 `meituan-user`，解析器选择 `meituan-user`。
