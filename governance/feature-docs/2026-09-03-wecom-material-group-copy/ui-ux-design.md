# 企业微信素材组复制 UI/UX 增量

## 素材组列表

- 在每个素材组的操作区增加“复制”按钮。
- 按钮使用素材组创建权限控制；点击时保留当前企业微信配置和搜索条件。
- 复制进行中仅禁用当前组的复制按钮并显示加载状态，避免重复提交。
- 成功提示“素材组复制成功”，刷新素材组列表；新组可自动选中并加载其素材。
- 失败时保留列表和当前选中组，直接展示后端可读错误。

## 交互边界

- 不弹出名称编辑表单，名称由服务端按既定规则生成。
- 不展示或修改企业微信图片 URL；副本沿用源素材数据。
- 复制不改变源组的选中状态，除非复制成功后页面自动切换到新组；两者均需在实现中保持数据一致。
