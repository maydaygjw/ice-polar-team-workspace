# UI/UX 设计 — 订单结算管理

## 概述

管理后台「订单中心」新增「订单结算管理」页面。列表以订单维度展示结算状态，点击弹窗查看结算明细（含分账明细 + 收款人银行卡信息）。

## 页面

路由：`/order/settlement`（后端动态菜单注册）

### 1. 结算列表

**筛选区**

- 订单号（el-input，回车触发搜索）
- 店铺（el-select，远程搜索）
- 订单状态（el-select）：未支付 / 待出单 / 待收货 / 已收货 / 退款单 / 已删除
- 结算状态（el-select）：未结算 / 待分账 / 分账中 / 已结算 / 分账失败
- 支付时间（el-date-picker，daterange）
- 搜索 / 重置按钮

**表格列**

| 列 | 说明 |
|----|------|
| 订单号 | 可点击跳转订单详情 |
| 店铺名称 | — |
| 订单金额 | ￥格式化 |
| 支付方式 | Tag 展示（Adapay / 微信 / 支付宝 / 余额 / 现金） |
| 支付时间 | YYYY-MM-DD HH:mm:ss |
| 订单状态 | Tag，颜色编码 |
| 结算状态 | Tag，颜色编码（见下方） |
| 分账时间 | YYYY-MM-DD HH:mm:ss，未结算显示 `--` |
| 操作 | 「查看明细」按钮（仅已结算/待分账/分账中/分账失败可用） |

**结算状态颜色**

| 状态 | Tag 类型 |
|------|----------|
| 未结算 | `info` |
| 待分账 | `warning` |
| 分账中 | ``（primary） |
| 已结算 | `success` |
| 分账失败 | `danger` |

### 2. 结算明细弹窗

`el-dialog`，标题「结算明细 - {orderId}」，宽度 700px。

**基本信息区**（el-descriptions，2 列）

| 字段 | 说明 |
|------|------|
| Adapay 支付 ID | — |
| Adapay 确认 ID | 分账成功后才有，否则 `--` |
| 分账时间 | — |
| 计算方式 | 计费规则 / 佣金比例回退 |
| 回退状态 | 是/否（`fallback_revenue=1` 时显示「已回退至虚拟余额」） |
| 失败原因 | 红色文字，仅分账失败时展示 |

**分账明细表**（el-table）

| 列 | 说明 |
|----|------|
| 角色 | 平台 / 店铺 / 配送方 / 销售方 |
| 收款人 | 收款人名称 |
| 分账金额 | ￥格式化 |
| 手续费 | 「是」/「否」 |
| 银行名称 | — |
| 银行卡号 | 脱敏格式（如 `**** **** **** 1234`） |
| 开户行 | 省份 + 城市（如 `浙江省 杭州市`） |

### 3. 交互状态

| 状态 | 说明 |
|------|------|
| 加载中 | 表格 `v-loading`，弹窗打开时 spin |
| 空数据 | 表格 `empty` slot，「暂无订单结算数据」 |
| 明细查询失败 | toast 提示「获取结算明细失败」，弹窗不打开 |
| 非 Adapay 订单 | 「查看明细」按钮 `disabled` 或隐藏 |

## 权限

- `order:settlement:query` — 查看页面和明细

## 租户权限

| 角色 | 数据范围 |
|------|----------|
| 超管/平台财务 | 所有租户 |
| 租户管理员 | 仅当前租户 |

## 空状态和边缘情况

- 列表无数据时显示空状态插画 + 「暂无订单结算数据」
- 结算状态筛选为空时，显示所有订单（含非 Adapay）
- 收款人已删除时，明细中收款人名称显示「收款人已删除」，银行卡信息显示 `--`
