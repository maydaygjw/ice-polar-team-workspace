# 打印方向与单双面设置需求规格

## 目标

在现有打印商品 Option 和链科打印任务链路上，增加打印方向及单双面设置。

## 业务规则

- 方向使用商品 Option 分组“方向”：`竖向`、`横向`。
- 双面使用商品 Option 分组“双面”：`单面`、`长边双面`、`短边双面`。
- 只同步打印机实际支持的选项；单面和竖向优先作为默认项（设备支持时）。
- 新增选项默认加价 0，价格仍由商品管理维护。
- 方向和双面不进入 SKU，沿用现有 `optionSelections`。
- 下单时服务端根据 Option 名称解析链科编码，不信任客户端直接传入的编码。
- 方向、双面名称及编码必须写入 `DeviceOrderDO.extraParams`，支付成功后的提交只读取订单快照。
- `dmOrientation`：`1=竖向`、`2=横向`。
- `dmDuplex`：`1=单面`、`2=长边双面`、`3=短边双面`。

## 非目标

- 不新增商品表或 SKU 表字段。
- 不改变普通商品 Option 计价逻辑。
- 不修改文件页数计算接口的参数；页数仍以纸张大小和文件内容为准。
