# 测试计划

## 环境前置

- 测试企业微信配置具有客户联系 secret 和客户朋友圈发表权限。
- 测试租户存在至少 2 名客户管理员及文字/图片素材。
- 使用测试企业微信和测试租户，不使用生产客户数据。

## 场景

1. 选择包含文字和 0-9 张图片的素材组，再选择 2 名客户管理员，创建任务成功。
2. 选择素材组复用文字和图片，确认顺序及快照。
3. 尝试选择含 10 张图片或视频/小程序的素材组、空发表人，确认前后端均拒绝。
4. 选择文字 + 链接素材组创建成功；选择含多个链接或链接 + 图片的素材组，确认前后端均拒绝。
5. 查询异步结果，确认待确认、已发表、无效成员和失败状态映射。
6. 使用其他租户或其他企业微信配置的 ID，确认读取和创建被拒绝。
7. 模拟企业微信超时，确认不自动重试并进入待核查。

## 验证重点

- backend 单元/集成测试覆盖编排、校验、租户隔离和异常状态。
- admin 执行 `pnpm ts:check`、相关构建和 Playwright E2E。
