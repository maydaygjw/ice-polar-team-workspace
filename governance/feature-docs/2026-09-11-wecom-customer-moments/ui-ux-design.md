# 客户朋友圈 UI/UX 设计

## 页面结构

- 企业微信配置选择器位于页面顶部。
- 左侧为朋友圈编辑区：正文、素材组选择、图片缩略图和顺序调整。
- 右侧为发表设置：客户管理员多选、已选人数、提交按钮和接口说明。
- 下方为任务记录表格。

## 交互与状态

- 未选择配置时编辑区和任务列表展示空状态。
- 素材组只展示当前配置下可用的文字和图片；含视频、链接或小程序的素材提供不可用提示。
- 图片上传、排序和删除均提供即时预览；超过 9 张时阻止继续添加。
- 提交中禁用提交按钮并显示加载状态。
- 成功后提示“任务已创建，等待客户管理员在企业微信确认发表”。
- 状态使用“创建中、待确认、已发表、部分失败、失败、待核查”。
- 企业微信错误在任务详情中展示可读原因，不在列表中展开长报文。

## 视觉与适配

- 沿用现有企业微信管理页面的 `ContentWrap`、`Dialog`、`el-table`、`el-upload` 和权限按钮模式。
- 图片缩略图保持统一尺寸，支持窄屏上下排列。
- 重要状态使用标签和图标同时表达，不仅依赖颜色。
