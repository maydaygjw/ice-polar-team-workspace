# 企业微信群临时二维码

## Scope

在管理后台客户群列表为单个客户群临时生成企业微信进群二维码。二维码展示并可下载；创建后 1 小时自动删除企业微信侧的进群方式配置。临时配置 ID 仅由后端用于排期和删除，不持久化到业务数据库。

影响仓库：`admin`、`backend`。不涉及 miniapp、H5 或其他业务仓库。

## Use Cases

1. 有权限的管理员在客户群列表某行点击“群二维码”，查看该群的临时进群二维码。
2. 管理员下载二维码，在 1 小时有效窗口内使用。
3. 后端在生成成功后安排清理任务；到期后调用企业微信接口删除该进群方式配置。

## Business Rules

- 一次只为一个已同步的客户群创建二维码，二维码仅绑定当前群。
- 该操作沿用客户群列表现有查询权限，不新增独立权限码。
- 生成时使用该群所属企业微信账号的客户联系配置和当前租户上下文。
- 企业微信创建成功后才安排 Redis 延迟清理；响应返回二维码地址和预计失效时间。
- 1 小时后消费者调用企业微信删除进群方式接口。删除成功后不再保留本地配置记录。
- 删除失败后按递增间隔持续重试，间隔上限为 60 分钟；不能因延迟队列已取出消息而丢弃清理任务。重试消息无法写回 Redis 时记录 ERROR 日志。
- 同一行重复点击复用该租户、企业微信账号和群对应的现有配置；每次点击将 Redis 缓存与延迟清理时间重新延长 1 小时。
- 二维码失效后，已下载图片仍可能存在，但扫描不能再通过已删除的企业微信进群配置生效。

## Frontend Requirements

- 客户群列表操作区新增“群二维码”入口，沿用现有客户群查询权限，不新增独立权限。
- 点击后显示加载态；成功后在弹窗展示二维码，并标明“1 小时后自动失效”。
- 提供下载二维码操作。关闭弹窗不影响后端延迟清理。
- 生成失败时显示后端错误信息，不展示空弹窗。

## Edge Cases

- 客户群不存在、已解散或关联企业微信配置不可用时，拒绝生成并返回可读错误。
- 企业微信创建请求失败时，不安排清理消息。
- Redis 延迟消息重复投递时，消费者应将企业微信“配置不存在”等幂等删除结果视为已清理。
- 删除请求超时且结果不确定时，安全重试删除；不得静默丢弃。
- 延迟清理服务重启后，已入队消息仍由现有 Redis/Redisson 延迟队列机制恢复消费。

## Acceptance Criteria

- 有客户群查询权限的用户可以生成指定群二维码，二维码能正确展示和下载。
- 请求创建的企业微信进群方式仅绑定对应 `chat_id`。
- 后端按租户和企业微信账号信息将 `config_id` 放入延迟任务，任务到期时间为创建成功后 1 小时。
- 到期消费者调用企业微信删除接口；成功后清理完成，失败会重试且有最终告警记录。
- 数据库无新增字段或表；日志不输出客户联系 Secret 或 access token。

## Assumptions

- 暂定二维码清理时长为 1 小时，依据当前对话中提出的默认值。
- 企业微信账号已具备客户群进群方式创建、查询凭证和删除权限；不具备时按接口错误提示管理员。
- 延迟队列复用 backend 现有 Redisson 延迟队列和 `DelayedQueueListener` 模式。
