# 拼单支付实现审查

## 审查结论

实现与已确认规格基本一致，可进入测试环境验收；未提交代码。

## 已核对

- 普通订单和拼单订单均生成新的三段式 AdaPay `outPayNo`；序号存独立字段，不解析历史单号。
- 拼单支付在主订单行锁内预占份数，成功回调按支付记录汇总，主订单拼满后才进入原有支付成功流程。
- 只有登录用户可支付；发起人首份限制、2～10 份、尾差、租户/门店配置和发起人退款权限均有后端校验。
- 超时、发起人取消和整单退款均按成功支付记录逐笔退款；门店配置使用继承/启用/禁用三态。
- 历史支付记录不迁移、不改写；数据库脚本只新增字段和索引。
