# 活动排行榜与游戏兜底奖励测试计划

## 管理端

1. 新建开奖、抽奖和游戏模板，确认三种模式均可选兜底奖；游戏模板保存并重新编辑时正确回显。
2. 兜底奖与任一关卡奖重复时保存失败；清除兜底奖可保存；跨租户、停用或失效奖品不可选。
3. 生成游戏期次后修改模板兜底奖，已生成期次仍保留原快照。

## 游戏结算

1. 按规则获得关卡奖时不发兜底奖，关卡奖库存正常扣减。
2. 首关失败、目标关没有可发库存或配置缺少可发关奖时，有兜底快照则写入兜底中奖记录，不扣减关卡奖库存。
3. 无兜底快照时保持现有未中奖原因；单人限中仍阻止重复派奖。
4. 重放相同终局 `requestId` 不重复创建中奖记录、增加期次中奖人数或更新成绩。
5. 兜底中奖沿用现有自动/线下兑奖、中奖通知和兑奖状态。

## 榜单

1. 开奖名单前 10 条与现有服务端排序一致，按联系人名称、用户昵称、默认名称的优先级展示未脱敏姓名、奖品和时间。
2. 游戏用户多局成绩按最高通过关数、该关数下最短用时计算个人最佳，再按确定的次序返回前 10 名。
3. 相同关数用时较少者靠前；完全相同的数据顺序稳定。
4. 游戏榜单无完成记录时返回空列表；非游戏期次返回业务错误。
5. 榜单只能返回当前期次有效报名；响应不包含用户 ID、完整手机号、openid 或兑奖码。

## H5

1. 开奖结果页显示中奖榜并成功、空列表和失败重试状态正确。
2. 抽奖结果页没有排行榜按钮。
3. 游戏中奖结果页显示闯关榜入口，列出前 10 名、通过关数和耗时。
4. 游戏页有配置兜底奖时展示奖励名称；无配置时不显示兜底区。
