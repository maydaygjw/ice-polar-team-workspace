# 活动排行榜与游戏兜底奖励 UI/UX 设计

## 结果页入口

- 入口保留在用户确认的中奖结果页。
- 开奖模式显示“查看中奖排行榜”；游戏模式显示“查看闯关排行榜”；抽奖模式隐藏排行榜入口。
- 每种榜单使用对应标题和数据列，避免把闯关成绩误显示为中奖次数。

## 榜单内容

- 中奖名单列出排名、展示名称、奖品名称、中奖时间，最多 10 条。名称优先使用企业微信客户联系人名称，其次用户昵称，均无时显示“吃货友友”。
- 闯关榜列出排名、展示名称、通过关数、耗时，最多 10 条；先按关数、再按耗时排序。名称规则与中奖名单一致。
- 弹窗内提供加载中、暂无数据、加载失败状态和关闭按钮。

## 游戏奖品区

- 三关奖品继续按关卡顺序展示。
- 已配置兜底奖时，在关卡奖品下方单独标注“兜底奖励”，展示奖品名和图片；说明仅在未获得可发关卡奖时发放。
