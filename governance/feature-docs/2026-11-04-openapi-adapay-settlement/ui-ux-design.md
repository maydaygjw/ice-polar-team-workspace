# 商圈 OpenAPI 默认店铺配置交互

## 表单

- 在现有商圈新增/编辑弹窗中，商圈代码之后增加带可见标签的“OpenAPI 默认店铺”选择器。
- 新建表单首次填写商圈代码后，或编辑打开表单时，加载该商圈启用店铺；列表按店铺名称展示，选项值使用店铺 ID。
- 尚未配置时显示“未配置”，并用简短帮助文案说明 OpenAPI AdaPay 支付需要此店铺来匹配计费模板和收款人。
- 当商圈代码为空或店铺加载中时禁用选择器并显示加载状态；接口失败时显示字段附近的错误提示并允许重试。

## 校验与反馈

- 服务端校验跨商圈/已停用店铺；失败时定位到“OpenAPI 默认店铺”字段展示原因。
- 更换或清除已配置店铺后，明确提示此变更只影响之后创建的支付，不修改历史结算快照。
- 财务应收应付列表把退款成功后作废的记录标为“已退款作废”，不允许再次结算或重算。
- 保存按钮保留现有 loading 与成功/失败消息模式；不增加独立确认弹窗。

## UI/UX 指引记录

- UI Pro Max UX 检索支持表单字段关联标签及提交状态反馈，符合当前 Form 结构。
- Vue stack 检索在 `accessible async select loading` 未命中；改为 `access` 后只检出 Vue ref/lifecycle/routing 指引，没有额外异步选择器规则。本设计按现有 Element Plus 组件和通用表单反馈规则实现。
