# UI/UX 设计

## 页面结构

- 在现有“微信管理”目录下增加“企业微信”菜单组。
- “企业微信配置”页面沿用公众号账号页的筛选栏、表格、分页和弹窗表单。
- “客户群”页面使用独立列表，顶部提供企业微信配置下拉、群名称和群 ID 查询，右侧提供刷新。

## 配置页增量

- 表格列：配置名称、企业 ID（脱敏中间段）、最近同步时间、备注、操作。
- 操作：编辑、删除、同步客户群；同步按钮拥有独立权限并在请求期间禁用。
- 表单字段：名称、企业 ID（CorpID）、客户联系 Secret、备注。
- Secret 使用密码输入；编辑时显示“已配置，留空保留原值”，不把服务端脱敏值回填到输入框。
- 删除使用现有二次确认。

## 客户群列表

- 表格列：群名称、群 ID、群主、成员数、群状态、企业微信配置、最后同步时间。
- 加载状态使用现有表格 loading；无数据时使用现有空列表表现。
- 同步完成显示成功/更新/失败汇总；部分失败用 warning 提示并保留列表中已有数据。
- 外部权限或凭证错误显示后端返回的可操作提示，避免展示 token、Secret 或完整第三方响应。

## 交互状态与适配

- 查询、重置、分页遵循现有后台组件模式。
- 表单提交、同步、删除期间禁用对应操作，避免重复请求。
- 页面沿用现有 `ContentWrap`、`Dialog`、`Pagination` 和 `useMessage()`，不引入新视觉组件。
- 表格在窄屏下允许横向滚动；主要操作按钮触控区域不小于现有后台标准。
