# 企业微信客户群同步

## Scope

### In

- 租户管理员可在管理后台维护企业微信配置：名称、企业 ID（CorpID，界面对应用户所说的 appid）、客户联系 Secret（界面对应用户所说的 key）和备注。
- 企业微信配置支持分页查询、新增、修改、删除；配置按租户隔离。
- 租户管理员可针对一个企业微信配置手动同步该企业当前可见的全部客户群。
- 系统保存客户群的群 ID、群名称、群主、创建时间、群状态、群公告、成员数量和成员信息，并在后台分页查看。
- 重复同步同一个企业微信配置时，已有客户群按群 ID 更新，不产生重复数据。

### Out

- 不实现企业微信员工、客户、客户标签、群发消息、欢迎语、入群方式和事件回调。
- 不修改微信公众号、小程序及小程序端功能。
- 不提供自动定时同步；本期只提供管理后台手动同步。
- 不支持在系统内创建、解散、编辑企业微信群或修改群成员。

### Deferred

- 客户群变更事件驱动同步、定时同步和同步任务进度。
- 客户群成员独立检索、客户归档和群运营能力。

## Use Cases

### UC-1 维护企业微信配置

租户管理员进入“企业微信管理”，新增或编辑企业微信配置，保存后可在列表中查看配置名称、CorpID 脱敏值和最近同步时间。编辑时 Secret 默认脱敏；留空表示保留原 Secret。

### UC-2 同步客户群

租户管理员在配置列表点击“同步客户群”。系统使用该配置访问企业微信客户联系接口，读取全部客户群及其详情，成功后将结果写入当前租户并返回本次新增/更新数量；接口失败时显示可理解的失败原因，不覆盖未成功获取的本地数据。

### UC-3 查看客户群

租户管理员进入客户群列表，可按企业微信配置、群名称和群 ID 查询，查看已同步的群基本信息、成员数量、状态和最后同步时间。

## Business Rules

- 企业微信配置的 CorpID 在同一租户内唯一；客户群 ID 在同一租户和企业微信配置内唯一。
- 只有具备企业微信“客户联系”权限的 Secret 才能同步客户群；无权限或凭证失效时同步失败并保留原数据。
- 同步以企业微信返回的群 ID 作为幂等键；重复同步只更新对应记录。
- 客户群详情获取失败时，本次同步不得删除或清空该群已有信息，并应返回失败数量。
- 企业微信 Secret 不得在列表或详情响应中以明文返回；后台展示时使用脱敏值。
- 所有企业微信配置和客户群查询均按当前租户隔离，不允许跨租户读取、更新或删除。
- 本期同步的是当前接口可见的客户群；不承诺恢复企业微信侧已删除群的历史详情。

## Frontend Requirements

- 在“微信管理”下增加“企业微信”入口，至少包含“企业微信配置”和“客户群”页面。
- 配置页沿用现有公众号/小程序账号的列表、弹窗表单、权限按钮和分页模式。
- 配置表单明确区分“企业 ID（CorpID）”与“客户联系 Secret”，Secret 使用密码输入并提示留空保留原值。
- 配置列表提供“同步客户群”操作；同步期间按钮禁用，完成后刷新最近同步时间并提示新增/更新/失败数量。
- 客户群页提供配置筛选、群名称/群 ID 查询、分页列表，以及加载中、空数据和同步失败提示。
- 不在前端保存或展示 Secret 明文；删除配置需二次确认。

## Edge Cases

- 配置缺少 CorpID 或 Secret、CorpID 重复、更新时 Secret 留空。
- 企业微信 access token 获取失败、Secret 无客户联系权限、接口返回业务错误或网络超时。
- 客户群数量超过单页接口上限，需要连续分页获取。
- 群列表成功但部分群详情失败，或返回群名称为空、成员列表为空。
- 同一配置并发触发两次同步。
- 同一个群 ID 在不同企业微信配置中出现。
- 租户管理员尝试使用其他租户的配置 ID 查询或同步。

## Acceptance Criteria

- 管理员可以创建、编辑、删除和分页查看企业微信配置，且 CorpID 在当前租户内不可重复。
- 配置详情和列表永远不返回 Secret 明文；编辑时留空保存不会清除原 Secret。
- 使用有效且有客户联系权限的配置点击同步后，系统能够跨页获取全部客户群并保存群基本信息和成员信息。
- 对同一配置重复同步不会生成重复群记录，已有群信息会更新。
- 同步失败时返回可识别的失败结果，已有本地客户群数据保持不变；部分失败不会导致成功数据丢失。
- 客户群列表可按配置、群名称、群 ID 分页查询，并展示群 ID、名称、群主、成员数、状态和最后同步时间。
- 不同租户之间无法通过接口或管理页面读取、修改、删除对方的企业微信配置或客户群。
- 后端目标模块测试通过，管理端类型检查和生产构建通过；测试结果记录在 `test-notes.md`。

## Assumptions

- 用户所说的“appid”按企业微信官方术语解释为 CorpID；“key”按用于客户联系接口的 Secret 解释，而不是自建应用 AgentSecret。若使用自建应用 Secret，企业微信侧必须已将其配置为可调用客户联系接口。
- 本期同步接口采用后台同步调用并返回汇总结果；如实际群规模导致超时，再拆为异步任务，不在本期预留任务状态模型。
- 客户群成员信息以同步快照保存，当前页面只展示成员数量和群基本信息，不单独展开成员管理。
