# 活动线下兑奖码

## 规则

- 新增开奖规则 `OFFLINE_CLAIM`，表示奖品由线下工作人员核验后发放。
- 该规则不在开奖或后台兑奖时执行外部发放动作；中奖记录仍按现有 `claimStatus` 流程确认兑奖。
- 每条有效中奖记录生成一个租户内唯一、不可变的兑奖码并持久化。
- 历史中奖记录在数据库升级时补齐兑奖码，不改变原有中奖和兑奖状态。

## 接口字段

- `GET /admin-api/activity/winner/page` 返回 `redemptionCode`，供中奖管理查看和导出。
- 用户端活动结果中的中奖记录返回 `redemptionCode`，供中奖客户线下出示。
- 兑奖码使用大写字母和数字组成，客户端不得自行生成或修改。

## 权限与兼容性

- 沿用现有奖品管理权限和中奖记录权限，不新增权限点。
- 现有开奖规则和线上兑奖规则行为保持不变。
