# 引流海报需求规格

## 1. 功能概述

在管理后台的「企业微信」模块下新增「引流海报」菜单。管理员从企业微信同步已有的「联系我」配置，选择二维码，上传背景图，在前端调整二维码位置和尺寸，生成固定尺寸的引流海报并保存到 OSS；APP 可按商圈查询启用海报的 OSS 图片链接。

本期只实现后台和后端能力，不实现小程序端接口消费；AI 背景生成延期。

## 2. 范围

### In Scope

- 菜单名称为「引流海报」，不超过 6 个字。
- 同步企业微信已有的永久「联系我」二维码配置。
- 创建、编辑和删除企业微信「联系我」二维码配置。
- 选择已同步的二维码。
- 上传背景图片并在固定模板中预览。
- 在前端编辑器中拖动二维码并调整二维码尺寸。
- 选择一个启用中的商圈作为投放范围。
- 生成 `1125 × 1500` 的完整海报并上传 OSS。
- 提供 APP 按商圈查询启用海报 OSS 图片链接的接口。
- 保存海报生成参数和最终图片地址。
- 海报列表、详情预览、编辑、删除、启用/停用和排序。
- 企业微信二维码和海报均按租户隔离。

### Out of Scope

- AI 背景生成。
- 小程序端页面、接口和展示逻辑。
- 点击、曝光、扫码和新增客户统计。
- 文字、装饰和其他模板元素编辑。
- 客户群「加入群聊」二维码。
- 企业微信临时会话二维码。

### Deferred

- 多套模板和模板编辑器。
- 海报投放时间段。
- 二维码失效监控和自动下线。

## 3. 角色与权限

- 具备引流海报查询权限的管理员可以查看当前租户有权限的海报和二维码。
- 具备创建/编辑权限的管理员可以上传背景、生成和修改海报。
- 具备删除权限的管理员可以删除海报；删除前需要二次确认。
- 商圈选择和海报查询遵循现有租户、部门和商圈数据权限。
- 企业微信 CorpID、Secret 和 access token 仅由服务端使用，后台不得展示明文 Secret。

## 4. 使用场景

### UC-1 同步联系我二维码

管理员选择企业微信配置并发起同步。系统通过 `list_contact_way` 分页获取配置 ID，再通过 `get_contact_way` 获取每个配置的当前信息和二维码地址，保存可用的永久二维码配置。重复同步不得产生重复记录。

同步结果需要告知处理总数、成功数和失败数；单个配置失败不得导致其他配置全部回滚。

企业微信列表接口不包含临时会话，且对历史配置存在官方时间范围限制；不满足接口返回条件的配置不进入选择列表，并在同步结果中说明。

### UC-2 生成引流海报

管理员上传背景图，选择同步的联系我二维码，在前端编辑器中拖动或缩放二维码，选择商圈后保存。前端将 Canvas 导出的完整海报上传 OSS，后端保存最终图片地址、背景地址、二维码快照和几何参数。

### UC-3 管理已生成海报

管理员可以按商圈、状态和时间查看海报，预览最终图片，编辑生成参数后重新生成，调整启用状态和排序，或删除海报。

## 5. 功能需求

### FR-1 联系我信息同步

- 后台提供选择企业微信配置和「同步联系我」操作。
- 系统只同步返回二维码地址的永久联系我配置，不同步仅包含小程序按钮的配置。
- 每条同步记录至少关联企业微信配置、`config_id`、当前二维码地址、备注、使用范围、同步时间和状态。
- 同一企业微信配置下的 `config_id` 唯一；再次同步更新当前信息，不创建重复数据。
- 被企业微信删除或查询失败的配置不得作为可选二维码；已被海报使用的历史二维码信息保留在海报快照中。
- 同步必须在服务端调用企业微信接口，前端不得接触 Secret 或 access token。

### FR-1.1 联系我配置管理

- 管理员可以新增联系我配置，填写单人/多人类型、成员 UserID 或部门 ID、备注和添加好友验证策略。
- 新增时由服务端调用企业微信生成 `config_id` 和二维码，并保存二维码 OSS 快照。
- 管理员可以编辑已同步或已创建的配置；`config_id` 不可编辑，修改成功后刷新本地快照。
- 管理员可以删除配置；只有企业微信删除成功后才删除本地同步记录。
- 本期仅支持二维码场景，不提供小程序联系我按钮配置。

### FR-2 背景图上传与模板预览

- 仅支持上传图片背景，不提供 AI 生成入口。
- 最终画布固定为 `1125 × 1500`，即 3:4 比例。
- 上传后按 3:4 比例展示背景；MVP 背景使用 cover 方式填充画布。
- 预览只展示背景和二维码，二维码支持拖动和缩放。
- 系统不根据背景内容自动识别文字空白区，也不自动移动模板元素；背景中已有内容与模板重叠时，由管理员通过预览调整背景裁剪。
- 输出图片不包含手机状态栏、微信导航栏或其他截图外壳。

### FR-3 二维码编辑

- 二维码在 `1125 × 1500` 画布内显示，默认使用合理的初始位置和尺寸。
- 管理员可以拖动二维码调整位置，可以拖动右下角控制点调整尺寸。
- 二维码保持正方形，最小尺寸为 `160`，不可超出画布边界。
- 商圈仅作为投放筛选条件，不自动显示在海报图片中。

### FR-4 二维码合成

- 只能选择已同步且状态正常的联系我二维码。
- 二维码位置和尺寸由管理员编辑，系统保存 `qrX`、`qrY`、`qrSize`。
- 生成前系统校验二维码信息完整；二维码地址无法获取时不得生成。
- 海报保存当前二维码的配置 ID 和二维码信息快照；后续企业微信同步更新不修改已生成的完整海报。

### FR-5 海报保存与管理

- 生成成功后才保存最终图片地址；OSS 上传失败时不得产生可用海报记录。
- 新建海报默认停用，由管理员明确启用。
- 列表展示缩略图、商圈、二维码备注、状态、排序、更新时间和操作项。
- 编辑海报时回显原背景、二维码位置/尺寸和商圈；重新导出并上传后更新当前海报结果。
- 删除海报不删除仍被其他海报引用的二维码同步记录。
- 海报图片 URL 必须是稳定的 OSS 访问地址，不依赖后台登录态。
- APP 通过商圈 ID 查询启用海报时，只返回排序最高的一张海报 OSS 图片链接。

## 6. 业务规则

- 所有海报和二维码同步记录按租户隔离。
- 商圈必须是当前租户可见且启用的商圈；商圈停用后，已有海报保留但不得新建或启用。
- 联系我配置以 `config_id` 作为企业微信侧唯一标识；删除并重新创建的配置视为新二维码。
- 海报是最终图片快照；二维码或背景同步变化不得追溯修改已生成图片。
- 同一海报只能关联一个背景、一个联系我二维码和一个商圈。
- 生成过程任一环节失败时，管理员可以重试，不应产生半成品海报。

## 7. 后台页面需求

- 列表页支持按商圈、状态、二维码备注和创建时间筛选。
- 新增/编辑页按“背景图 → 二维码编辑 → 商圈 → 预览 → 保存”的顺序组织操作。
- 二维码选择器展示二维码缩略图、备注、企业微信配置名称、使用成员摘要和最近同步时间。
- 背景上传区域展示模板安全区说明和最终尺寸提示。
- 预览区域展示最终比例，保存前可清晰查看二维码和背景的叠加效果。
- 同步按钮展示同步进度和结果摘要，失败项可查看失败原因。

## 8. 异常与边界场景

| 场景 | 预期行为 |
|---|---|
| 企业微信配置无客户联系权限 | 同步失败并提示配置权限问题 |
| 联系我列表为空 | 展示空状态，不允许选择二维码 |
| 同步接口分页 | 自动处理 cursor，直到完成全部页面 |
| 单个配置详情获取失败 | 记录失败原因，继续处理其他配置 |
| 企业微信返回二维码地址为空 | 不进入可选列表 |
| 背景图无法裁剪为 3:4 | 阻止生成并要求重新调整裁剪区域 |
| 文案超出模板区域 | 阻止生成并提示修改文案 |
| 商圈被停用 | 已有海报可查看，不允许新建或启用 |
| OSS 上传失败 | 保留表单内容，提示重试，不生成可用记录 |
| 同步时二维码配置被删除 | 标记本地记录不可用，历史海报不受影响 |

## 9. 验收标准

- [ ] 菜单名称为「引流海报」，不超过 6 个字。
- [ ] 可以选择企业微信配置并同步已有永久联系我配置。
- [ ] 同步通过 `list_contact_way` 和 `get_contact_way` 完成分页及详情获取。
- [ ] 重复同步不会产生重复 `config_id` 记录。
- [ ] 可以选择同步成功且可用的二维码。
- [ ] 可以上传背景图，并通过辅助线完成 3:4 裁剪预览。
- [ ] 二维码支持拖动和缩放，且不能超出画布边界。
- [ ] 商圈只影响海报归属和筛选，不显示在最终图片中。
- [ ] 输出图片尺寸始终为 `1125 × 1500`。
- [ ] 最终海报包含背景和联系我二维码。
- [ ] 前端导出成功后图片上传 OSS，并保存图片地址和二维码几何参数。
- [ ] OSS 上传失败时不会产生可用海报记录。
- [ ] 已生成海报可编辑、预览、启用/停用、排序和删除。
- [ ] 同步更新二维码不会修改历史海报图片。
- [ ] 不新增小程序页面、接口或展示逻辑。
- [ ] 不包含 AI 图片生成能力。
- [ ] 租户和商圈数据权限校验有效。
- [ ] APP 可以根据商圈 ID 获取启用海报的 OSS 图片链接；无可用海报时返回业务错误。

## 10. 假设与限制

- 本期使用企业微信永久二维码「联系我」配置；支持通过 API 新建配置，也支持同步已有配置。
- 企业微信接口返回的历史范围限制由企业微信侧决定，系统不承诺同步全部历史配置。
- 二维码默认坐标和尺寸由前端编辑器提供，保存时以后端校验的 `qrX`、`qrY`、`qrSize` 为准。
- APP 海报查询只支持按商圈 ID 获取单张启用海报，不扩展为门店级或多海报列表查询。
