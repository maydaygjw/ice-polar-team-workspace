# 引流海报后台 UI/UX 设计

## 1. 页面入口

- 父菜单：企业微信
- 子菜单：引流海报
- 页面类型：后台桌面端管理页，复用现有 Element Plus 表格、表单、抽屉和上传组件。

## 2. 列表页

### 查询区

- 商圈：下拉选择，仅显示当前用户可见且启用的商圈。
- 状态：全部、启用、停用。
- 二维码备注：文本搜索。
- 创建时间：时间范围。
- 操作：查询、重置、同步联系我、新增海报。

### 表格列

1. 缩略图：固定 3:4 比例，点击查看大图。
2. 商圈。
3. 联系我二维码备注。
4. 状态。
5. 排序。
6. 更新时间。
7. 操作：预览、编辑、启用/停用、删除。

### 列表状态

- 加载中：表格显示 loading。
- 无数据：显示空状态和“新增海报”操作。
- 查询失败：保留筛选条件，显示错误提示，可重新查询。
- 海报图片加载失败：显示占位图，不影响其他行。

## 3. 联系我同步

- 点击“同步联系我”打开同步弹窗。
- 弹窗先选择企业微信配置，再点击同步。
- 同步中禁用重复操作，显示进度和“正在获取联系我配置”提示。
- 完成后展示总数、成功数、失败数。
- 存在失败项时允许展开查看失败原因。
- 同步完成后刷新二维码选择器和列表，不自动刷新正在编辑的表单选择值。
- 没有可同步二维码时展示空状态和企业微信权限提示。

## 4. 新增/编辑页

建议使用较宽抽屉或全屏弹窗，左侧为编辑表单，右侧为海报预览；预览区域固定保持 3:4 比例。

### 表单顺序

1. 背景图
2. 企业微信联系我二维码
3. 商圈
4. 海报预览和保存操作

### 背景图组件

- 支持点击上传和拖拽上传。
- 上传成功后在 `1125 × 1500` 比例的编辑器中展示背景。
- 背景按 cover 方式填充，避免拉伸变形。
- 不提供文字输入和文字图层，背景中的已有内容由上传者负责设计。
- 上传失败、格式不支持和超过大小限制时在组件下方显示明确错误。

### 二维码选择器

- 支持按企业微信配置筛选。
- 卡片展示二维码缩略图、备注、企业微信配置名称和最近同步时间。
- 不可用、失效或缺少二维码图片的记录置灰且不可选择。
- 未同步时提供“去同步”操作入口。

### 二维码编辑器

- 二维码以可选中图层叠加在背景上。
- 支持拖动二维码调整位置，支持拖动右下角控制点调整大小。
- 二维码保持正方形，最小尺寸为 `160`，不可超出画布边界。
- 编辑已有海报时恢复已保存的位置和尺寸。

### 商圈选择

- 只允许选择一个商圈。
- 选择器只展示可见且启用的商圈。
- 商圈名称只作为管理属性，不在海报画面中显示。

## 5. 海报预览

- 预览容器始终保持 `1125:1500` 比例，按可用空间等比缩放。
- 预览展示最终图层顺序：背景、二维码。
- 编辑状态显示二维码边框和缩放控制点；最终导出时不包含编辑辅助元素。
- 预览加载中显示骨架或 loading，不显示旧海报作为新内容。
- 保存中禁用编辑和关闭操作，显示“正在导出并上传海报”。
- 上传成功后保存海报记录；导出或上传失败保留当前编辑状态，允许重试。

## 6. 交互反馈

| 操作 | 成功反馈 | 失败反馈 |
|---|---|---|
| 同步联系我 | 显示同步统计并刷新列表 | 显示失败原因和重试入口 |
| 上传背景 | 显示裁剪器 | 显示格式/大小/读取失败 |
| 生成海报 | 显示最终图片 | 保留表单并提示具体失败环节 |
| 启用/停用 | 更新状态标签 | 恢复原状态并提示失败 |
| 删除 | 二次确认后刷新列表 | 保留当前行并提示失败 |

## 7. 视觉和可用性约束

- 复用后台现有颜色、按钮、表格和表单样式，不新增独立品牌色。
- 预览区域不低于 `360 × 480px`，避免文字和二维码细节不可见。
- 二维码选择卡片的点击区域不小于 `88px` 高度。
- 重要操作按钮按“同步、新增、生成、保存”区分主次，删除使用危险色。
- 错误提示应靠近对应控件，同时保留顶部消息提示用于接口错误。
- 预览辅助线不能出现在最终保存图片中。
