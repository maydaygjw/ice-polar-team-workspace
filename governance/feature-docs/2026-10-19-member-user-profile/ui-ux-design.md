# UI/UX 设计：外卖用户画像

## 页面入口与布局

- 页面名称：用户画像；入口放在后台“会员/用户中心”菜单下。
- 沿用管理后台现有 Element Plus 管理列表页的间距、标题、筛选栏、表格和分页样式，不引入新组件库或视觉依赖。
- 页面标题下方提供简短说明：“画像数据由外部系统导入，本页仅支持查询”。

## 筛选区

单行或按现有后台响应式规则换行展示：

| 控件 | 交互 |
|---|---|
| 会员 ID | 文本输入，精确匹配，支持 Enter 搜索 |
| 是否从未下单 | 下拉选择：全部、是、否；`true` 表示注册后从未下单 |
| 用户阶段 | 下拉选项从 `member_user_profile_stage` 数据字典加载 |
| 用户标签 | 文本输入，匹配单个完整标签名称，支持 Enter 搜索 |
| 搜索 / 重置 | 搜索从第 1 页开始；重置清除筛选条件 |

筛选项不提供标签编辑、导入或批量操作入口。

## 结果表格

列顺序：会员 ID、注册时间、是否从未下单、近 3 天订单数、近 3 天下单天数、近 7 天订单数、近 7 天下单天数、近 30 天订单数、最近下单时间、用户阶段、用户标签、更新时间。

- 会员 ID 显示为可点击链接，跳转至会员信息页；无关联会员时显示未关联且不提供链接。注册时间取关联会员资料。阶段编码原样可读；已知阶段显示数据字典中的中文名称，未知阶段显示原值。
- `is_new_user=true` 显示“是”，表示注册后从未下单；false 显示“否”。它与用户阶段“新用户”含义不同。
- 订单数右对齐；日期和时间按 Asia/Shanghai 展示。
- 标签以只读 Tag/文本标签形式展示；标签较多时换行或收敛显示并可查看完整值，避免撑坏表格。
- 最近下单时间为空时显示 `—`。
- 横向空间不足时保持表格可横向滚动，分页控件遵循现有后台列表规范。

## 空状态与反馈

- 首次查询无数据且无筛选：说明“暂无画像数据，请由外部系统导入后查询”，不展示虚构统计卡片或示例行。
- 筛选后无匹配项：说明“没有符合条件的画像记录”，提供重置筛选操作。
- 加载时使用表格 loading 状态；查询失败沿用后台统一错误提示。
- 页面及筛选仅访问只读分页接口；没有行内编辑、详情编辑或删除操作。

## 可访问性与响应式

- 控件使用明确标签/占位说明，键盘可完成输入、搜索和重置。
- 小屏下筛选项自然换行，表格容器水平滚动，避免页面整体被宽列挤压。
