# 契约变更：订单每日序号

## API

- 订单管理端详情、分页列表、导出响应，以及 C 端订单详情、列表响应新增可选字段 `orderSequence`。
- 类型为整数；新订单为正整数，历史订单可为 `null`。
- 字段只读，创建/更新请求不接受客户端指定的序号。
- 既有 `orderId`、`numberId` 语义和接口参数保持兼容。

## DB

- `yshop_store_order` 新增 `order_sequence`，保存订单每日序号；允许为空以兼容历史数据。
- 新增 `yshop_order_sequence` 计数表，按 `tenant_id + shop_id + sequence_date` 唯一维护当天已分配的最大序号。
- 计数表包含租户、门店、日期、当前值及标准审计字段；唯一约束保证并发下每个门店每天只有一条计数记录。
- 升级脚本：`backend/sql/upgrade-2026-08-15-order-daily-sequence.sql`。
- 回滚：停止新版本订单写入后删除订单序号字段，再删除计数表。

## 权限与数据范围

- 订单序号沿用订单接口现有的租户隔离和管理端数据权限，不新增权限。
- 计数表只由订单创建流程使用，不提供独立查询接口。
