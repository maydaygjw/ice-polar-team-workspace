## E2E Test Plan: MiniApp 订单详情页

### Test Scenarios
- 从订单列表进入详情页
- 正常展示已完成订单详情
- 正常展示未支付订单详情并继续支付
- 可退款订单从详情页跳转退款页
- 非法订单号或无权限订单访问失败

### E2E Test Cases
1. 已登录用户打开订单列表，点击订单卡，进入订单详情页并看到订单号、状态、金额
2. 未支付订单进入详情页，点击立即支付，支付成功后跳转到 `processing`
3. 已完成且可退款订单进入详情页，点击申请退款，进入退款页
4. 详情接口返回无权限或不存在时，页面提示异常并允许返回

### Test Data Setup
- 至少准备一条未支付设备订单
- 至少准备一条已完成且可退款设备订单
- 至少准备一条非当前用户订单用于权限校验

### Environment Requirements
- MiniApp 通过微信开发者工具运行
- Backend 本地或测试环境可用
- 登录态有效
